# PDF·이미지로 AI 찬양 준비하기

2026-10-07 · REQ-037 / FLOW-011 / TC-037

오른쪽 아래 도구 모음의 **AI로 찬양 준비**에서 악보·가사 파일을 넣어 곡과 콘티 순서를 만든다. 각 예배의 곡 구성은 해당 콘티에 저장된다. 왼쪽 플레이리스트와 Songs·Bible 영역 사이의 구분선을 끌어 두 영역의 높이를 조절할 수 있다.

## 처음 설정

**AI 연결 추가**를 눌러 Google Gemini, OpenAI, Anthropic Claude 중 제공자와 모델을 선택하고 API 키를 등록한다. 제공자에 맞는 기본 모델 ID가 입력되며 계정에서 사용 가능한 다른 PDF·이미지 및 도구 호출 모델 ID로 바꿀 수 있다. 여러 연결을 등록하고 사용할 AI를 선택할 수 있다. 기존 Gemini 키도 활용할 수 있다. 선택한 원본과 이 작업의 지시·준비 중인 곡 내용이 해당 제공자에 전달된다. API 키는 OS 보호 저장소에 암호화하며 화면에는 등록 여부만 표시한다. 파일 분석은 선택한 AI 계정에 비용이 발생할 수 있다.

## 파일에서 콘티 만들기

1. 현재 콘티와 곡 수를 확인한다. **기존 콘티 끝에 추가** 또는 **기존 콘티 순서를 새로 구성**을 선택한다.
2. 기본 **확인 후 적용**, 또는 **명확한 결과는 자동 적용**을 선택한다. 자동 적용도 가사·반복·원곡 연결이 불명확하면 확인을 기다린다.
3. **송폼과 추가 지시**에 원하는 순서를 적는다. 예: `첫 곡은 A B A B×2 C B TAG, 슬라이드당 두 줄`.
4. PDF·PNG·JPG·WEBP를 선택하거나 창에 끌어 놓는다. 목록과 제공자를 확인하고 **분석 시작**을 누른다.
5. **원본 확인**에서 파일과 페이지를 비교한다. 곡별 파트 가사와 송폼을 수정한다. 가사의 빈 줄은 슬라이드 구분이다. 반복 횟수와 콘티 곡 순서도 변경할 수 있다.
6. **찬양 목록 원곡 연결**을 확인한다. 없는 새 곡은 목록에도 저장한다. 기존 곡이면 원곡을 유지하며, 원곡도 바꾸려는 경우에만 **기존 원곡도 이번 구성으로 갱신**을 선택한다.
7. 각 곡의 **가사·송폼·원곡 연결 확인 완료**를 표시하고 **플레이리스트에 적용**한다. 완료 창에서 등록/갱신 곡 수와 최종 순서를 확인한다.

준비 창을 닫으면 유효한 검토 수정도 저장된다. 현재 편집 곡과 송출은 유지되며 준비한 콘티를 선택해 운영한다. 원곡을 현재 편집 중이라면 준비 화면에서 원곡을 갱신하지 말고, 적용한 콘티에서 **찬양 목록 원곡에 반영**을 사용한다.

## 문제 발생 시

- 키·모델 오류: 연결 설정을 수정하고 같은 작업을 다시 분석한다. 다른 AI를 선택한 경우 파일을 그 제공자로 다시 보내는 버튼을 누른다.
- 불명확한 송폼: 원문과 사용자 송폼을 대조해 순서·반복을 직접 고친다. 자동 적용은 확인 완료까지 멈춘다.
- 일부 분석 실패: 확보된 초안을 수정·확인하고 준비된 곡만 사용하거나 같은 파일을 다시 분석한다.
- 콘티/원곡 변경: **최신 콘티에 맞춰 다시 확인**으로 최신 목록을 기준으로 검토한다. 원곡 변경 시 확인 완료가 해제된다.
- 저장 실패: 기존 자료와 순서는 유지된다. 저장 공간을 확인하고 같은 작업을 다시 적용한다. 완료 응답을 놓쳤다면 최근 작업의 저장 결과를 확인한다.
- 중단/취소: 최근 준비 작업에 초안과 파일이 남는다. 취소한 작업도 다시 분석할 수 있다. 저장 중에는 저장 결과를 먼저 확인한다.

**이번 순서 적용 되돌리기**는 적용 이후 콘티가 변경되지 않았을 때 직전 순서를 복원한다. 등록/갱신한 원곡은 남으며 편집 Undo는 소비하지 않는다.

## 파일 보관

파일당 20MB, 전체 40MB/20파일/50페이지를 선택한다. 곡당 펼친 슬라이드 200장, 전체 1,000장까지다. AI 요청 한도가 더 작으면 파일 크기를 줄이거나 나누도록 안내한다. 암호 PDF는 암호를 해제한 뒤 선택한다.

원문·작업본은 완료/취소 후 생성일 기준 7일을 지나면 앱 시작 시 정리된다. **원본과 작업본 계속 보관**을 선택하면 유지한다. 미확정/중단/부분 실패 초안은 보호한다. **원본·작업본 삭제**는 준비 원본과 상세 초안만 삭제하고 저장된 찬양·콘티·적용 기록은 남긴다. 일반 발표/백업 파일에는 원문 PDF·이미지를 자동 포함하지 않는다.

실제 악보의 가사와 반복은 첫 사용 시 반드시 원문과 대조한다. 현재 검증은 합성 자료와 합성 API 응답의 앱 동작이며 실제 모델별 한국어 악보 품질 평가는 별도로 남아 있다. [설계·구현](../engineering/ai-song-preparation.md), [검증 기록](../quality/verification-2026-10-07-ai-song-preparation.md)을 참고한다.
