## 빌드와 공개 릴리즈

```bash
npm run verify
npm run format:check
npm audit
npm run package:check
```

로컬 앱은 `release/0.1.0/mac-arm64/ProPre.app`다. 현재 패키지는 서명/공증 없이 로컬 확인용으로 생성했다. ProPre 앱 아이콘을 포함하며 실제 배포용 저작권자 표기는 소유자가 확정한다.

공개 릴리즈는 `npm run release`로 실행한다. [검사 스크립트](../../scripts/check-release.mjs)는 아래 증거가 없으면 릴리즈 명령을 멈춘다. 파일을 작성했다는 사실만으로 권리/장비 승인을 얻는 것은 아니며 실제 검토 근거를 입력한다.

| 파일                                      | 실제 기록할 근거                                      |
| ----------------------------------------- | ----------------------------------------------------- |
| release-evidence/code-license.json        | 코드 라이선스 원문·권리자·허락 범위                   |
| release-evidence/bible-license.json       | 성경 원본/번역 출처·이용 허락 범위                    |
| release-evidence/platform-acceptance.json | 지원 환경·물리 장비·사용자/설치/복원·장시간 수용 기록 |

각 JSON은 approved, approvedBy, source, reviewedAt를 포함한다. 현재 무료 배포는 Apple 서명·공증 인증을 요구하지 않는다. 증거를 임의 생성하거나 이 명령에서 외부에 게시하지 않는다.

## 앱 내 업데이트 배포

[업데이트 운영 절차](앱-설치와-업데이트-배포.md)를 따른다. `npm run package:free`는 unsigned DMG/ZIP과 `propre-update.json`을 준비한다. `npm run release`는 권리/장비 증거와 전체 검증을 거쳐 같은 무료 파일을 생성한다. Apple 계정/서명/공증은 요구하지 않는다. 외부 게시를 자동 수행하지 않으며 실제 다운로드·종료 후 수동 교체·자료 보존을 확인하고 DMG 다음 manifest 순서로 게시한다.
