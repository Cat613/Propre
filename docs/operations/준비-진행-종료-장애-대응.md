# 준비·진행·종료·장애 대응

2026-10-05 추가: 외부 AI로 자료를 준비할 때는 [AI 연결·사용·복구 안내](AI에서-ProPre-사용하기.md)를 따른다. 설정에서 세션 권한을 허용하고 로컬 MCP 클라이언트를 연결한다. 새 자료 준비는 현재 선택/송출을 유지하며 송출 중인 현재 자료 수정은 거절한다. 직접 송출은 기존 운영자가 수행한다.

2026-10-04 · 제품 0.1.0 · 실제 앱 검사와 코드 기준. 지정 물리 장비·운영자 리허설은 미실행이다.

## 준비와 진행

1. `ProPre · 컨트롤`을 열고 마지막 자료와 상단 `자동 저장됨` 상태를 확인한다. 복구·누락 안내가 있으면 해당 자료와 미디어를 먼저 확인한다.
2. 새 찬양·슬라이드·성경·파일로 준비한다. 제목·본문·요소·자료 스타일은 자동 저장된다. 새 자료/가져오기/성경 탭 검색은 이전 발표 ID를 상속하지 않는다. 현재 찬양에 말씀을 넣는 `성경 구절 추가`는 같은 자료를 편집한다.
3. 전체 텍스트 편집은 빈 줄로 슬라이드를 나눈다. 열린 캔버스에서도 변경을 반영한다. 자동 적용은 활성 슬라이드의 실제 송출에도 반영되므로 진행 중 편집할 대상을 확인한다.
4. 라이브러리 자료를 순서에 추가하고 정렬한다. 콘티에는 추가 시점의 독립 곡 사본을 저장하며 원곡 수정은 전파하지 않는다. 사본 편집과 저장 실패는 소속·상태로 확인한다.
5. 미디어를 파일 선택으로 등록한다. 이미지·영상·오디오를 구분한다. 누락 자료는 `설정 → 누락 미디어 다시 연결`, 사용하지 않는 파일은 `자료와 최근 백업에서 사용하지 않는 파일 정리`를 사용한다. 정리는 자료·미디어 목록·직전 기록의 참조를 보호한다.
6. 설정에서 메인·모니터 장비를 고르고 송출을 켠다. 각 창은 `ProPre · 메인 송출`, `ProPre · 모니터`로 표시하며 Dock·창 메뉴에서 찾는다. 앱의 적용 상태와 실제 프로젝터/모니터 내용을 함께 확인한다.
7. 일반 슬라이드 클릭, 방향키, Space, 숫자 1~9로 진행한다. 입력·IME·모달에서는 송출 키를 차단한다. 편집 모달 Escape는 변경 반영 후 닫고, 성경 추가 모달 Escape는 추가 없이 닫는다. Tab은 모달 안에서 이동한다.
8. 중단이 필요하면 `모두 지우기` 또는 F2/모달 밖 Escape를 사용한다. 배경·본문·광고·고정 안내·자막·오디오를 중단한다. 실제 스피커와 화면이 멈췄는지도 확인한다.

오디오는 컨트롤 루트의 단일 재생 주체다. 미디어/스타일 탭을 바꿔도 재생을 유지하며 출력 창에 중복 audio를 만들지 않는다. 오디오 파일·소리·음량·반복 상태는 실제 진행 전에 확인한다.

## 찬양 중간에 성경 구절 넣기

찬양 자료를 열고 오른쪽 아래 `성경 구절 추가`를 누른다. `요 3:16`, `시편 23:1-6`, `창 1`처럼 검색하고 본문을 확인해 필요한 구절을 선택한다. `추가 위치`에서 맨 앞·맨 뒤·원하는 슬라이드 뒤를 고른 다음 `N개 구절 추가`를 누른다. 다중 선택이 있으면 목록 순서상 마지막 선택 슬라이드 뒤가 기본값이다.

현재 찬양 ID·제목·가사를 유지하고 결과 항목마다 본문과 구절을 가진 말씀 슬라이드를 만든다. 원본에서 묶인 여러 절은 한 슬라이드로 유지한다. 자동 저장하며 Ctrl/Cmd+Z 한 번으로 이번 추가 전체를 취소할 수 있다. 추가 직후 현재 송출을 유지하며, 모니터의 다음 본문은 새 순서로 갱신한다. 말씀 슬라이드 클릭으로 송출하고 더블클릭으로 본문을 편집한다. 찬양·성경의 스타일 전환은 아래 기본 프리셋 정책을 따른다.

취소·닫기·Escape는 추가하지 않는다. 잘못된/없는/부분 범위는 입력 수정 안내를 표시하며 기존 찬양을 유지한다. 검색 입력을 바꾸면 이전 선택을 지우므로 다시 검색한다. [구현·검증 기록](../quality/2026-10-05-찬양-자료에-성경-구절-추가.md)을 참고한다.

## 모니터의 찬양·성경 표시

`빈 슬라이드 추가`는 본문이 없는 슬라이드를 만든다. 목록의 `(빈 슬라이드)`는 구분용 표시이며 메인·모니터에 송출되지 않는다. 슬라이드를 더블클릭하면 빈 입력창에서 본문을 작성할 수 있고, 작성한 내용은 자동 저장된다.

`설정 → 글로벌 스타일 자동 적용`의 일반/찬양·성경 기본 프리셋은 자료를 열거나 처음 송출할 때 적용한다. 찬양↔성경 종류가 바뀌면 해당 기본 프리셋으로 전환한다. 현재 종류의 기본값을 바꾸면 메인과 모니터에 바로 반영한다. 같은 종류의 슬라이드를 진행하는 동안 직접 조정한 스타일은 유지한다.

`선택 안함` 또는 삭제된 프리셋은 자료에 저장된 스타일을 사용한다. 기본 프리셋은 전역 스타일에 적용하며, 개별 텍스트에서 켠 사용자 스타일은 우선한다. 적용 스타일과 프리셋 설정은 자동 저장한다. [기본 프리셋 검증](../quality/2026-10-05-기본-프리셋-자동-적용-복구.md)에 확인 범위를 기록한다.

모니터는 현재·다음 본문과 시계를 유지하며 선택한 자료의 메인 스타일을 자동으로 반영한다. 찬양은 가사 글꼴·색상·굵기·정렬·줄 간격을 사용하고, 성경은 현재·다음 본문에 각 구절을 함께 표시한다. 구절은 메인에서 선택한 글꼴·색상·위/아래·좌/우 방향을 따르며 본문·시계와 겹치지 않는 별도 줄에 배치한다.

성경 구절 표기는 기존 `성경 출처 스타일` 설정을 사용한다. 본문의 글꼴·색상·크기를 바꾸어도 구절 표기 설정은 함께 바뀌지 않는다.

모니터 본문 크기는 `설정 → 시스템 환경 설정 열기 → 무대 모니터`의 현재/다음 본문 크기를 사용한다. 값은 최대 크기이며 긴 본문과 작은 창에서는 자동으로 줄인다. 메인 본문 크기를 변경해도 모니터의 최대 크기는 별도로 유지한다. 자료 스타일의 변경·본문 송출 해제·모니터 재열기는 자동 반영된다.

배경은 검정, 다음 영역은 어두운 배경의 읽기 구성이다. 텍스트 요소는 읽기 순서로 표시한다. 구절의 미세 픽셀 이동과 캔버스 좌표 대신 모니터 영역 안에서 배치한다. [모니터 스타일 검증](../quality/2026-10-05-모니터-찬양-성경-스타일-연동.md)에서 지원 범위를 확인한다.

## 자동 저장과 종료

| 표시 | 의미·행동 |
| --- | --- |
| 저장 대기 중 | 변경 내용을 반영하고 기록 대기 중. 기본 400ms, 일괄/캔버스는 적용 대기 350/250ms 추가 |
| 저장 중… | Main에서 안전하게 기록 중 |
| 자동 저장됨 | 현재 대기 자료·설정·미디어 기록이 완료됨 |
| 자동 저장 실패 | 창을 유지하고 저장 공간/권한/파일 상태를 확인. 재시도 또는 현재 자료를 다른 위치에 내보내기 |

별도 저장 버튼을 누를 필요는 없다. `파일 → 자동 저장 확인` 또는 Ctrl/Cmd+S로 대기를 즉시 정리할 수 있다. 정상 종료 때는 편집창 적용과 저장 완료를 기다리며 실패하면 종료를 멈춘다. 강제 종료보다 화면의 복구 절차를 사용한다.

컨트롤만 닫으면 메인·모니터의 현재 시각 출력을 유지하고 오디오는 중단한다. Dock에서 컨트롤을 다시 열 수 있다. 앱 전체 종료/재시작은 자료·설정을 복원하지만 마지막 본문/오디오를 자동 송출하지 않는다.

저장 파일이나 앱 데이터 폴더를 삭제해 복구하지 않는다. 저장 실패 상태의 현재 내용을 확인하지 않은 채 백업으로 교체하지 않는다.

## 백업·복원·이동

- `파일 → 파일로 내보내기`: 현재 자료·자료 스타일·참조 등록 미디어를 담은 `.ppros`.
- `파일 → 전체 백업 내보내기`: 모든 자료·작업본·순서·프리셋/설정·등록 미디어를 담은 `.ppros`. 키와 개인 절대 파일 경로는 제외.
- `파일 → 프로젝트 불러오기`: legacy/새 JSON을 읽어 새 자료로 가져오기. 원본 파일/기존 발표는 보존. 필요한 미디어가 포함되어 있는지 확인.
- `파일 → 전체 백업 복원`: 화면의 명시 확인 뒤 현재 자료·순서·설정 교체와 출력 창 중단. 키는 바꾸지 않음. 복원 후 재실행된 화면에서 자료와 장비 확인.
- `파일 → 직전 저장본 복구`: 최근 `.bak1`을 읽어 이전 작업 상태로 복구. 일반 편집은 자료별 Undo도 사용 가능.

현재 로컬 기록 위치는 기존 `pro-presenter-lite` userData다. `workspace-v4.json`과 `.bak1`~`.bak5`, 보존된 `workspace-v1.json`·`workspace-v2.json`·`workspace-v3.json`/백업, `media`, `key-v1.json`은 일반 공유 첨부로 제공하지 않는다. 공유/이동은 앱의 키 제외 백업을 사용한다. 기존 config와 origin별 localStorage는 변환/보존하며 다른 origin 프리셋의 자동 이전을 보장하지 않는다.

운영 저장/IPC 24MiB, 개별 미디어 100MiB, 프로젝트/백업 200MiB 한도다. 전체 미디어가 한도를 넘거나 누락되면 자료를 나눠 내보내거나 미디어를 다시 연결한다. 백업 생성과 실제 복원 결과는 별도로 기록한다.

## AI와 운영 기록

키 없는 AI 버튼은 시스템 환경 설정을 연다. Google 전송 안내와 모델을 확인하고 명시적으로 키를 등록한다. OS 보호 저장을 사용할 수 없으면 새 키의 평문 저장으로 대체하지 않는다. 키·실제 자료·개인 경로를 문서와 로그에 첨부하지 않는다.

실제 장비 리허설·설치·업그레이드·장시간 검사는 [릴리즈 기준](릴리즈-운영-투입-기준.md)과 [검증 양식](../templates/마크다운-산출물-템플릿.md)으로 기록한다. 이번 자동/네이티브 결과는 [후속 검증](../quality/2026-10-04-운영-개선-후속-검증.md)에 있다.

개발 실행 검은 화면의 보완과 실행 복구는 [개발 시작 복구 검증](../quality/2026-10-04-개발-실행-검은-화면-복구-검증.md)에 기록한다. 개발 서버 실행 중에는 해당 실행 창을 유지한다.

## 웹·PDF 송출

[운영 안내](웹-PDF-화면-송출.md)를 따른다. 등록·준비와 송출을 구분하고 PDF 번호/회전·웹 음소거·로그인을 리허설에서 확인한다. 전체 중지/F2는 외부 자료도 중지한다. 전체 백업에는 원본 PDF와 등록 URL이 들어가고 브라우저 로그인은 포함되지 않는다.

## 전체 예배와 업데이트

기도·설교·메모·담당자·연결 자료까지 이동하려면 콘티 더 보기의 `예배 전체로 저장`을 사용한다. 곡 파일 저장은 곡 순서만 담는다. 전체 백업은 휴대용 형식 3으로 예배 계획·자료 사본·템플릿까지 보존한다. [전체 예배 운영 안내](예배-전체-순서-사용-안내.md)에 순서 진행·무대 안내·점검·타이머·템플릿·큐시트 절차가 있다.

앱 업데이트는 컨트롤 하단에서 확인하고 브라우저로 다운로드한다. 무료 방식에서는 예배·송출을 마치고 자동 저장을 확인한 뒤 정상 종료하고 앱을 직접 교체한다. 앱이 자동 설치·재시작하거나 진행 상태를 바꾸지 않는다. [업데이트 안내](앱-설치와-업데이트-배포.md)를 따른다.
