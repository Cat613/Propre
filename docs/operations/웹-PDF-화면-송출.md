# 웹·PDF 화면 송출

[각 기능의 상세 설명](../product/웹-PDF-송출-기능-상세-안내.md) · [최근 검토·개선 기록](../quality/2026-10-13-웹-PDF-송출-검토와-개선-기록.md)

오른쪽 `미디어` 도구의 `송출 자료`에서 기존 이미지·영상·오디오와 웹·PDF를 사용한다. 웹·PDF의 자료 선택과 화면 준비는 현재 송출을 유지한다. `준비 화면 송출`을 눌러야 메인 화면으로 전환한다.

## 웹 주소

1. `URL 추가`에서 이름과 HTTP(S) 주소를 입력하고 `주소 저장`을 누른다. 스킴이 없는 주소는 HTTPS로 보완한다. 이름을 비우면 호스트명으로 저장한다.
2. 웹 자료를 선택하고 `화면 준비`를 누른다. 별도 브라우저 준비 창에서 로그인·스크롤 등 필요한 화면을 준비한다. 같은 인스턴스를 송출에 사용한다.
3. 준비 패널의 뒤로·앞으로·새로고침·확대 또는 `브라우저 조작`을 사용한다. 이동 후에는 `준비 확인`을 누른 뒤 `준비 화면 송출`을 누른다.
4. 송출 중에는 뒤로/앞으로/새로고침/확대가 잠긴다. 다른 주소나 페이지로 이동하려면 먼저 `슬라이드로 복귀`한다. SPA와 페이지 자체의 자동 갱신을 정지시키는 기능은 아니다.
5. 웹 소리는 기본 음소거다. `웹 소리 켜기`는 기존 오디오를 일시정지한다. 복귀 후 기존 오디오는 직접 재생한다.

송출 중 `실시간 조작`을 켜면 컨트롤의 클릭·휠·일반 키가 실제 웹 화면에 적용된다. 복귀·중지·새 송출 때 실시간 조작은 다시 잠긴다. 캡처 미리보기는 최대 5fps이며 실제 화면보다 지연될 수 있다. 한글 IME·페이지 이동은 준비 창에서 수행한다. 웹에서 F2는 전체 중지이고 Escape는 페이지 자체 동작에 맡긴다.

앱 종료 시 브라우저 쿠키·로그인 세션을 버린다. 같은 실행 중 준비 창을 닫으면 숨겨지며 `브라우저 조작`으로 다시 연다. 슬라이드 클릭은 준비 창을 앞으로 가져오지 않으며, 웹 송출에서 슬라이드로 복귀하면 준비 창을 숨긴다. 주소에 로그인 ID/비밀번호를 포함할 수 없고 알려진 인증 query도 저장을 거절한다. 개인 링크 여부는 사용자가 확인해야 한다. 팝업 인증, 파일 업로드/다운로드, 카메라·마이크·화면 공유·위치·클립보드 권한은 지원하지 않는다. 사이트가 내장 브라우저를 거절하거나 DRM을 사용하면 표시·재생이 제한될 수 있다.

## PDF 페이지

1. `PDF 추가`에서 파일을 선택한다. 암호가 없는 100MiB 이하·1~1,000페이지 문서를 지원한다. 첫 페이지 파싱·렌더까지 확인한 뒤 앱 관리 폴더에 복사한다.
2. 자료 선택 후 썸네일이나 페이지 번호를 선택해 준비한다. 썸네일은 현재 번호 주변 6페이지씩 표시한다. 준비 이전/다음과 90도 회전을 지원한다.
3. `화면 준비` → `준비 화면 송출`로 전환한다. 페이지는 검은 여백 안에 전체가 보이도록 맞춘다.
4. 송출 중 `송출 이전/다음`은 실제 송출 PDF의 페이지를 바꾼다. 마지막 페이지에서 다음은 비활성화한다. 준비 페이지 선택은 실제 송출을 바꾸지 않는다. 송출 이전/다음은 송출에 확정한 회전을 유지하고 별도로 선택한 준비 페이지·회전을 바꾸지 않는다.
5. 모니터에는 현재·다음 PDF 페이지가 표시된다. 웹은 자료명과 호스트·송출 상태를 표시한다.

원본 파일을 옮기거나 지워도 복사한 PDF는 유지된다. 앱 내부 파일이 누락되면 설정의 `누락 미디어 다시 연결`에서 같은 형식의 PDF를 선택한다. 새 파일의 페이지 수·hash를 확인하고 준비 번호를 범위 안으로 보정한다. 송출 중 자료 수정·삭제·재연결은 거절한다.

## 복귀·중지·실패

- `슬라이드로 복귀`는 현재 슬라이드·레이어를 다시 표시한다. 기존 곡·콘티·draft·편집 이력은 외부 자료 준비로 바뀌지 않는다.
- 기존 슬라이드 또는 이미지·영상을 실행하면 해당 슬라이드 모드로 복귀한다. 오디오만 실행하면 화면 소스를 유지한다.
- `전체 중지` 또는 F2는 웹·PDF·오디오·레이어와 대기 작업을 모두 중지한다. 브라우저 focus나 컨트롤 입력칸에서도 F2를 사용할 수 있다. 웹은 다시 준비해야 한다.
- F1 텍스트/F4 배경 지우기는 기존 슬라이드 레이어에 적용된다. 외부 자료 위에는 가사·공지·props·message를 합성하지 않는다. 크로마키 설정도 외부 자료의 색을 바꾸지 않는다.
- PDF 렌더나 웹 로딩 실패 시 기존 송출을 유지하고 준비 패널에서 재시도한다. 웹 renderer 중단 시 마지막 캡처가 있으면 정지 화면을 표시하며 경고는 컨트롤에 나타난다. 즉시 슬라이드로 복귀할 수 있다.
- 재시작 시 자료 목록과 마지막 PDF 준비 페이지는 복원하지만 외부 자료를 자동 접속·송출하지 않는다.

## 저장과 백업

새 기록은 `workspace-v4.json`이다. 이전 v1/v2/v3 파일과 백업은 보존한다. 전체 `.ppros` 백업에는 PDF 원본과 등록 웹 주소가 들어가고 쿠키·탐색 이력·실시간 입력·캡처·API 키는 들어가지 않는다. 최종 JSON/base64를 포함한 200MiB 한도를 적용한다. 기존 단일 곡·콘티 파일에는 외부 자료를 넣지 않는다.

구버전 앱은 v3를 읽지 못한다. 같은 데이터 폴더에서 구버전과 신버전을 번갈아 사용하면 자료가 갈라질 수 있으므로 업데이트 후에는 새 버전을 사용한다. 문서 변환이 필요한 PPT/Word/Excel/한글은 PDF로 내보내 등록한다. 창/화면 공유는 이번 구현 범위에 포함되지 않는다.

## 준비 패널·크기 조절·삭제 되돌리기 (2026-10-13)

- 컨트롤 안의 `준비 패널 닫기` 또는 선택한 자료를 다시 누르면 준비 패널을 접는다. 웹 창·등록 자료·현재 송출은 유지하고 현재 송출의 복귀/중지 도구도 남긴다.
- 별도 웹 준비 창은 가장자리로 크기를 조절한다. 웹 내용이 함께 맞춰지고 크기 변경 후 준비 확인이 필요하다. 확인을 누르거나 다시 열어도 조절한 크기를 유지한다. 실제 송출은 메인 창 크기에 맞춰 다시 배치될 수 있다.
- `자료 삭제`는 복원 상태로 저장하며 `삭제 되돌리기` 또는 삭제 뒤 웹·PDF 영역의 Ctrl/Cmd+Z로 복원한다. 재시작·전체 백업에서도 복원 상태를 유지한다. 삭제한 PDF 원본은 미디어 정리에서 제거하지 않는다.
- 이전 방식으로 이미 삭제된 자료도 복원 항목이 없다면 같은 버튼에서 최근 저장 복사본 5개를 조회한다. PDF 원본과 hash가 남아 있는 경우 자료만 복원하며 현재 곡·콘티·설정을 이전 상태로 되돌리지 않는다. 남은 복사본이 없으면 전체 백업 또는 원본으로 복구한다.

## 2026-10-15 준비·입력·오디오 개선

- PDF 준비 응답이 늦게 돌아오더라도 현재 선택한 자료·revision·페이지·회전과 일치할 때만 송출할 수 있다. 준비 중 페이지 번호를 바꾸면 이전 결과는 송출에 사용할 수 없다.
- 페이지 번호는 1부터 전체 페이지 수 사이의 정수여야 한다. 빈 값·소수·범위 초과는 입력칸 아래에 안내하며 준비·송출을 막는다.
- 다른 자료를 선택하면 열려 있던 주소 수정 폼을 닫고 저장 전 입력을 취소한다. 주소 수정 폼에는 대상 이름을 표시한다.
- 웹 소리와 로컬 오디오는 한 번에 한 소스만 재생하도록 전환한다. 웹 소리를 켜면 로컬 오디오를 일시정지하고, 플레이어 재생 또는 미디어 오디오 선택으로 로컬 오디오를 켜면 웹을 음소거한다. 화면 소스는 웹으로 유지된다. 로컬 재생을 위해 웹 음소거가 필요하지만 실패하면 재생을 보류하고 안내한다.
- 웹 소리는 송출 패널에, 로컬 오디오 상태는 플레이어에 표시한다. 플레이어 숨김 설정에서는 기존처럼 소리 재생을 유지하며 F2/전체 중지로 함께 멈춘다.
