# 미디어에서 음악 준비와 재생

작성: 2026-10-17 · 현재 개발 작업 트리 기준 · 실제 Chrome 계정·음향 수용은 별도

## 화면 찾기

중앙 편집 상단 오른쪽은 `현재 송출` 미리보기다. 왼쪽 제목은 편집 중인 자료이고 오른쪽은 실제 송출 화면이므로 서로 다를 수 있다. `확대`로 크게 보고 Escape/닫기로 복귀한다. 작은 패널에서는 미리보기 화면을 접고 상태·확대·중지 도구를 유지한다.

오른쪽 `미디어 → 음악`에서 음악을 관리한다. 전체 분류에서는 `예배 음악 준비·관리`로 들어갈 수 있다. 상단의 작은 `음악` 버튼은 다른 도구 탭에서도 음악 분류로 이동한다. 대기 중 상태 표시는 설정에서 끌 수 있지만 활성/미확인 소리의 중지 도구는 유지한다.

중앙 편집 도구의 `이미지·영상`은 슬라이드 추가이고, 오른쪽 미디어는 자료 등록·배경/음악 관리다.

## 로컬 음악 준비

1. 콘티 보관함에서 예배를 만들거나 연다.
2. `미디어 → 음악 → 파일 음악 추가`에서 파일을 선택한다.
3. 이름, 시작/끝 시간, 기본 음량, 구간 반복, 줄여 멈춤 시간을 확인하고 `음악 저장`을 누른다. 끝을 비우면 곡 끝이다.
4. 목록의 음악 이름을 누르면 다음 음악으로 준비한다. 이때 소리는 나지 않는다. 파일을 읽거나 구간을 확인하지 못하면 현재 음악을 유지하고 오류를 안내한다.
5. `준비한 음악 재생` 또는 `전환해 재생`으로 실제 시작한다. 다음 준비와 현재 음악은 별개다.

이미 등록된 오디오를 전체 미디어에서 선택하면 해당 예배 음악으로 등록·준비하며 즉시 재생하지 않는다. 이미지/영상 배경 선택의 기존 동작은 유지한다. 파일 선택 취소는 아무것도 재생하지 않는다.

## 진행 중 조작

- 일시정지/이어 재생: 현재 위치를 유지한다. 미디어가 아닌 스타일·레이어·설정 탭을 열어도 단일 재생 엔진이 유지된다.
- 처음부터: 지정한 시작 위치로 돌아간다. 멈춘 상태이면 그대로 멈춰 있다.
- N초간 줄여 멈춤: 로컬 음량을 줄인 뒤 일시정지한다. 이어 재생하면 마지막 현재 음량으로 돌아온다.
- 현재 음량: 지금 재생에 즉시 적용한다. 항목 설정의 기본 음량/구간/반복 수정은 다음 재생부터 적용된다.
- 음악 중지: 화면은 유지하고 음악을 중단한다. 외부 중단을 확인하지 못하면 브라우저 확인이 필요하다.
- 전체 중지/F2: 화면·음악을 함께 중단한다. 폼 입력 중이거나 확대 미리보기가 열려 있어도 동작한다.

Look의 소리 숨김 후 다시 표시해도 자동으로 이어 재생하지 않는다. 검은 화면 전환만으로 음악을 멈추지는 않는다. 로컬 음원은 macOS 기본 오디오 장치로 나간다. 헤드폰 전용 미리듣기 기능은 없으므로 시험 재생은 실제 스피커로 들릴 수 있다.

## 유튜브 뮤직

`유튜브 뮤직 링크`에서 곡 또는 재생목록의 music.youtube.com HTTPS 주소와 이름을 저장한다. 로컬 대체 음원을 선택해 연결할 수 있다. 링크 저장만으로 브라우저에 접속하거나 음악을 재생하지 않는다.

현재 제공되는 것은 개발용 연결 확장과 앱 브리지다. `브라우저 연결 → 확장 폴더 열기`에서 확장 소스를 찾고 [설치·연결 안내](../../browser-extension/youtube-music/README.md)에 따라 Chrome 개발 확장을 설치한다. 확장 ID를 앱에 입력해 연결 프로그램을 설정한 뒤, 브라우저에서 직접 로그인하고 준비한 탭을 확장 팝업으로 연결한다. 확장 ID 고정·일반 사용자 배포는 별도 수용 전이다.

앱은 실제 연결·현재 곡/목록 대상·재생 상태를 확인한 경우에만 재생 버튼을 활성화한다. 볼륨은 브라우저에서 조절한다. 계정·쿠키를 앱에 붙여넣지 않는다. 실제 서비스 화면 변경이나 자동재생 제한으로 제어가 실패할 수 있으며 현재 로컬 검사가 실제 계정 재생 성공을 뜻하지 않는다.

연결이 끊겨도 브라우저 음악은 계속 나올 수 있다. 브라우저에서 먼저 멈추고 앱에서 해당 상태의 수동 정지 확인을 한 뒤 대체 음원을 시작한다. 대체는 구간 시작부터 재생하며 스트리밍과 같은 위치로 자동 맞추지 않는다. 인터넷 끊김만으로 대체 음악을 갑자기 재생하지 않는다.

## 저장·복구·예배 연결

음악 목록은 예배별이다. 예배 복제·템플릿·예배 파일·전체 백업에 설정과 참조 음원이 포함된다. 새 개발 작업 트리는 workspace-v5/휴대용4를 사용하고 이전 v4 원본은 보존한다. 구버전 앱에서 새 파일을 읽을 수 있다고 가정하지 않는다. 예배 파일에는 실제 연결 탭·계정·현재 재생 위치·인증 정보를 넣지 않는다.

순서 편집의 `진행할 때 준비할 음악`을 연결하면 해당 순서를 실제 진행했을 때 다음 음악으로 준비한다. 자동 재생하지 않는다. 순서의 소리 정책을 중지로 설정하면 관리 소리 중단을 요청한다. 외부 미확인 상태는 상단 음악 도구에서 확인한다.

목록 삭제는 현재 실행 사본을 멈추지 않는다. `음악 삭제 되돌리기`는 해당 항목만 복원하고 삭제 뒤 다른 음악에 한 수정은 유지한다. Undo는 세션 내에서 제공하며 자동 재생하지 않는다. 파일이 없으면 설정의 `파일 다시 연결`로 복구한다. 종료는 저장과 외부 중단 확인을 기다리며, 실패하면 창 유지 또는 외부 소리 잔류를 확인하고 종료할 수 있다. 재시작은 목록만 복원하며 자동 재생하지 않는다.


### 연결됐는데 준비한 음악 재생이 비활성화된 경우

탭 연결과 재생 대상 준비는 별개다. 연결된 Chrome 탭에서 앱에 등록한 곡·재생목록을 열어야 한다. 다른 곡/목록이 준비돼 있으면 재생 버튼을 비활성화하고, 현재 브라우저 곡과 등록한 항목 이름을 안내한다. 플레이어를 읽을 수 없는 경우에는 탭 연결 실패와 구분해 표시한다. 브라우저에서 곡을 직접 재생하면 즉시 소리가 날 수 있으므로, 준비 단계에서는 앱의 명시적 재생과 구분한다.


### Chrome에서 링크 준비 (2026-10-18)

음악 항목의 `더 보기 → 재생 없이 연결`와 외부 음악 복구의 링크 열기는 macOS에서 Chrome 앱을 명시해 연다. 시스템 기본 브라우저가 Whale이어도 Chrome을 사용하며 기본 브라우저 설정을 변경하지 않는다. Chrome 실행 실패 시 오류를 표시한다. 앱의 음악 항목에서 재생 또는 재생 없이 연결로 연 탭은 확장이 자동으로 연결한다. 외부 음악 복구의 `브라우저 확인`은 상태를 직접 확인하기 위한 링크 열기로, 연결 대상을 자동으로 바꾸지 않는다. 앱의 Main 코드 변경이므로 이미 실행 중인 앱에는 정상 종료 후 다시 실행해야 적용된다.


### 앨범·재생목록을 한 번에 재생

1. 앨범·재생목록 링크를 등록합니다.
2. 음악 카드의 `재생`을 누릅니다. 연결된 탭이 없거나 다른 곡이 연결돼 있어도 해당 링크를 Chrome에 열고 자동 연결한 뒤 첫 재생까지 처리합니다.
3. 이후 현재 음악의 일시정지·이어 재생·음악 중지를 사용합니다.

별도의 제목 선택이나 Chrome 준비 단계는 필요하지 않습니다. 무음 준비가 필요하면 제목을 선택하고, 재생 없이 Chrome에 연결할 때는 카드의 `더 보기 → 재생 없이 연결`을 사용합니다. 설정·위로 이동·삭제도 `더 보기` 안에 있습니다.

첫 로딩 동안 `재생 확인 중…`이 표시되며 최대 12초 기다립니다. 음악 중지는 로딩 중에도 가능합니다. 링크 등록·준비만으로는 소리가 나지 않습니다. 이미 같은 목록의 곡이 로드됐다면 기존 위치에서 이어 재생합니다.

확장 업데이트 후 Chrome 확장 프로그램 관리에서 ProPre 음악 연결 확장을 새로고침하고 유튜브 뮤직 탭도 새로고침한 뒤 다시 연결해야 합니다. 앱 코드 업데이트도 다시 실행해야 적용됩니다. Chrome 로그인·재생 제한 또는 유튜브 뮤직 화면 변경으로 시작하지 못하면 브라우저에서 직접 재생해 확인해주세요.

빈 플레이어와 실제로 로드된 곡을 구분합니다. 재생 확인 중 및 재생 실패는 일시정지와 다르게 표시하고, 연결 설정 완료 안내가 재생 오류를 가리지 않도록 각각 표시합니다.


### Chrome 탭 자동 연결

확장 설치와 앱의 `연결 프로그램 설정`은 처음 한 번 필요합니다. 이후에는 음악 항목의 `더 보기 → 재생 없이 연결`를 누르면 그 항목이 다음 음악으로 준비되고, Chrome에서 해당 링크가 열리며 자동 연결됩니다. `Chrome 연결 중…` 다음 `Chrome 탭 연결됨`이 표시되는지 확인합니다. 준비만으로는 소리가 나지 않습니다. 기존에 연결된 외부 음악이 있다면 중단 확인 후 새 탭으로 바꿉니다. 기존 로컬 파일 음악은 연결 준비만으로 중단하지 않습니다.

30초 내에 연결이 확인되지 않으면 확장 설치·새로고침과 연결 프로그램 설정을 안내합니다. Chrome에 직접 연 일반 탭은 자동으로 인수하지 않으며, 필요하면 확장 팝업에서 수동 연결할 수 있습니다. 앱과 확장을 업데이트한 뒤에는 앱 재시작과 확장 새로고침이 필요합니다. 이후 새로 준비한 탭은 별도 새로고침 없이 자동 연결됩니다.

### 새 음악 화면

상단의 현재 음악 플레이어에서 곡과 상태를 확인하고 일시정지·이어 재생·중지를 실행합니다. 긴 제목은 두 줄까지 표시되며 전체 제목과 브라우저 음량 안내는 재생 정보에서 볼 수 있습니다. 로컬 파일은 진행 시간을 확인하고 음량을 바로 조절하며, 처음부터·줄여 멈춤은 재생 설정에서 사용합니다.

음악 목록 오른쪽의 `추가`에서 파일 또는 YouTube Music 링크를 등록합니다. 목록 각 행의 ▶로 바로 재생하며, 현재 음악의 버튼은 일시정지와 이어 재생을 처리합니다. ⋯ 메뉴는 설정·재생 없이 연결·이동·삭제를 제공합니다. 제목 선택은 소리가 나지 않는 다음 준비입니다. 선택된 표시와 실제 재생 상태는 구분됩니다. 메뉴는 Escape로 닫을 수 있습니다.

연결 상태는 음악 제목 오른쪽에서 확인하고 해당 버튼으로 설정을 엽니다. 연결이 미확인인 경우 브라우저 확인과 직접 중단 확인 복구 안내를 따릅니다.
