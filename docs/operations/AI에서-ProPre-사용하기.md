# AI에서 ProPre 사용하기

2026-10-05 · REQ-034 / TASK-029 · [설계와 계약](../engineering/AI-연결-설계와-계약.md) · [검증](../quality/2026-10-05-AI-로컬-연결-자료-준비-구현과-검증.md)

## 처음 연결하기

1. 새 빌드의 ProPre를 연다. 개발 환경은 프로젝트에서 `npm run dev`, 로컬 앱은 `release/0.1.0/mac-arm64/ProPre.app`을 사용한다.
2. 컨트롤의 **설정 → 시스템 환경 설정 열기 → AI 연결**로 이동한다.
3. 조회/미리보기만 사용할지, 새 자료·본문·스타일·진행 순서의 준비까지 허용할지 선택하고 **AI 연결 허용**을 누른다.
4. 사용할 AI 클라이언트를 선택하고 **연결 설정 복사**를 누른다. Codex는 TOML, 다른 MCP 클라이언트는 `mcpServers` JSON을 복사한다.
5. Codex는 MCP 설정 파일의 기존 항목을 유지하면서 복사한 `propre` 항목을 추가하고 MCP 서버를 다시 연결한다. 다른 클라이언트는 해당 제품의 로컬 MCP 서버 설정에 추가한다. 설정의 실행 경로와 `ELECTRON_RUN_AS_NODE=1`을 함께 유지한다. 별도의 Node 설치나 ProPre용 AI API 키는 필요하지 않다.
6. 연결 상태가 **AI 연결됨**으로 바뀌는지 확인하고 설정창을 닫는다. AI에서 “ProPre 상태와 자료 목록을 보여줘”로 확인한다.

앱을 다시 시작하면 연결 허용은 꺼진다. 다시 허용한 뒤 AI 클라이언트의 MCP 서버를 재연결한다. 설치 위치를 옮기거나 개발 앱에서 패키지 앱으로 바꾼 경우 연결 설정을 다시 복사한다. 한 설정은 복사한 앱과 그 앱의 데이터 디렉터리에 연결된다.

현재 연결은 같은 컴퓨터의 MCP 클라이언트용이다. ChatGPT 웹의 원격 플러그인 연결을 이 로컬 설정만으로 제공하지 않는다. 실제 클라이언트 제품의 메뉴/계정 지원은 [공식 로컬 MCP 문서](https://learn.chatgpt.com/docs/extend/mcp?surface=cli)를 따른다.

## 준비 작업 예시

- “ProPre에서 제목에 ‘찬양’이 들어간 자료를 찾아줘.”
- “아래 가사를 빈 줄마다 슬라이드로 나눠 ‘주일 찬양 준비’라는 새 자료로 저장해줘. 현재 송출은 유지해줘.”
- “ProPre 성경 자료에서 요한복음 3장 16절을 조회하고 새 말씀 자료로 만들어줘.”
- “방금 만든 찬양 → 말씀 → 찬양 순서로 진행 순서를 구성해줘.”
- “찬양의 첫 슬라이드 미리보기를 보여줘.”
- “자료를 다시 조회해서 둘째 슬라이드의 본문을 아래 문장으로 수정해줘.”

성경은 앱에 포함된 원문을 조회하며 존재하지 않는/부분적으로만 덮인 절 범위는 거절한다. 내장 원문 출처·배포 권리·원문 품질이 확인 완료되었다는 뜻은 아니다.

새 자료는 라이브러리에 추가하며 현재 선택과 송출을 바꾸지 않는다. AI에서 미리보기로 확인한 뒤 앱의 자료 목록에서 열어 검토하고 기존 클릭 송출 절차를 사용한다. 미리보기에는 기본 프리셋과 종류 전환의 스타일 선택 규칙을 적용하며, 실제 프로젝터 적용 여부는 별도로 확인한다.

본문·제목·스타일·슬라이드 추가를 일괄 수정할 수 있다. 현재 자료가 활성 슬라이드/레이어/오디오 또는 열린 메인·모니터에 사용되고 있으면 수정은 거절한다. 다른 자료나 새 자료는 준비할 수 있다. 현재 자료를 수정하려면 운영자가 송출을 중단하고 필요한 출력 창을 닫은 뒤 요청한다. AI가 송출을 중단하는 도구는 제공하지 않는다.

열려 있는 현재 자료의 AI 일괄 수정은 한 번의 Undo로 되돌린다. 다른 자료의 수정은 기존 직전 저장 백업에 남지만 현재 자료의 Undo 이력을 소비하지 않는다. 진행 순서 구성은 교체 작업이며 순서에 같은 자료를 여러 번 포함할 수 있다.

## 상태와 실패에서 돌아오기

| 상태/오류                        | 다음 행동                                                                                                                                                   |
| -------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 연결 꺼짐 / 연결할 수 없음       | ProPre 컨트롤을 열고 AI 연결을 허용한 뒤 클라이언트 서버를 재연결한다.                                                                                      |
| 연결 대기 중                     | 복사한 설정을 클라이언트에 추가했는지, 실행 경로가 현재 앱인지 확인한다.                                                                                    |
| 조회 권한만 허용됨               | 앱에서 연결을 해제하고 자료 준비 권한으로 다시 허용한 뒤 재연결한다.                                                                                        |
| 운영자 편집 중                   | 입력·캔버스·일괄 편집·시스템 설정창을 닫고 다시 요청한다.                                                                                                   |
| 수정 버전 충돌                   | AI가 최신 자료/순서를 다시 조회하고 변경 내용을 새 요청으로 적용하게 한다.                                                                                  |
| 현재 송출 자료 보호              | 다른 자료 또는 새 자료를 준비한다. 현재 자료 수정이 필요하면 운영자가 송출/창 상태를 정리한다.                                                              |
| 새 자료/순서 저장 실패           | 이전 확정 상태가 유지된다. 저장 공간·접근 권한을 해결하고 목록을 다시 확인한 뒤 새 요청으로 실행한다.                                                       |
| 현재 자료 수정 반영 후 저장 실패 | 편집본과 복구 기록은 유지된다. 앱의 자동 저장 오류에서 **재시도**, 필요하면 파일 내보내기를 사용한다. AI는 `applied: true`를 반환한다.                      |
| 결과 확인 불가                   | 새 자료를 바로 다시 만들지 않는다. 같은 requestId 재시도와 자료 목록/현재 상태를 확인해 중복 작업을 피한다. 결과 확인 불가 응답이 유지되면 앱에서 확인한다. |
| 세션 작업 한도                   | 500개 변경 요청 한도다. 연결을 다시 허용/재연결한 뒤 자료를 재조회한다.                                                                                     |
| 미리보기 실패                    | 앱에서 슬라이드와 등록 미디어를 확인한다. 누락/디코딩 오류를 빈 화면 성공으로 취급하지 않는다.                                                              |

앱의 **AI 연결 해제**는 이후 요청을 차단한다. 이미 적용·저장을 시작한 요청은 완료될 수 있으므로 최근 작업과 자료 상태를 확인한다. requestId의 중복 방지는 같은 연결 세션 안에서만 유지된다. 앱/연결 세션을 다시 시작한 뒤에는 자료를 재조회하고 새 작업 여부를 판단한다.

## 데이터와 접근 범위

조회에는 자료 제목·본문·식별자·스타일·진행 순서와 준비 미리보기가 포함되며 연결한 AI 서비스가 처리할 수 있다. API 키·개인 파일 경로·등록 미디어 원문은 도구 결과에 제공하지 않는다. AI에 전체 파일/폴더 접근·자료 삭제·백업 복원·외부 네트워크·직접 송출 권한을 주지 않는다.

연결 설정에는 인증 토큰이 없다. 세션 인증 파일은 Main이 소유자 전용 권한으로 기록하고, 연결 해제/종료 때 삭제하며 백업에서 제외한다. AI 찬양 준비용 제공자별 API 키는 OS 보호 저장소를 사용한다. 이전 Gemini 키는 Gemini 연결이 읽을 수 있도록 보존하며 이전 단일 이미지 추출 UI와 전용 분석 경로는 제거했다.
