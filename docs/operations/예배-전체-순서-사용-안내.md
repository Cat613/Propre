# 예배 전체 순서 사용 안내

2026-10-16 · WSP-01 로컬 구현 · [설계와 진행 상태](../design/worship/README.md)

현재 로컬 작업 트리의 기능 안내다. 배포본에 모두 포함되었다는 뜻은 아니다. 큐시트의 파일 이동과 웹·PDF 사본 송출을 격리 앱에서 검증했다. 실제 예배 장비 수용은 별도다.

## 순서 준비

현재 콘티에서 `곡 / 전체 순서`를 선택한다. 기존 콘티의 첫 진입은 곡 보기, 새 콘티는 전체 순서가 기본이며 콘티별 선택을 기억한다. 전체 순서에서도 Songs의 ＋로 찬양을 넣을 수 있다.

`순서 추가`에서 기도·봉독·설교·헌금·광고·기타를 고르고 제목을 입력한다. 시간은 미정으로 둘 수 있다. 담당자·운영 메모·송출 자료·화면 정책은 상세를 펼쳐 설정하고 `순서 추가` 또는 `변경 저장`으로 함께 적용한다. 입력 중 초안은 이 컴퓨터의 복구 기록에 남고, 취소를 누르면 해당 입력 초안을 버린다. 추가/저장 실패 시 입력을 유지한다.

행 클릭과 Enter는 순서 선택이다. 현재 송출은 바뀌지 않는다. 선택한 행 아래에서 편집·위/아래 이동·제거를 할 수 있고, 최근 순서 편집은 되돌릴 수 있다. 위/아래는 선택을 이동하고 Alt+위/아래는 선택한 순서의 위치를 바꾼다. 진행 중인 순서의 삭제·자료 교체는 다른 순서로 전환하거나 예배를 마친 뒤 할 수 있다.

운영 메모는 청중용 하단 자막과 별개다. 운영 메모는 Control에서만 표시한다. 별도 무대 안내 초안을 저장하고 아래의 명시 전송 흐름으로 Stage에 보낼 수 있다.

## 자료 연결과 진행

비곡 순서에는 찬양·성경 자료 또는 등록된 웹·PDF를 연결할 수 있다. 연결 시 예배 소유 사본을 만든다. 자료를 연결했다고 자동으로 송출하지 않으며 `진행할 때 화면`을 `연결 자료 송출`로 바꾼 경우에만 진행 시 사용한다. PDF는 시작 페이지를 선택한다. 연결된 PDF의 시작 페이지·회전과 발표의 시작 슬라이드는 순서 편집에서 바꿀 수 있다.

1. 진행할 행을 선택한다.
2. `준비 확인`으로 저장·참조·송출 세대를 점검한다.
3. `이 순서 진행`을 누른다. 출력 적용 확인이 끝나면 진행 중 상태가 바뀐다.
4. `다음 순서 준비`로 다음 미진행 행을 선택하고 같은 방식으로 준비·진행한다. 선택만으로 자동 진행하지 않는다.

준비 이후 계획·자료·송출 화면이 바뀌면 다시 준비해야 한다. `현재 화면 유지`는 현재 시각 출력을 유지하며 순서 기록만 진행한다. 배경만 유지와 검정 화면은 본문·광고·청중 자막·props를 지운다. 검정 화면은 크로마키 색상보다 우선한다. 소리 유지 정책에서도 웹을 다른 시각 source로 전환할 때는 기존 웹 음소거 정책을 따른다.

`예배 마치기`는 진행 기록을 마감한다. 청중 화면과 오디오를 중단하려면 기존 `전체 중지`를 사용한다. 전체 중지는 진행 중인 예배를 중단 상태로 바꾸고 늦은 실행 결과가 다시 표시되지 않게 한다. 다시 시작하려면 원하는 순서를 새로 준비한다.

## 저장·복구·파일

새 기준 파일은 workspace-v4.json이다. 이전 v1/v2/v3 원본과 최근 백업을 보존해 이전한다. 기존 콘티 곡과 사본의 ID·가사·스타일은 유지한다. 예전 앱으로 돌아가면 예전 파일을 읽어 새 편집은 표시되지 않는다.

전체 백업은 portable schema 3으로 계획·비곡 자료 사본·참조 assets를 보관한다. 기존 백업 1/2는 계속 읽는다. 곡 파일 저장은 기존 playlist 형식으로 곡만 담으므로 기도·설교·메모·시간은 제외된다. 관련 내용이 있으면 곡만 저장할 것인지 안내한다. 콘티 더 보기의 `예배 전체로 저장`은 메모·담당자·연결 자료까지 포함한 한 예배 파일이다. `예배 파일 불러오기`로 새 독립 콘티를 만든다. 현재 편집·송출은 바꾸지 않는다. 공유 전에 비공개 메모 포함 여부를 확인한다.

앱을 다시 시작하면 진행 체크포인트는 중단 상태로 복구한다. 실제 화면·소리·일시 안내를 자동으로 재생하지 않는다. 종료한 예배의 진행 기록은 별도 로컬 요약에 예배당 최근 20회, 전체 2MiB 이내로 보관하며 메모 본문을 넣지 않는다. 무료 업데이트는 브라우저에서 다운로드하고 예배·송출 종료 후 앱을 정상 종료해 직접 교체한다. 앱이 자동 설치·재시작하지 않는다.

파일을 다른 내용으로 재연결하면 과거 예배 사본까지 바뀌므로 사본에서 사용하는 파일은 새 자료로 등록해 교체한다. 같은 바이트의 파일 복원은 허용한다.

검사 결과와 실장비 한계는 [P1 최종 기록](../quality/2026-10-16-예배-파일-전환-조작-검증.md)에 구분한다.

## 무대 전용 안내

순서 편집에서 `무대 안내 초안`을 저장할 수 있다. 초안이나 운영 메모는 순서를 진행해도 자동 전송하지 않는다. 전체 순서의 `무대 안내 · 청중 비공개`를 펼쳐 문구와 유지 시간을 확인하고 `무대에 보내기`를 누른다. Stage가 닫혀 있으면 먼저 `무대 화면 열기`를 사용한다.

120자·현재 Stage 크기 기준 두 줄 이내 문구를 지원한다. 기본20초 후 지우며 직접 지울 때까지 유지도 선택할 수 있다. 입력을 고치는 동안 현재 안내는 그대로이며 명시 교체해야 바뀐다. Control 상단의 현재 안내/지우기는 다른 보기에서도 사용할 수 있다. 표시 확인 중·확인 필요를 실제 표시 성공으로 해석하지 않는다. F2/전체 중지·앱 재시작은 일시 안내를 제거한다. 저장 초안은 보존한다. 청중 화면에는 이 안내를 보내지 않는다.

## 사전 점검

전체 순서 상단의 `사전 점검`에서 검사를 시작한다. 파일 누락·자료 연결·PDF 페이지·본문 크기/요소 경계·출력 창 상태를 확인하며 웹에 자동 접속하거나 송출을 바꾸지 않는다. 문제 순서의 `수정하기`로 이동할 수 있고 돌아온 결과는 유지된다. 자료·설정·화면·글꼴이 바뀌면 `재검사 필요`이므로 다시 검사한다.

실제 메인/무대 화면, 소리, 전체 중지 리허설은 현장에서 확인한 뒤 각각 체크한다. 경고는 직접 확인해 남겨둘 수 있지만 차단 오류는 해결해야 한다. 준비 완료는 자동 검사와 수동 체크·저장이 끝났다는 뜻이며 실제 장비를 앱이 보증한다는 뜻은 아니다. 검사 취소/부분 결과와 지난 앱 실행의 요약은 준비 완료로 사용하지 않는다. 저장 실패 때는 다시 검사하거나 입력을 저장한 뒤 재시도한다.

## 구간 바로가기

슬라이드 목록 위 `구간 · 선택 후 준비`를 펼친다. 절/후렴/브릿지를 고르면 해당 첫 슬라이드에 구간 준비 표식을 표시하며 송출은 유지한다. `이 구간 송출`로 실행한다. 후렴이 반복되면 현재 라이브 뒤의 가장 가까운 후렴을 고르고 발생 목록에서 첫/중간/마지막을 직접 선택할 수 있다. 다음 가사는 원래 배열의 다음 슬라이드다.

`구간 클릭 즉시 송출`은 켠 경우 칩/발생 선택 즉시 송출하며 영역에 즉시 송출 표식을 유지한다. 앱/Control을 다시 열면 기본 준비 모드다. 내용·순서·출력이 바뀌면 구간을 다시 선택해야 한다. 송폼이 불완전하면 현재 라벨을 사용한다는 안내를 확인한다. 구간 송출은 예배 진행 순서를 자동 이동시키지 않는다.

## 진행 타이머

순서를 진행하면 접힌 타이머 표시줄에 실제 경과가 나타난다. 펼쳐 `타이머 시작`을 누르면 예상 시간의 카운트다운 또는 미정인 경우 카운트업을 사용할 수 있다. 일시정지는 해당 타이머만 멈추며 실제 순서 경과는 이어진다. 초기화는 타이머 카운트만 지운다. 0초 뒤에는 초과로 계속 표시하며 다음 순서로 자동 이동하지 않는다.

`타이머 +1분`은 타이머 목표만 늘린다. 계획 시간과 현재 타이머 목표를 따로 확인한다. 계획을 편집한 뒤 현재 타이머도 바꾸려면 `현재 순서 설정을 타이머에도 반영`을 누른다. 순서 편집의 타이머 설정에서 자동 시작을 명시할 수 있으며 기본은 꺼짐이다.

무대 창을 열고 `타이머 무대 표시`를 켜면 청중과 별개인 Stage 영역에 표시한다. 전체 중지/F2·절전은 pause와 무대 표시 끄기이며 재개는 직접 누른다. 앱 재시작도 마지막 확인 checkpoint에서 일시정지로 복구하고 무대에는 자동 표시하지 않는다. 저장 오류를 해결한 뒤 재시도한다. 실제60분 정확도·실제 절전/장비 검증은 별도 수행해야 한다.

## 예배 템플릿

콘티 더 보기의 `템플릿으로 저장`에서 이름·설명을 정하고 재사용할 자료만 `고정 자료 포함`으로 선택한다. 기본은 매번 채우기 슬롯이다. 담당자/운영 메모/무대 초안은 기본 제외이며 포함하려면 상세에서 명시한다. 고정 자료는 저장 당시의 독립 사본이다.

`예배 템플릿` 또는 새 콘티의 `템플릿으로 만들기`에서 선택해 새 예배를 만든다. 입력한 새 콘티 이름/날짜는 템플릿 흐름에도 유지한다. 슬롯을 나중에 채울 수 있지만 필수 자료가 비면 해당 순서의 준비/진행이 차단된다. 생성 후 해당 순서 편집에서 자료를 연결한다. 비곡은 자료 없이 현재 화면을 유지할 것을 명시할 수 있다.

관리 화면에서 이름/설명·순서·슬롯/고정 자료·메모를 수정하고 복제·휴지통·복원할 수 있다. 기존 예배는 바뀌지 않는다. 템플릿 파일은 수정 가능한 구조와 선택한 메모/고정 자료를 전달하므로 공유 전 포함 표시를 확인한다. 불러오기는 새 템플릿을 만들고 현재 예배와 송출을 유지한다. 동일한 media는 재사용한다. 전체 백업에는 휴지통 템플릿도 포함한다.

## 큐시트 인쇄·PDF

콘티 더 보기의 `큐시트 인쇄·PDF`를 연다. 기본 공용은 담당자·운영 메모·무대 초안·웹 호스트를 제외한다. 찬양팀은 곡 구간, 운영자용은 담당자·운영 메모·자료/화면 정책을 포함한다. `포함 정보`에서 개별 항목을 조절하고 문서와 화면의 포함 표시를 확인한다. 전체 가사·원문 악보/PDF·일시 무대 안내는 내보내지 않는다.

A4 세로/가로와 보통11pt/큰13pt를 선택하면 실제 PDF 페이지를 다시 만든다. 긴 메모는 다음 쪽에 제목 `(계속)`과 함께 이어지며 말줄임으로 숨기지 않는다. 계획 시각은 명시 선택하며 미정은 미정, 자정 이후는 `+1일`로 표시한다. 처리 중 취소 후 다시 만들 수 있다. 최대 순서/메모 출력은 시스템 메모리를 많이 사용하므로 오류 안내가 나오면 포함 정보를 줄이고 재시도한다.

`PDF 저장`에서 경로를 선택하면 파일 기록 후 저장 완료/파일 위치 보기를 제공한다. 미리보기 이후 예배를 고치면 이전 내용 표시가 나오며, 최신 내용으로 다시 만들거나 확인 후 이전 고정본을 저장한다. `인쇄`는 OS 인쇄 대화상자로 전달하며 실제 용지 출력을 확인했다는 뜻이 아니다. 창을 닫으면 미리보기 임시 파일만 정리한다. 이미 저장한 PDF는 보존한다. 실제 프린터 A4 세로/가로와 지원 OS 폰트는 현장에서 확인해야 한다.
