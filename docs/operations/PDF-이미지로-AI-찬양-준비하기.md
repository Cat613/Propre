# PDF·이미지로 AI 찬양 준비하기

2026-10-17 · REQ-037 / FLOW-011 / TC-037

오른쪽 아래 도구 모음의 **AI로 찬양 준비**에서 악보·가사 파일을 넣어 곡과 콘티 순서를 만든다. 각 예배의 곡 구성은 해당 콘티에 저장된다. 왼쪽 플레이리스트와 Songs·Bible 영역 사이의 구분선을 끌어 두 영역의 높이를 조절할 수 있다.

## 화면 구성

왼쪽 **새 찬양 준비**는 파일 업로드와 준비 메모, **현재 준비 작업**은 분석·검토·완료, **작업 기록**은 이전 작업을 이어서 여는 화면이다. 새 준비에서는 이전 작업의 오류나 초안을 함께 표시하지 않는다. 사용할 AI와 연결 추가는 보조 내비게이션에 있다. 연결 추가는 별도 패널로 열리며 Escape로 해당 패널만 닫는다.

검토 화면 상단에서 곡을, **가사 파트**에서 A/B/후렴 등의 파트를 선택한다. 파트 탭은 좌우 방향키와 Home/End로도 이동할 수 있다. 왼쪽에서 가사·송폼을 편집하고 오른쪽에서 원본·슬라이드·콘티 순서를 확인한다. 저장·곡 확인·적용은 하단에 모여 있다. 데스크톱에서는 편집 영역만 스크롤되며, 좁은 창에서는 한 열로 이어서 확인한다. **분석 및 작업 관리**에서 재분석·보관·삭제를 연다.

## 처음 설정

**AI 연결 추가**를 눌러 Google Gemini, OpenAI, Anthropic Claude 중 제공자와 모델을 선택하고 API 키를 등록한다. 제공자에 맞는 기본 모델 ID가 입력되며 계정에서 사용 가능한 다른 PDF·이미지 및 도구 호출 모델 ID로 바꿀 수 있다. 여러 연결을 등록하고 사용할 AI를 선택할 수 있다. 기존 Gemini 키도 활용할 수 있다. 선택한 원본과 이 작업의 지시·준비 중인 곡 내용이 해당 제공자에 전달된다. API 키는 OS 보호 저장소에 암호화하며 화면에는 등록 여부만 표시한다. 파일 분석은 선택한 AI 계정에 비용이 발생할 수 있다.

연결 저장 중에는 입력·연결 선택·닫기를 잠근다. 저장 완료 안내는 설정 저장만 의미하며 실제 모델 응답은 파일 분석 시 확인한다. 연결 입력을 마치거나 중단하려면 입력 영역의 **AI 연결 추가 닫기** 또는 **취소**를 누른다. Escape도 연결 입력을 먼저 닫고 기존 준비 작업으로 돌아온다. 저장하지 않은 연결·키 입력은 버리며 저장된 연결과 송폼 지시는 유지한다. 창 상단 **닫기**는 연결 입력이 열려 있어도 찬양 준비 창 전체를 닫는다.

## 파일에서 콘티 만들기

1. 현재 콘티와 곡 수, 사용할 AI를 확인한다. 기본은 기존 콘티에 추가하고 확인 후 적용한다. 바꾸려면 **적용 설정**을 펼쳐 **기존 콘티 끝에 추가** 또는 **기존 콘티 순서를 새로 구성**을 선택한다.
2. 기본 **확인 후 적용**, 또는 **명확한 결과는 자동 적용**을 선택한다. 자동 적용도 가사·반복·원곡 연결이 불명확하면 확인을 기다린다.
3. **송폼과 추가 지시**에 원하는 순서를 적는다. 예: `첫 곡은 A B A B×2 C B TAG, 슬라이드당 두 줄`.
4. PDF·PNG·JPG·WEBP를 선택하거나 창에 끌어 놓는다. 파일이 선택되면 현재 준비 작업 화면으로 이동한다. 파일과 제공자를 확인하고 **분석 시작**을 누른다. 다른 파일을 선택하려면 **다른 파일로 새로 준비** 또는 왼쪽 **새 찬양 준비**를 누른다.
5. **원본 확인**에서 파일과 페이지를 비교한다. 파트의 **근거** 버튼을 누르면 해당 파일과 페이지를 펼친다. 미리보기 오류는 **원본 다시 불러오기**로 재시도할 수 있다. 같은 PDF 내 페이지 이동은 이미 읽은 문서를 사용한다. 곡과 파트 탭을 선택해 파트별 가사와 송폼을 수정한다. 가사의 빈 줄은 슬라이드 구분이다. 반복 횟수와 콘티 곡 순서도 변경할 수 있다.
6. **찬양 목록 원곡 연결**을 확인한다. 없는 새 곡은 목록에도 저장한다. 기존 곡이면 원곡을 유지하며, 원곡도 바꾸려는 경우에만 **기존 원곡도 이번 구성으로 갱신**을 선택한다.
7. 각 곡의 **가사·송폼·원곡 연결 확인 완료**를 표시하고 **플레이리스트에 적용**한다. 완료 창에서 등록/갱신 곡 수와 최종 순서를 확인한다.

검토 화면에는 **확인한 곡 수**와 저장 상태가 표시된다. 준비 창을 닫거나 최근 작업을 바꾸거나 새 파일·재분석·최신 콘티 재확인으로 이동할 때 유효한 수정 내용을 먼저 저장한다. 저장 중에는 편집과 작업 전환·닫기가 잠긴다. 잘못된 반복 횟수·빈 제목 등은 화면 안내에 따라 수정한다. 마지막 저장 상태로 돌아가려면 **수정 취소 → 저장된 초안 복원**을 선택한다. 저장하지 않은 수정을 버리는 범위를 화면에서 확인한 뒤 복원한다. 현재 편집 곡과 송출은 유지되며 준비한 콘티를 선택해 운영한다. 원곡을 현재 편집 중이라면 준비 화면에서 원곡을 갱신하지 말고, 적용한 콘티에서 **찬양 목록 원곡에 반영**을 사용한다.

## 문제 발생 시

- Gemini 402: 파일 오류가 아니라 결제 필요 응답이다. AI Studio에서 API 키가 속한 프로젝트의 Billing Tier·선불 잔액·결제 상태를 확인한다. 유료 프로젝트 잔액이 0이어도 자동으로 무료 구간으로 전환되지 않는다. 무료 사용을 원하면 Free Tier 프로젝트의 키를 앱 연결에 등록해 선택한다. 기존 Cloud 프로젝트 결제 연결 해제는 다른 서비스에도 영향을 줄 수 있으므로 앱에서 자동 변경하지 않는다.

- Gemini 429: Google AI Studio에서 API 키가 속한 프로젝트의 해당 모델 한도·사용량을 확인한다. 구조화된 오류가 할당량 0/일일/분당 제한을 밝히면 각각 구분해 안내한다. 구체적인 한도 정보가 없으면 원인을 확정하지 않는다. 무료 모델이어도 프로젝트별 한도가 적용되며, 같은 프로젝트에 키만 새로 만들어 한도를 늘릴 수는 없다.
- OpenAI 429: 오류 코드가 크레딧·사용/지출 한도를 가리키면 Platform의 잔액과 한도를 확인한다. 모든 429를 잠시 후 재시도로 안내하지 않는다. 원격 오류 본문·키·원문 자료는 그대로 표시하거나 기록하지 않는다.


- 키·모델 오류: 연결 설정을 수정하고 같은 작업을 다시 분석한다. 다른 AI를 선택하면 분석 버튼이 **선택한 AI로 파일을 다시 전송해 분석**으로 바뀐다. 이 버튼은 선택한 연결로 작업을 전환한 다음 분석한다. 위의 **이번 분석에 사용할 AI**를 확인한다. 이전 작업의 오류는 이전 AI 이름과 함께 구분한다.
- 불명확한 송폼: 원문과 사용자 송폼을 대조해 순서·반복을 직접 고친다. 자동 적용은 확인 완료까지 멈춘다.
- 일부 분석 실패: 확보된 초안을 수정·확인하고 준비된 곡만 사용하거나 같은 파일을 다시 분석한다.
- 콘티/원곡 변경: **최신 콘티에 맞춰 다시 확인**으로 최신 목록을 기준으로 검토한다. 원곡 변경 시 확인 완료가 해제된다.
- 저장 실패: 기존 자료와 순서는 유지된다. 저장 공간을 확인하고 같은 작업을 다시 적용한다. 완료 응답을 놓쳤다면 최근 작업의 저장 결과를 확인한다.
- 중단/취소: 최근 준비 작업에 초안과 파일이 남는다. 취소한 작업의 확보된 초안은 수정·확인 후 적용하거나 다시 분석할 수 있다. 사용자 취소 시 자동 적용 설정은 해제한다. 전체 분석 제한 시간(10분)이 지난 작업은 복구 대상으로 유지하며, 개별 요청 대기 시간(2분) 초과는 오류로 안내한다. 저장 중에는 저장 결과를 먼저 확인한다.

**이번 순서 적용 되돌리기**는 적용 이후 콘티가 변경되지 않았을 때 직전 순서를 복원한다. 등록/갱신한 원곡은 남으며 편집 Undo는 소비하지 않는다.

## 파일 보관

파일당 20MB, 전체 40MB/20파일/50페이지를 선택한다. 곡당 펼친 슬라이드 200장, 전체 1,000장까지다. AI 요청 한도가 더 작으면 파일 크기를 줄이거나 나누도록 안내한다. 암호 PDF는 암호를 해제한 뒤 선택한다.

원문·작업본은 완료/취소 후 생성일 기준 7일을 지나면 앱 시작 시 정리된다. 현재 작업의 **분석 및 작업 관리 → 작업 정보 및 보관**을 펼쳐 **원본과 작업본 계속 보관**을 선택하면 유지한다. 미확정/중단/부분 실패 초안은 보호한다. **원본·작업본 삭제**를 누르면 삭제 범위와 취소/확인 버튼이 표시된다. **원본·작업본 삭제 확인**은 준비 원본과 상세 초안만 삭제하고 저장된 찬양·콘티·적용 기록은 남긴다. 일반 발표/백업 파일에는 원문 PDF·이미지를 자동 포함하지 않는다.

실제 악보의 가사와 반복은 첫 사용 시 반드시 원문과 대조한다. 현재 검증은 합성 자료와 합성 API 응답의 앱 동작이며 실제 모델별 한국어 악보 품질 평가는 별도로 남아 있다. [설계·구현](../engineering/PDF와-이미지로-찬양-슬라이드와-플레이리스트-준비.md), [검증 기록](../quality/2026-10-07-AI-찬양-준비-구현-검증.md)을 참고한다.


## 분석 규칙 (2026-10-12 개선)

사용자 송폼·분할 지시가 우선이며 별도 지정이 없으면 기본 두 줄로 문장·호흡에 맞춰 슬라이드를 나눈다. 원문 악보 줄바꿈은 그대로 슬라이드 경계로 사용하지 않는다. 코드·템포·저작권 문구는 가사에서 제외하고 음절 분리 하이픈·늘임선을 정리한다. 판독 불가 부분은 기억하는 가사로 채우지 않고 파일·페이지·위치와 함께 검토 목록에 남기도록 지시한다.

원문의 반복·1/2번 엔딩·D.C./D.S.·Fine·Coda를 진행 근거로 사용한다. 전체 송폼이 명확하지 않으면 추정으로 표시하고 임의의 후렴 반복을 추가하지 않는다. 원본 파일이나 페이지가 바뀌면 같은 파트 이름이라도 별도 파트로 나누어 근거를 확인할 수 있게 한다.

일부 파일만 재분석할 때는 이번 분석 밖의 곡·파트·진행 순서·등장 횟수 변경을 앱에서 거부한다. 이어지는 페이지의 추가는 기존 파트와 진행 순서를 유지한 채 새 파트를 뒤에 붙이는 방식으로 허용한다. 변경하지 않은 기존 곡의 확인 상태와 원곡 연결은 유지한다.

프롬프트와 도구 설명은 `electron/services/song-prompt.ts`에서 관리한다. 고정 규칙은 제공자의 시스템 지시로, 사용자 지시·파일 목록은 작업 메시지로 전달하며 각 첨부 앞에 파일 ID와 이름을 표시한다. 구조 검증은 실제 원문 인식 정확성을 보증하지 않으므로 적용 전 원문 대조가 필요하다.
