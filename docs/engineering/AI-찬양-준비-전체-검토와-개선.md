# AI 찬양 준비 전체 검토와 개선

2026-10-17

## 범위와 유지할 계약

파일 입력·복사/해시·원문 미리보기 → 제공자별 요청/도구 실행 → 초안 저장/수정 → 원곡 연결/콘티 순서 → 명시적 또는 설정된 자동 적용 → 기록/되돌리기 → 보관/삭제를 검토한다. 실제 AI 계정 호출 없이 합성 응답과 격리된 Electron 사용자 데이터를 사용한다. 현재 편집·송출 보존, 원곡 갱신의 명시적 선택, 원자적 적용과 중복 방지, 분석 범위 밖 초안 보존 계약을 유지한다.

## 확인한 문제와 설계

1. **초안 전환 시 손실**: 닫을 때만 저장해 작업 전환·파일 선택·재분석·최신 콘티 재확인에서 편집을 잃을 수 있다. 변경된 유효 초안은 동작 전에 저장한다. 잘못된 입력은 전환을 멈추고 원래 화면에서 수정할 수 있게 한다. 필요하면 화면 내 확인 후 마지막 저장 초안을 복원한다. 저장 중 편집과 작업 전환을 잠근다. 상태만 갱신된 이벤트는 로컬 초안을 초기화하지 않는다.
2. **다른 작업의 적용 기록 노출**: 작업 변경 시 이전 영수증을 즉시 구분하고, 이전 비동기 조회가 늦게 도착해도 현재 작업 기록에 덮어쓰지 못하게 한다. 오류·원본 페이지·삭제 확인 상태도 전환 시 초기화한다.
3. **원본 이동과 미리보기**: 파트 근거 버튼이 파일·페이지만 바꾸고 접힌 원본을 열지 않는다. 근거를 누르면 원본을 펼치고 이동한다. 로딩/오류를 표시하고 파일·페이지 변경 시 진행 중인 PDF 렌더를 정리한다.
4. **검토 동작의 의미와 한도**: 유효하지 않은 송폼은 저장·적용 전에 이해할 수 있는 위치와 메시지를 보여준다. 마지막 진행 삭제, 스키마 한도 이상의 추가를 막고 확인된 곡 수를 표시한다. 적용 버튼 옆에 남은 확인 수와 저장 상태를 보여준다.
5. **연결 편집 중 경쟁**: 연결 저장 중 입력·연결 선택·닫기를 잠그고 저장 완료와 다음 행동을 안내한다. 제공자 변경 시 기존 키를 사용할 수 있다는 오해를 줄인다.
6. **서비스 동시성**: 분석 시작을 기존 직렬 큐에 넣고 사용량 갱신도 직렬화해 보관/초안/취소 상태를 덮어쓰지 않는다. 취소된 도구의 뒤늦은 순서 갱신을 차단한다. 실행 중 보관 변경을 확인한다.
7. **제공자 오류의 경계**: 성공 상태의 손상 JSON이나 네트워크 예외도 원문·키를 포함할 수 있다. 예외를 안전한 고정 메시지로 변환하고 응답 봉투와 도구 호출 형식을 검증한다. 취소·요청 시간 초과·형식 오류를 구분한다.
8. **복구·삭제**: 제한 시간으로 중단된 분석을 명시적 사용자 취소와 구분해 복구 대상으로 보존한다. 삭제는 화면 내 확인 단계와 범위 설명을 제공하고 적용된 찬양·콘티는 유지한다.

## 단계별 검증

- 초안 전환·잘못된 송폼의 전환 차단·상태 알림 중 로컬 수정 유지·저장 중 잠금: Electron 시나리오.
- 적용 기록 교차 노출·파트 근거 열기·원본 오류/회복·연결 입력 상태·키보드: Electron 시나리오 및 캡처.
- 분석 시작 경쟁·보관과 사용량 경쟁·제한 시간 복구·응답 형식/예외 비노출: 서비스 단위 검사.
- 기존 provider adapter, 부분 분석, 원곡/콘티 충돌, 적용/되돌리기 회귀: 관련 단위 검사와 기존 Electron 검사.
- 타입·린트·포맷·프로덕션 빌드 후 최종 검증 결과를 별도 보고서에 기록한다.

## 추가로 확인한 UI 문제

긴 한글 제목을 콘티 순서 select에 표시할 때 fieldset의 기본 최소 너비가 콘텐츠 크기로 확장되어 560px 창에서 가로 스크롤이 발생했다. fieldset 최소 너비와 select의 축소·행 줄바꿈을 명시하고 오류 위치 제목은 최대 40자로 요약했다. 접힌 영역의 summary를 포커스 순서에 포함하고, 초기 포커스는 AI 선택으로 지정한다. 기본적으로 원본 미리보기는 펼쳤을 때만 생성하며 접으면 PDF worker와 렌더 작업을 정리한다.

## 복구 동작

사용자 취소는 자동 적용을 해제한다. 취소 시점까지 확보한 초안은 다시 분석하지 않아도 직접 수정·저장·확인 후 적용할 수 있다. 제한 시간 초과는 canceled 대신 interrupted로 남겨 완료/취소 작업의 7일 자동 정리 대상에서 제외한다. 분석 시작과 사용량 저장은 직렬화하며, 분석 종료 처리도 여전히 analyzing인 작업에만 적용해 늦은 응답이 사용자 수정 상태를 덮어쓰지 않는다.
