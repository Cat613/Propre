# AI 찬양 준비 화면 간소화

2026-10-16 · 기존 AI 찬양 준비 흐름의 화면 개선

## 문제와 목표

새 작업 설정, 이전 작업 정보, 원본 보관, 재분석과 오류 안내가 동시에 노출되어 시작 위치와 다음 동작을 찾기 어려웠다. 파일 선택 → AI 분석 → 확인 후 적용의 단계와 현재 작업을 먼저 보여준다. 분석·저장 계약과 기본 확인 후 적용 정책은 유지한다.

## 화면 구성

- 상단: 현재 콘티와 곡 수, 고정 닫기 버튼, 현재 단계를 표시한다. 자동 적용 또는 검토 결과가 있어도 분석 중에는 분석 단계를 표시한다.
- 준비 카드: AI 선택과 연결 추가는 항상 접근할 수 있다. 새 작업에서는 파일 업로드, 선택 입력인 송폼 지시를 펼친다. 작업이 선택되면 이 영역을 접고 **다른 파일로 새로 준비**에서 다시 연다.
- 적용 설정: 기본 접힘. 현재 추가/새 구성, 확인/자동 적용 값을 요약한다. 설정은 새로 선택하는 파일에 적용된다.
- 현재 작업 카드: 상태, 파일 이름과 페이지, 오류, 재분석 대상, 사용할 AI와 실행 버튼을 모은다. 이전 AI 오류와 새 AI 재전송 안내는 구분한다.
- 작업 정보 및 보관: 작업 생성 당시의 AI·적용 조건, 계속 보관, 삭제를 기본 접힘 영역에 둔다.
- 검토: 원본 확인과 기존 곡별 편집·미리보기·적용·되돌리기를 유지한다. 좁은 화면에서는 편집과 미리보기를 한 열로 쌓는다.

## 시각·접근성 기준

최대 폭 1,000px의 카드와 여백, 테마 변수에 따른 배경·테두리·문자색을 사용한다. 밝은 테마 오류는 연한 붉은 배경과 진한 붉은 글씨로 표시하며 AI 안내의 파란 글씨 대비를 보정한다. 기본 details/summary로 접힘 영역의 키보드 조작을 제공하고 포커스 테두리를 표시한다. 상단 닫기 버튼은 스크롤 중에도 유지한다. 준비된 AI가 없으면 파일 선택과 파일 드롭을 실행하지 않는다.

## 검증 범위

`tests/electron/song-preparation.spec.ts`에서 격리된 `PROPRE_TEST_USER_DATA` 경로를 확인한 뒤 연결 입력 닫기·Escape·포커스 복원, 기본 접힘, 파일 선택 접근성, 오류와 재시도, 기존 편집/송출 보존, 검토·적용·되돌리기, 자동 적용과 불명확한 송폼의 검토 중단, 보관과 재실행을 확인한다. 밝은/어두운 1280×900 및 560×800 오류 화면, 초기 화면을 캡처한다. API는 합성 응답이며 실제 제공자나 한국어 악보 인식 품질을 검증하지 않는다.

검증 결과: 타입 검사·프로덕션 빌드·ESLint·수정 소스 Prettier·diff 공백 검사 통과. 찬양 준비 단위 검사 7개, 최종 빌드 기준 Electron 시나리오 8개 통과. 초기 통합 실행에서 이미지 시나리오는 앱 첫 창 대기 시간 초과가 있었으며 단독 재실행 및 이후 전체 실행에서 통과했다. 초기·오류의 밝은/어두운·좁은 화면과 검토 화면 캡처를 확인했다.
