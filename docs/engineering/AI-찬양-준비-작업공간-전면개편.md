# AI 찬양 준비 작업공간 전면 개편

2026-10-17

## 방향

기존의 단일 세로 폼을 단계별 작업공간으로 교체한다. 새 준비와 기존 초안 검토를 한 화면에 나열하지 않는다. 파일·설정·분석·검토·완료의 현재 위치와 다음 행동이 항상 명확해야 한다.

## 화면 계약

- 공통: 고정 헤더와 사이드 내비게이션, 현재 콘티 요약. 새 준비 / 현재 작업 / 작업 기록을 구분한다. AI 선택과 연결 설정, 최근 작업 이동은 보조 내비게이션에서 접근한다. 설정 입력은 별도 패널로 열고 닫는다.
- 새 준비: 파일 업로드를 중심으로 한 안내와 지시/적용 옵션의 두 영역. 기존 작업의 오류·초안·영수증은 표시하지 않는다. 새 파일 선택은 분석 요청을 자동 실행하지 않으며 선택 후 분석 화면으로 이동한다.
- 분석: 파일과 상태, 주 행동(분석 시작·취소·재분석)을 표시한다. 원본·보관·삭제는 보조 옵션이다. 초안이 있는 경우 명시적으로 검토와 분석 관리를 오갈 수 있다.
- 검토: 상단 곡 선택 목록, 가사/송폼 편집과 미리보기/원본의 두 작업 영역. 확인 진행률과 저장·적용은 별도의 고정 하단 영역에 두어 긴 가사를 내려도 찾을 수 있게 한다. 원곡 연결과 세부 순서는 해당 작업 영역에서 확인한다.
- 완료: 저장 결과와 콘티 보기·되돌리기·다음 준비를 독립적으로 보여준다.
- 좁은 창: 내비게이션을 짧은 상단 행으로 줄이고 편집과 미리보기를 한 열로 배치한다. 각 영역의 최소 너비와 긴 한글을 검증한다.

## 보존 및 검증

기존 초안 저장·전환 차단·취소 복구·원본 근거·부분 재분석·원곡 갱신 선택·적용과 되돌리기의 서비스 계약은 유지한다. 화면 이동 전 수정본을 저장한다. 기존 AI 준비 Electron 시나리오를 새 동선에 맞춰 갱신하고 초기/분석 오류/검토/완료·밝은/어두운/좁은 화면을 확인한다. UI 변경이므로 반복 전체 서비스 검사 대신 타입·린트·빌드와 해당 Electron 검사를 집중 실행한다.

## 구현 결과

`SongPreparationPanel.tsx`의 화면을 새 준비/현재 작업/작업 기록으로 분리하고 `SongPreparationPanel.css`를 작업공간 레이아웃으로 교체했다. 업로드 중심의 시작 화면, 보조 내비게이션의 AI/콘티 정보, 별도 연결 설정 패널, 곡 목록과 파트 탭, 편집/원본·미리보기의 독립 스크롤 영역, 데스크톱 하단 고정 검토 동작, 독립 완료 화면을 제공한다. 파트 탭은 좌우/Home/End 및 선택 탭만의 Tab 진입을 지원하고 연결 패널은 자체 모달 포커스를 유지한다. 좁은 창에서는 편집 공간을 가리지 않도록 단일 스크롤과 일반 하단 동작 영역을 사용한다.

새 준비 화면으로 이동할 때 기존 유효 초안을 저장하고, 작업 기록에서 현재 작업을 다시 열 때도 저장 직전의 오래된 초안으로 되돌리지 않는다. 새 파일을 선택한 뒤 분석 화면에 도달한 상태를 검사에서 명시적으로 기다린다. UI 재배치 중 확인 체크박스와 적용 동작이 겹치는 문제, 검토 중 로컬 저장 오류가 숨겨지는 문제를 수정했다.

## 검증

타입 검사·ESLint·수정 TSX/CSS/검사 소스의 Prettier·프로덕션 빌드와 AI 준비 Electron 시나리오 12개를 확인한다. 기존 파일/분석/초안 전환/재시도/원본/보관/확인/적용/되돌리기 검사에 파트 전환 시 수정 보존, 파트 탭 키보드 이동, 작업 기록에서 완료 작업 복귀를 포함한다. 밝은/어두운 초기·오류·검토, 좁은 검토, 완료·작업 기록 화면을 캡처한다. 실제 모델 호출이나 설치 앱 교체는 포함하지 않는다. 서버·제공자 계약은 변경하지 않아 전체 서비스 검사를 반복하지 않는다.
