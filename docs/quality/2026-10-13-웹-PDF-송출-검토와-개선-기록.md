# 웹·PDF 송출 검토와 개선 기록

[기능 상세 안내](../product/웹-PDF-송출-기능-상세-안내.md) · [운영 안내](../operations/웹-PDF-화면-송출.md) · [이전 구현 검증](2026-10-12-URL-PDF-송출-검증-기록.md)

## 검토 기준

사용자가 보고한 웹 준비 창 전면 표시 문제를 우선 수정하고 준비/송출/복귀/중지, PDF 회전과 페이지 이동, 웹 미리보기·오디오·조작 상태, 자료 저장과 오류 경로를 현재 소스에서 검토했다. 기존 dirty 구현과 문서는 보존했으며 시작 HEAD와 파일 hash는 `/tmp/propre-output-review-2026-10-13-baseline.json`에 기록했다.

모든 Electron 기능 검사는 합성 HTTP 페이지·생성 PDF와 임시 `PROPRE_TEST_USER_DATA`를 사용하고 실제 `app.getPath('userData')`가 일치하는지 확인한다. 실제 사용자 데이터 폴더를 사용하는 패키지 UI 검사는 시도하지 않는다.

## 발견 사항과 수정

1. **슬라이드 클릭마다 웹 준비 창이 올라옴**: `returnToSlides()`가 이미 준비 중인 웹에도 `detach()`를 호출하고, detach가 항상 `showPreparation()`의 `show()`를 수행했다. 비송출 상태의 detach는 아무 창도 바꾸지 않고, 자동 detach·전환 실패는 웹을 준비 창에 옮기되 창을 앞으로 가져오지 않도록 했다. 최초 준비·명시적 `브라우저 조작`만 준비 창을 표시한다. 웹 송출에서 복귀한 준비 창은 숨긴다.
2. **PDF 송출 회전과 준비 회전 혼용**: 송출 상태에 확정한 회전값을 포함했다. 송출 이전/다음은 이 값을 사용하고 별도 준비 페이지·회전을 바꾸지 않는다. 썸네일 요청에도 준비 회전을 전달하며 PDF 준비 위치 저장 후 목록 메타데이터를 갱신한다.
3. **중지 후 늦은 웹 attach**: native capture 이후 browser identity/수명과 coordinator generation을 다시 확인해 중지 후 새 소스가 publish되지 않도록 했다. 취소된 attach의 오류 처리도 빈 준비 창을 다시 만들지 않는다. 크기 변경으로 취소된 전환은 이전 소스를 유지·복구하며 웹 rollback은 기존 음소거 상태를 유지한다.
4. **조작 잠금·미리보기·오디오**: 다른 웹 자료의 캡처를 현재 웹 미리보기에 표시하지 않는다. 새 송출·복귀·중지 시 실시간 조작을 다시 잠그고 중단된 웹의 소리/조작 버튼을 비활성화한다. 웹 소리 켜기가 거절될 때 기존 오디오를 미리 일시정지하지 않는다.
5. **준비 viewport·웹 호스트**: 재사용하는 웹 준비 창은 현재 출력 크기에 맞추되 전면 표시하지 않는다. 웹 송출/모니터의 호스트는 저장 주소가 아니라 준비 창에서 실제로 연 현재 주소를 반영한다.

추가 PDF 회귀 검사에서 fixture 등록 후 UI bootstrap이 필요했던 점과 비동기 송출 완료를 기다리지 않은 assertion을 수정했다. 실제 송출 상태가 완료될 때까지 poll하는 최종 전체 실행에서 58개 모두 통과했다. 기존 슬라이드·미디어·오디오·콘티·AI·성경·저장/복구 검사도 포함한다.

검토 시작 HEAD `4dbdd7de94c72ff20ed385ec0e70e647d7c49a35`는 그대로 유지했다. 기준 hash와 비교하여 이번 변경 파일이 위 개선·문서·회귀 검사·생성 번들 범위에 한정됨을 확인했다. 실제 사용자 데이터 폴더를 테스트 대상으로 실행하지 않았다.

추가 회귀 검사는 native `BrowserWindow.show` 호출을 기록해 연속 슬라이드 실행과 웹 복귀에서 호출되지 않고 명시적 조작 명령에서만 호출되는지 검사한다. OS 전면 순서는 임의 사용자 앱 상태에 의존하므로 자동 검사를 물리 화면 수용 증거로 해석하지 않는다. 추가로 송출/준비 PDF 회전 분리, 회전 썸네일, native web attach 중 전체 중지와 빈 준비 창 재생성 방지를 확인한다.

실사이트·DRM·Windows·프로젝터·음성 장치·서명/공개 배포는 이번 검토 범위에서 실행하지 않는다. 커밋·푸시는 하지 않는다.
