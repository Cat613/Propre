# 현재 콘티 상단 간소화

2026-10-14 (Asia/Seoul)

사용자가 제공한 이미지의 현재 콘티 제목·새 콘티·파일 버튼·편집 안내·원곡 반영 영역을 간소화했다. 제목/곡 수와 새 콘티/보관함/더 보기 두 줄로 정리했다. 날짜가 있을 때만 제목 옆에 표시하고 중복 자동 저장 안내는 생략한다. 파일 저장·새 콘티로 불러오기·현재 콘티에 추가는 더 보기 메뉴에서 수행한다. 편집 소속과 원곡 반영을 한 줄로 줄이고 상세 원곡 보호 설명은 tooltip에 남겼다.

메뉴는 작업 선택·바깥 클릭·Esc로 닫힌다. Esc로 메뉴만 닫을 때 기존 송출을 유지하고 작업 중 메뉴·파일 동작의 중복 실행을 제한한다. 좁은 패널에서도 메뉴 너비가 패널을 넘지 않도록 제한했다.

## 확인

- `npm run build:app`: TypeScript·생산 빌드 통과.
- `npx playwright test tests/electron/playlist-files.spec.ts tests/electron/setlists.spec.ts tests/electron/workbench.spec.ts`: 11개 검사 통과. 메뉴를 실제로 열어 파일 저장/불러오기·확인/취소·오류·중복 차단을 확인했다. 원곡 반영·콘티·좁은 작업 화면, 메뉴 Esc/바깥 클릭과 미리보기 유지도 포함한다.
- `npm run lint`: 통과.
- `npm run check:bundle`: renderer 632,128 bytes / 선택 PDF parser·worker 1,397,111 bytes, 한도 통과.
- 변경 파일 Prettier 및 source/doc 공백 검사 통과.
- `npm run package:check`: macOS arm64 패키지 생성·내부 stdio 합성 호출 통과(서명 없음).

실제 앱에서 생성한 light 화면 캡처 `test-results/simple-setlist-header.png`를 확인했다. 메뉴 안의 숨긴 버튼은 includeHidden 옵션으로 busy 상태를 검사하며 실제 작업 클릭은 사용자처럼 메뉴를 열어 수행한다. 초기 검사 실패는 테스트의 숨김 버튼 선택 옵션과 중첩 미리보기 선택자를 수정한 뒤 전체 관련 11개를 재실행하여 통과했다.

모든 Electron 검사는 실제 임시 PROPRE_TEST_USER_DATA를 확인했고 사용자 자료를 사용하지 않았다. 기준 HEAD/파일 hash는 `/tmp/propre-simple-setlist-header-baseline.json`에 기록했다. 기존 다른 변경을 보존하며 공개 배포·커밋·푸시는 하지 않았다. 이번 UI 변경에서 전체 앱 회귀 검사를 재실행한 것으로 기록하지 않는다.
