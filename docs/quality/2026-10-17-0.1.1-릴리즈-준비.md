## 검증

첫 전체 검증은 단위 305개와 Electron 117개를 모두 통과했다. 의존성 변경 후 npm audit는 0건이며 형식 검사는 전체 통과했다. 0.1.1과 수정된 의존성으로 재실행한 전체 검사도 단위 305개·Electron 117개 모두 통과했다. lint·타입·빌드·번들 예산·전체 형식 검사와 npm audit 0건을 확인했다. Renderer 기본 JS는 696561 bytes로 700000 제한 이내다.

## 공개 배포 조건

check-release.mjs 실행은 release-evidence/code-license.json 누락으로 중단됐다. 코드·성경 자료 배포 허락과 실제 Mac 수용 기록 3개가 모두 없다. 실제 검토 근거를 임의 작성하지 않는다. 파일 생성·GitHub 초안 업로드는 공개 승인이나 실장비/유튜브 뮤직 실서비스 수용 완료를 의미하지 않는다. 공개는 이 기록을 갖춘 뒤 수행한다. 이전 v0.1.0 초안은 보존한다.

- 패키지 ASAR 코드를 별도 Electron 런타임으로 실행해 임시 userData를 먼저 검증하고 AI 준비 열기·Escape 닫기를 확인했다. 배포 파일에 없는 개발용 Dock 아이콘 설정만 검사 harness에서 생략했다. 실제 패키지 GUI 실행 시도는 기존 인스턴스 잠금으로 종료되었고, 설치본은 테스트 경로 환경변수를 받지 않는 것을 확인했다. 이 검사를 실제 설치본·깨끗한 Mac 실행 수용으로 간주하지 않는다.
- 전체 회귀의 PDF 예제 생성 부작용은 검사 전 원본으로 복원했다. 사용자 데이터·로그인·브라우저 등록은 변경하지 않았다.

이전 버전의 workspace-v4 원본은 보존되지만 새 음악 참조는 v5/휴대용4다. 이전 앱은 새 형식 자료를 직접 읽지 못하므로 운영 자료의 설치·복구 수용은 별도다. 유튜브 뮤직 실제 로그인/재생·광고/지역·장비 수용도 별도다.


## 원격 CI 발견과 후속 보완

최초 main/develop CI는 설치·audit·단위 검사를 통과했으나 Electron에서 각각 6개/7개가 실패했다. 결과를 로컬 성공으로 덮지 않는다.

- 다중 선택 도구가 좁은 화면에서 슬라이드를 덮어 클릭을 가로챘다. 도구를 절대 위치 오버레이에서 높이를 확보하는 하단 영역으로 옮겼고 성경 추가 검사를 1024×768로 명시했다.
- Chromium 초기 캡처에서 UnknownVizError가 간헐 발생했다. 실제 webContents와 load generation이 같은 동안 특정 일시 오류만 최대 8회/100ms 간격으로 재시도한다. 다른 오류·대상 교체·파괴는 계속 실패 처리한다. 초기 두 캡처 실패 후 실제 캡처 성공을 확인하는 Electron 회귀 검사를 추가했다.
- 1000개 순서·최대 노트 생성이 CI에서30초를 넘었다. 페이지 배치 중 완료 페이지를 DOM에서 분리하고, 분리 전에 overflow를 검사해 누적 레이아웃을 줄였다.30초/메모리 제한을 완화하지 않았다. 로컬 생성 elapsed는10903→9342ms, peakWorkingSetSize는1843744→1360112KiB로 감소했고1474페이지를 유지했다.
- 최초 CSS containment 시도는 메모리 한도 오류가 나타나 폐기했으며 최종 변경에 포함하지 않았다.
- 최종 변경의 성경·웹 자원 검사19개와 큐시트 검사8개가 통과했다. 원격 전체 검증은 후속 커밋에서 다시 실행한다.

최초 초안 파일은 GitHub에서 다시 내려받아 동일 해시·hdiutil 무결성·읽기 전용 마운트·내부 버전0.1.1을 확인했다. 후속 보완을 포함한 설치 파일의 최신 해시는 GitHub0.1.1 초안 설명에서 관리한다. 초안 파일은 공개 전 변경될 수 있다.

사용자가 확인을 위임했으므로 저장소와 공식 자료를 조사했다. 성경 자료의 앱 배포 허락과 코드의 최초 라이선스 원문, 실제 설치·장비 운영 수용을 입증하는 자료는 확보하지 못했다. 임의 승인 JSON을 생성하지 않았다. [공식 저작권 안내](https://www.bskorea.or.kr/bbs/content.php?co_id=subpage2_3_4_1)는 이용 허락이 필요함을 명시하므로, 초안 공개 전 확인 조건을 유지한다.
