# 음악 워크스페이스 UI 개편 검증

## 구현

현재 음악 플레이어와 간결한 행 목록을 분리했다. 재생·일시정지·중지는 플레이어, 파일·링크 추가는 추가 메뉴, 설정·무음 연결·이동·삭제는 항목 메뉴로 정리했다. 긴 제목은 두 줄 표시하고 전체 정보는 펼쳐 확인한다. 로컬 파일의 진행률·음량과 실제 브라우저 음량 조절 안내는 소스별로 구분했다. 연결 설정은 상태 버튼에서 연다. 선택만 된 다음 음악에 재생 중 표시를 하지 않는다.

## 통과한 검사

- 음악 단위 테스트 32개.
- 음악 워크스페이스 Electron 테스트 8개: 단일 엔진 유지·F2·페이드·재시작·예배 변경·자동 재생 버튼·삭제 복구·한 번 재생·현재 음악/다음 준비 분리·현재 항목에서 이어 재생 시 요소 유지·추가 메뉴·Escape 포커스·긴 한국어 제목·테마와 레이아웃.
- 관련 운영 Electron 테스트 2개: 대기 음악 도구 설정 유지와 오디오 단일 소유권·탭 이동·전체 중지.
- 타입 검사, 린트, 앱 빌드, 변경 소스 포맷 검사.
- 1280/1920 창에서 밝은/어두운 테마의 실제 렌더링 스크린샷 검토. 행 높이 84px 이하와 패널 가로 넘침 없음을 검사했다.

테스트는 임시 userData 경로를 생성하고 실제 app 경로 일치를 확인한다. 스크린샷의 재생 상태는 테스트 음원이다. 이 UI 검증은 실제 Chrome 계정의 재생을 새로 검증하거나 공개 배포를 완료했다는 뜻이 아니다. 기존 실제 서비스 연결·첫 재생 기록은 별도 문서를 따른다.

## 병합 전 전체 검사

- 전체 단위 테스트 326개, 린트, 타입 검사, 프로덕션 빌드와 번들 크기 검사 통과.
- 전체 Electron 검사에서 120개 통과 후 기존 버튼 이름에 의존하던 오디오 전환 검사 1개가 실패했다. 개편된 항목 재생 버튼으로 검사 경로를 수정하고 해당 usability 스위트 7개를 모두 재검증했다. 실제 로컬 음악 재생·정지와 웹 소리 소유권 전환 검증은 유지했다.
- 의존성 보안 검사에서 취약점 0개. macOS arm64 패키지 생성과 패키지 내부 stdio 어댑터 동작 검사 통과. 이 검사는 서명·공개 배포를 포함하지 않는다.
