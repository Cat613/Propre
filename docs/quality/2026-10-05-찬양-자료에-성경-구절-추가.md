# 찬양 자료에 성경 구절 추가

2026-10-05 (Asia/Seoul) · 제품 0.1.0 · REQ-035 / TASK-030 / TC-035 / ADR-012

사용자가 찬양 슬라이드에 성경 구절을 추가하는 기능을 요청했다. 기존 성경 탭 검색은 새 자료를 열었으므로 찬양 자료를 유지하며 중간에 말씀을 넣을 별도 진입점을 구현했다. 작업 전 저장소에는 다른 개선의 로컬 변경이 존재했으며 이번 작업은 현재 코드에 필요한 변경을 더했다.

## 구현 동작

- 오른쪽 아래 `성경 구절 추가` → 개역개정 위치 검색 → 본문 확인/구절 선택 → 추가 위치 지정 → 일괄 추가.
- `요 3:16`, `시편 23:1-6`, `창 1` 등 권명/약칭·장·절/범위를 지원한다. 원본의 묶인 절은 전체 범위로 검색하고 한 항목으로 보존한다.
- 검색 결과는 모두 선택된 상태이며 개별/전체 선택을 해제할 수 있다. 맨 앞·맨 뒤·특정 슬라이드 뒤를 고른다. 다중 선택 시 문서 순서상 마지막 선택 슬라이드 뒤, 선택이 없으면 맨 뒤가 기본이다.
- 기존 자료 ID·제목·가사·현재 송출·스타일·배경을 유지하며 bible 슬라이드에 content와 bibleReference를 기록한다. `말씀` 라벨로 구분한다. 본문 인라인 편집 후에도 구절을 유지한다.
- 일괄 추가는 한 번의 Undo/Redo이며 자동 저장과 다음 모니터 본문 갱신을 사용한다. 말씀 클릭 송출은 기존 찬양↔성경 기본 프리셋과 독립 출처 스타일을 따른다.
- 오류·빈 선택·취소·Escape는 자료를 바꾸지 않는다. 검색 입력 변경은 이전 결과/선택을 지우고 늦은 결과는 무시한다. 자료 변경/삭제된 위치는 추가를 거절한다. 모달의 포커스 순환과 송출 단축키 차단을 적용했다.

이번 모달의 결과 화면과 작은 창의 긴 장을 스크린샷으로 육안 확인했다. 본문·구절·위치·선택 수·추가 버튼이 보이며 긴 결과는 내부에서 스크롤된다. 실장비·실제 운영자 수용·공개 배포를 수행했다는 뜻은 아니다. 커밋·푸시는 수행하지 않았다. [소스·번들·패키지 식별](source-manifest-2026-10-05-bible-insert.json)을 연결한다.

## 패키지 확인 중 실제 자료 접근과 복구

첫 패키지 실행에서 `PROPRE_TEST_USER_DATA`를 설정했지만 앱은 패키지 모드에서 이 설정을 사용하지 않았다. 테스트 구절 하나를 추가한 뒤 슬라이드 수 예상이 달라 검사가 실패했고, 실제 작업 자료 접근을 확인했다. 라이브러리와 작업본의 끝에 동일한 새 슬라이드 한 장 및 수정 시각/리비전만 바뀌었으며, 기존 가사·나머지 라이브러리·순서·설정·미디어·장비 선택에는 변경이 없었다.

직전 저장본과 대조해 이 변경만 존재함을 먼저 확인한 뒤 작업 파일을 그 저장본으로 원자적으로 복구했다. 저장 파일의 바이트·SHA-256 일치로 전체 작업 데이터 복구를 확인했다. 이 저장 과정에서 직전 기록은 정상 저장처럼 한 차례 회전했으며 과거 기록까지 변경이 없었다고 주장하지 않는다. 이후 패키지의 리소스를 임시 폴더로 추출하고 실제 앱의 userData 경로가 임시 경로와 일치하는지 확인한 뒤 새 찬양에서 재검사했다. 원문·키·개인 파일 경로를 검증 기록에 복사하지 않았다.
