# WSP-P4a 구간 바로가기 검증

2026-10-16 · HEAD4dbdd7d + dirty 작업 보존 · macOS arm64 / Electron44.5.1

송폼의 part/step/repeat/page와 실제 연속 배열을 대조해 발생 인덱스를 만든다. 불일치하면 경고와 실제 라벨 기반으로 전환한다. 연속 동일 명시 라벨은 묶고 비연속 반복·미지정 슬라이드는 각각 보존한다. 가사로 파트를 추정하지 않고 배열/송폼을 재작성하지 않는다.

슬라이드 목록 위 접는 구간 영역에 칩과 반복 발생 선택을 배치했다. 기본 선택은 준비 표식/스크롤만 바꾸며 별도 `이 구간 송출`로 실행한다. 준비 표식과 편집 다중 선택을 분리했다. 선택 때문에 편집 도구가 뜨면서 마지막 카드를 가리는 문제를 발견해 이 분리를 적용했다. 구간 제어는 카드 스크롤과 별도 영역에 고정해 먼 발생을 선택해도 실행 버튼을 잃지 않게 했다.

클릭 즉시 송출은 명시 체크·영역 표식을 유지하며 Control 재생성 시 기본 준비 모드로 돌아간다. 칩 좌우 방향키/Enter와 명시 반복 발생 선택을 지원한다. 현재 라이브 다음의 가장 가까운 같은 파트를 기본으로 고르고 마지막 발생도 직접 선택할 수 있다.

Main Control 전용 명령은 presentation ID/revision·첫 슬라이드 ID·expected generation을 검사한다. 누락/중간 슬라이드·내용 변경·다른 generation은 거절한다. 기존 native commitSlides 경로와 operator lock을 사용해 PDF/웹에서 복귀하고 출력 적용 확인 뒤 editor를 동기화한다. 일반 Output/Stage 발행과 큐 전환의 경합을 막았다. 수동 구간 송출은 진행 cue를 변경하지 않고 수동 송출 표식을 남긴다.
