# 프로프리 macOS 앱 아이콘

2026-10-16 (Asia/Seoul)

Dock·응용 프로그램에 표시되는 앱 아이콘 변경 요청을 반영했다. 남색 라운드 타일 안에 흰색 P와 파란 송출 화면 프레임을 배치했고 바깥 여백은 투명하다. 원본은 build/icon.png, ICNS는 build/icon.icns다. 생성 원본은 프로젝트에 복사했고 macOS 표준 크기로 변환하는 scripts/build-app-icon.mjs와 npm run icon:build를 추가했다.

- sips 검사: 1254×1254 정사각 PNG, alpha 있음. 64px 축소본을 직접 확인했다.
- ICNS: 16–1024px의 일반/Retina 크기 표현을 생성했다.
- 타입 검사·생산 빌드 통과.
- native windows and Dock entries Electron 검사 1개 통과. 임시 userData와 실제 app.getPath('userData') 일치를 기존 검사에서 확인했다.
- macOS arm64 디렉터리 패키지 및 패키지 내부 stdio 합성 호출 통과. 기본 Electron 아이콘을 사용한다는 기존 패키징 경고가 사라졌다.
- Info.plist의 CFBundleIconFile=icon.icns를 확인했다. 패키지 Resources/icon.icns와 build/icon.icns의 바이트가 완전히 같다. SHA256: 8fca6abc6565ff809d0be4d8fa09f3869596f96313398b9dbeed117530a3048e.
- 기존 사용자 자료·데이터 경로를 유지했다. 패키지 앱을 사용자 데이터로 실행하는 UI 검사는 하지 않았다.

서명 없는 로컬 패키지이며, Finder/Dock의 실제 아이콘 캐시 갱신·서명·공개 배포 확인은 포함하지 않는다. 실행 중인 이전 앱은 종료하고 새 빌드를 실행한다. 기존 응용 프로그램 사본을 사용하는 경우 새 빌드로 교체해야 새 아이콘이 적용된다.
