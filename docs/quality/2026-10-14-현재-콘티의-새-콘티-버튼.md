# 현재 콘티의 새 콘티 버튼

2026-10-14 (Asia/Seoul)

왼쪽 현재 콘티 제목 아래에 항상 보이는 `새 콘티` 버튼을 추가했다. 보관함 목록을 거치지 않고 기존 생성 입력을 바로 연다. 직접 생성 모드는 목록을 숨기고 작은 입력 dialog를 사용한다. 취소·닫기·Esc는 현재 콘티 화면으로 돌아간다. 이름·예배 날짜·현재 순서 복사, 기존 저장과 revision 검증 경로는 공유한다.

- `npm run build:app`: TypeScript·생산 빌드 통과.
- `npx playwright test tests/electron/setlists.spec.ts tests/electron/workbench.spec.ts`: 기존 8개 검사 통과. 직접 버튼에서 입력 초점·취소·빈 콘티 생성과 기존 보관함·실패 재시도 경로를 확인했고, desktop/compact 작업 화면 검사도 포함했다.
- `npm run lint`: 통과.
- `npm run check:bundle`: 초기 renderer 630,096 bytes / 선택 PDF parser·worker 1,397,111 bytes로 한도 통과.
- `npm run package:check`: macOS arm64 패키지 생성과 내부 stdio 합성 호출 통과(서명 없음).
- 변경 소스·관련 검사 Prettier와 source/doc 공백 검사: 통과.

검사는 임시 PROPRE_TEST_USER_DATA를 사용하고 실제 app.getPath('userData')를 대조했다. 시작 상태는 `/tmp/propre-new-setlist-button-baseline.json`에 기록했고 기존 웹·PDF 및 다른 변경은 보존한다. 이번 단순 진입점 변경에서는 기존 관련 검사만 실행했으며 전체 회귀 검사를 재실행한 것으로 기록하지 않는다. 공개 배포·커밋·푸시는 하지 않았다.
