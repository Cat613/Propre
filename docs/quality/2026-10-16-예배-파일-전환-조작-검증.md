## 변경과 최종 계약

- `예배 전체로 저장`은 portable schema 3 / kind=service로 한 예배의 순서·담당자·운영 메모·무대 초안·곡 사본·비곡 자료 사본·실제 참조 assets만 담는다. 개인 설정·원곡 라이브러리·현재 편집·다른 예배·현재 송출은 제외한다. 저장창 제목과 버튼 도움말은 메모 포함을 명시한다.
- 전용 불러오기는 확인 후 새 콘티를 만든다. 콘티/행/cue/곡 사본/비곡 사본/resource ID를 새로 발급하고 원곡 출처 링크는 제거한다. 자료 안 slide/part ID는 문서 범위 식별자이므로 보존한다. 같은 hash/type/extension asset은 재사용하고 ID 충돌은 재매핑한다. 가사·메모의 media:// 문자열은 바꾸지 않는다.
- 불러오기 전과 최종 원자 저장에서 현재 콘티 ID/revision을 검사한다. 충돌·무결성 실패·저장 실패는 부분 사본/파일을 남기지 않는다. 취소는 변경하지 않는다. 현재 편집과 청중 화면은 유지한다.
- 자료 연결도 requestId 영수증을 사용한다. 동시 중복 요청은 한 번만 적용하고 같은 ID에 다른 내용은 거절한다. 디스크 실패 시 같은 요청을 다시 시도할 수 있다. 영수증은 실행 중 한정·최대 1,000개다.
- 기존 연결의 시작 슬라이드/PDF 페이지·회전을 편집할 수 있다. 진행 중인 cue의 화면 연결 변경은 기존 세션 보호를 따른다. 바인딩된 슬라이드 배경과 audio-stop을 native 전환에 함께 적용한다.
- `다음 순서 준비`는 다음 미진행 cue를 선택만 한다. 준비 확인·진행은 별도다. 수동 슬라이드/외부 source 변경은 진행 cue를 바꾸지 않고 `수동 송출 중`을 표시한다.
- 키보드 위/아래는 선택 이동, Alt+위/아래는 구조 이동이다. 입력 모달은 포커스를 가두고 추가/저장 뒤 선택 행에 돌려준다. 충돌 시 입력을 보존하고 사용자가 최신 순서에 명시 재적용한다.
- 예배 사본에서 참조하는 이미지/영상/오디오를 다른 바이트로 재연결하면 과거 사본도 바뀌므로 차단한다. 새 자료 등록/연결로 교체한다. PDF는 예배 소유 hash를 검사한다. 기존 파일이 없는 구형 image asset의 동일성 증명은 불가능해 교체 등록이 필요하다.
- 업데이트 UI도 Main guard와 동일하게 진행/중단 상태의 예배가 있으면 설치를 비활성화한다. 출력 창을 닫아도 이 제한은 유지한다.

## UI 검토와 한계

1024×768 / 1280×800 / 1920×1080 합성 캡처를 다시 생성했고, 1024 화면에서 선택·진행 중 표식, 고정 준비/진행 버튼, 스크롤 경계를 시각 확인했다. 파일 메뉴는 격리 앱에서 실제 클릭했다. 청중에 private 메모가 들어가지 않는 snapshot 계약도 검사했다.

F2 상태 저장은 비동기이므로 메모리 상태 확인 직후 디스크를 즉시 읽던 검사를 최종 저장까지 기다리도록 수정했다. 해당 실패는 중단 상태 저장의 즉시성 가정 오류였으며 수정 후 통과했다.

실제 프로젝터/Stage 모니터/음향, 실제 로그인·DRM 웹, Windows, 서명 업데이트 설치, 사용자 리허설은 미검증이다. PDF/실인쇄는 P5b 범위이며 여기서 완료로 해석하지 않는다.
