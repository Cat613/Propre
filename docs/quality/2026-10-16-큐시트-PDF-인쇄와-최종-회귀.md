# WSP-P5b 큐시트 PDF·인쇄와 최종 회귀

2026-10-16 Asia/Seoul · macOS arm64 · Electron44.5.1 · HEAD4dbdd7d + 기존 dirty 작업 보존

## 구현과 최종 계약

공용/찬양팀/운영자 프리셋과 개별 포함 옵션을 typed allowlist DTO로 만들고 저장된 setlist revision을 고정한다. 공용 기본은 담당자·메모·URL/호스트를 제외한다. 명시 선택한 호스트도 hostname만 허용한다. 자료 미정/미정 시간·자정+1일·곡 구간을 표현하고 전체 가사·원문 파일·실행 토큰·일시 Stage 안내·타이머 카운트·실제 파일 경로는 내보내지 않는다.

Main의 격리 sandbox 인쇄 renderer는 preload/Node/외부 요청/권한/탐색/새 창이 없으며 자신의 preview.html만 읽는다. HTML은 escape하고 시스템 한글 폰트 준비를 확인한다. 실제 높이로 A4 세로/가로·11/13pt의 반복 머리글·표·긴 메모 이어짐·쪽 번호를 배치한다. 페이지 분할 전 제목/쪽 번호를 고정하고,50쪽씩 DOM에 붙여 Chromium PDF를 생성·병합한다. 단순 pageRanges만으로는 전체 배치 메모리가 줄지 않아 이 방식으로 조정했다. 제목의 `(계속)`이 한글 한 글자로 갈라지지 않도록 keep-all을 적용했다.

Control은 최종 PDF 바이트를 PDF.js canvas로 미리 본다. 생성 중 취소, 늦은 응답·옵션 경쟁·닫힌 job을 거절한다. 저장은 native 경로 선택 후 원자 기록하고 완료/파일 위치를 표시한다. 내용이 바뀌면 이전 revision임을 표시하며 이전 내용 저장/인쇄는 기본 취소인 재확인을 거친다. 인쇄는 silent:false/A4/선택 방향이며 성공 표시는 OS 전달이다.

한 번에 하나의 UUID job만 유지한다. 임시 폴더0700/파일0600, 닫기·실패·정상 종료·다음 시작에서 정리하고 사용자가 저장한 PDF는 보존한다. Electron will-quit가 Promise를 기다리지 않아 종료 시 자기 job의 동기 정리를 추가했다. 임시 저장 공간 오류는 선택 기능의 실패로 처리하며 앱 전체 시작을 막지 않고 복구 후 재시도한다. 생성30초·PDF200MiB·4,000쪽·renderer working set2GiB/250ms 표본 상한을 적용한다.

## 잔여 수용

실제 Main/Stage/프로젝터·음향·장비 연결/해제·운영자 리허설, 실제60분 타이머 drift/실제 절전, 실제 OS 인쇄 대화상자·A4 세로/가로 물리 인쇄, 다른 OS의 한글 폰트, 서명/공증/배포/실제 버전 설치는 미실행이다. short timer/fake clock/OS 이벤트 주입과 로컬 PDF/print 콜백 검사를 이 증거로 대체하지 않는다. 실제 사용자 자료·키는 시험 입력으로 사용하지 않았다. 커밋·푸시·배포·다른 채팅 메시지를 수행하지 않았다.
