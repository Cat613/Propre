# AI 할당량 오류 안내 검증

2026-10-16 · 범위: 제공자 오류 처리와 사용자 안내

모든 HTTP 429를 동일한 일시 제한 문구로 표시하던 처리를 변경했다. Gemini의 구조화된 quota 위반 값에서 0·일일·분당 제한을 구분하고, OpenAI의 크레딧/지출/사용 한도 오류 코드를 분리한다. 원인 정보가 없는 429는 계정 한도·결제 확인을 안내하며 일시 제한으로 확정하지 않는다. 제공자 이름과 HTTP 상태를 표시하되 원격 메시지·키·자료는 표시하지 않는다. 오류 본문은 64KiB 이내 구조화 필드만 읽고 파싱 실패·초과 크기는 안전한 일반 안내를 사용한다.

- 제공자 단위 검사 15개 통과. 정상 요청/연속 도구 호출과 실패·0/일일/분당·결제 분류, 민감 원문 비노출, 비정상/초과 크기 오류를 검사했다.
- 찬양 준비 Electron 7개 통과. 폐기 가능한 userData와 실제 앱 경로 일치를 먼저 확인하고, Gemini quota 0 모의 응답의 화면 안내·키 비노출·기존 콘티/작업본/라이브러리 보존을 확인했다.
- 타입 검사·생산 빌드·번들 검사·변경 파일 형식/공백 검사 통과.

실제 사용자 키로 제공자 API를 호출하거나 실제 계정의 한도·결제 상태를 조회하지 않았다. Google 프로젝트 한도가 실제로 0인지, 일일/분당 제한인지 사용자 계정 원인은 아직 미확인이다. 오류 분류 개선이 할당량을 늘리거나 제공자 제한을 해제하는 기능은 아니다. 커밋·푸시·서명 설치·배포는 수행하지 않았다.

공식 근거: [Google 한도](https://ai.google.dev/gemini-api/docs/rate-limits), [Google 요금](https://ai.google.dev/gemini-api/docs/pricing), [OpenAI 오류](https://developers.openai.com/api/docs/guides/error-codes).

## 402 결제 필요 응답 후속 수정

Google 공식 결제 문서의 HTTP 402/Prepay 및 Free Tier 전환 규칙을 확인했다. Gemini 402를 일반 파일 오류로 안내하던 경로를 결제 상태·선불 잔액·Free Tier 프로젝트 확인으로 수정했다. 실제 계정의 잔액을 조회하거나 결제·프로젝트 설정을 바꾸지는 않았다. 제공자 단위 검사는 16개 통과했고, 타입·생산 빌드와 변경 파일 형식/공백 검사도 통과했다. 이번 후속 변경에서 Electron 전체 검사를 다시 실행하지 않았다.

[Google 결제 기준](https://ai.google.dev/gemini-api/docs/billing).
