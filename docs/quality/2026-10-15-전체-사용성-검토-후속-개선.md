# 전체 사용성 검토 후속 개선

2026-10-15 (Asia/Seoul) · [수정 전 검토](../review/2026-10-15-전체-흐름-재검토-2026-10-15.md)

사용자가 승인한 R1–R4 및 I1–I3과 날짜 입력·라이트 모드·새 콘티 화면 간소화 요청을 반영했다.

## 반영한 동작

1. **송출 키 소유권**: 이미 처리된 키 입력을 무시하고, 버튼·summary·링크·ARIA 조작 요소가 사용하는 Space/화살표는 전역 슬라이드 이동에 전달하지 않는다. 입력/IME/모달 보호와 F2 중지는 유지한다.
2. **PDF 준비 일치 확인**: 페이지 입력 변경 시 대기 중 준비 요청을 무효화한다. 자료 ID·revision·generation·페이지·회전이 현재 선택과 일치할 때만 송출 버튼을 활성화한다. 빈 번호·소수·범위 초과에는 인라인 안내와 준비/페이지 이동/회전 제한을 적용한다.
3. **주소 편집 대상**: 수정 폼에 자료 이름을 표시하고 다른 자료 선택 시 이전 폼을 닫아 저장 전 입력을 취소한다. 기존 자료의 ID로 잘못 저장하는 동선을 없앴다.
4. **키보드 콘티 조작**: Enter로 곡을 열고 Alt+위/아래로 순서를 바꾼다. 곡을 열어도 송출은 시작하지 않는다. 제거 버튼과 키 이벤트를 구분하며 스크린리더 조작 안내도 갱신한다. 포인터 드래그는 유지한다.
5. **찬양·미디어 휴지통**: 삭제한 항목을 저장소에 보관하고 개별 복원 화면을 제공한다. 찬양 원곡 삭제는 콘티의 독립 사본을 바꾸지 않으며, 복원도 현재 콘티/송출을 바꾸지 않는다. 미디어 복원은 재생을 시작하지 않는다. 충돌하는 찬양 ID는 덮어쓰지 않는다. 재시작·전체 백업에 휴지통을 포함하고 참조 원본을 파일 정리에서 보호한다. 같은 미디어 URL에 새 목록 ID가 붙는 기존 가져오기 동작은 삭제로 오인하지 않는다.
6. **오디오 전환**: 웹 소리를 켜기 전에 로컬 오디오를 일시정지한다. 로컬 플레이어 재생과 미디어 오디오 선택은 현재 웹 음소거를 확인·적용한 뒤 재생한다. 필요한 음소거 실패 시 재생을 보류한다. 중지/다른 재생 요청 뒤의 이전 응답은 재생을 되살리지 않고, 낮은 generation 응답은 최신 화면 상태를 덮어쓰지 않는다. 웹/로컬 상태를 각각 표시한다.
7. **날짜 입력**: 날짜칸 전체 클릭을 기본 showPicker에 연결하고 테마와 무관하게 다크를 강제하던 스타일을 제거했다. 커스텀 달력 아이콘을 테마의 텍스트 색상으로 표시하고 native indicator 중복은 숨겼다. 키보드 날짜 입력과 선택 날짜의 기존 저장 검증은 유지한다.
8. **새 콘티 간소화**: 직접 생성/이름 수정에서는 상단 제목을 한 번만 표시한다. 중복 뒤로 버튼·큰 본문 제목·소개 문구를 없애고 입력 간격·상하 여백을 줄였다. 빈 콘티/현재 순서 복사를 두 열에 배치하고 설명은 현재 선택에 맞는 한 줄만 표시한다. 날짜는 `(선택)`으로 표시한다. 1100×700에서 하단 저장 버튼까지 스크롤 없이 보이는 것을 확인했다.

## 데이터 계약

`workspace-v3.json`에 `deletedLibrary`, `deletedMedia` 배열을 기본 빈 값으로 추가했다. 이전 v3 데이터는 그대로 읽는다. 전체 백업 schemaVersion 2에도 선택 필드로 포함하고, 오래된 백업에 이 값이 없으면 빈 휴지통으로 복원한다. 복원은 기존 원자적 transaction을 사용한다. 삭제 이전에 이미 영구 제거된 자료의 소급 복원이나 영구 삭제 UI는 이번 작업에 포함하지 않는다.

## 검증

- 기존 전체 Electron 63개와 새 사용자 흐름 7개를 합친 **70개 모두 통과**.
- 새 흐름: 메뉴 Space 송출 방지·Enter/Alt 순서 조작, 지연 PDF 결과 무효화·입력 범위, 주소 수정 대상 전환, 날짜 전체 클릭·light/dark·작은 창, 찬양 휴지통 복원, 미디어 휴지통 복원과 재생 유지, 웹/로컬 오디오 양방향 전환.
- 새 저장소 검사: 삭제/재시작/백업 내보내기·다른 저장소 복원, 7회 체크포인트 뒤 정리 보호, 미디어 ID 교체 오인 방지, 같은 ID의 새 곡 덮어쓰기 거절.
- 전체 단위 검사와 늦은 오디오 응답 중지 보호, 마지막 빌드·패키지 확인 결과는 아래 최종 확인에 기록한다.
- 날짜 클릭 검사는 input.showPicker 호출을 관찰하여 연·월·일·아이콘 위치의 연결을 확인한다. light/dark의 상속 color-scheme과 실제 앱 스크린샷을 대조했다. 운영체제 native 달력 팝업 자체의 픽셀/키 조작은 별도 수동 수용 범위다.
- 오디오 검사는 합성 로컬 웹과 무음 WAV로 실제 HTMLAudioElement.paused 및 웹 muted 상태를 확인한다. 스피커 출력·실제 사이트 영상 음량을 시험한 것은 아니다.
- 모든 Electron 실행은 임시 userData를 사용하고 app.getPath('userData')와 대조한다. 실제 사용자 자료·로그인·계정·외부 사이트는 사용하지 않았다.
- 개발 시작 실패 복구 검사의 React preamble 오류는 의도된 실패 경로이며 해당 테스트는 통과했다.
- 실장비 다중 디스플레이, Windows, DRM/외부 사이트 로그인, 서명·공개 배포는 확인하지 않았다.

## 최종 확인

- 최종 린트·타입 검사·생산 빌드 통과.
- 최종 단위 검사 **16개 파일 / 161개 통과**. 새 저장소 검사 2개와 오디오 중지 후 늦은 응답 검사 1개를 포함한다.
- 전체 Electron **70개 통과** 후, 마지막 오디오 응답 보호·오류 안내 수정이 들어간 빌드로 웹/PDF·사용성 **22개를 재실행해 모두 통과**했다.
- 최종 변경 소스·검사의 Prettier 및 범위 공백 검사 통과.
- bundle 한도 통과: renderer JavaScript 638,826 bytes / 선택 PDF parser·worker 1,397,111 bytes.
- macOS arm64 디렉터리 패키지 생성과 패키지 내부 stdio 합성 호출 통과. 서명 없는 로컬 확인용 패키지이며 공개 릴리즈는 아니다.
- 라이트/다크 실제 앱 스크린샷의 입력 간격·아이콘 대비·저장 버튼 노출을 대조했다.
