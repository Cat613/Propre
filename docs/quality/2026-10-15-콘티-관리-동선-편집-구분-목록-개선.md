# 콘티 관리 동선·편집 구분·목록 개선

2026-10-15 (Asia/Seoul)

사용자가 승인한 개선 5개를 적용했다.

1. 편집 곡이 현재 콘티에 속하면 같은 이름의 안내 줄을 생략한다. 다른 콘티·휴지통의 곡과 원곡 편집 소속은 유지한다.
2. 현재 제목·날짜를 누르면 기존 콘티 관리의 rename 경로를 사용하는 작은 입력 화면을 바로 연다. 이름·날짜를 채운 상태에서 시작하며 저장/취소/Esc 후 현재 화면으로 돌아온다.
3. 새 콘티는 빈 콘티/현재 순서 복사 radio 선택을 제공한다. 기본은 빈 콘티이며 곡이 없으면 복사를 비활성화한다. 보관함에서도 같은 생성 화면과 정책을 사용한다.
4. 곡 이름과 슬라이드 수를 한 줄에 표시하고 수량을 `8장`처럼 축약한다. 긴 제목 tooltip과 드래그·제거 동작을 유지하고 제거 버튼과 수량이 겹치지 않게 여백을 확보한다.
5. 원곡 반영/새 원곡 저장을 더 보기 메뉴로 옮겼다. 메뉴에 현재 편집곡 이름을 표시하고 기존 확인창과 revision 충돌 검증을 유지한다.
