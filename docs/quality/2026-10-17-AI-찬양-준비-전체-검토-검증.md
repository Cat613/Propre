## 유지한 계약

- 분석 중 적용 도구를 제공하지 않으며, 원곡 갱신과 콘티 적용은 기존 권한 경계를 유지한다.
- 파일 검증/복사/해시 확인, 배치 밖 곡·파트·순서 보존, 명시적 원곡 갱신, 독립 예배 사본, 원자적 적용/중복 방지, 충돌 감지와 되돌리기를 관련 단위 검사로 재확인했다.
- Electron 검사 시작 때마다 임시 `PROPRE_TEST_USER_DATA` 경로와 실제 `app.getPath('userData')` 일치를 확인했다. 실제 사용자 예배 데이터나 실제 AI 계정은 사용하지 않았다.

## 실행 결과

- `npm test`: 28개 파일, **294개 통과**.
- `npx playwright test tests/electron/song-preparation.spec.ts`: **12개 통과**.
- 공통 모달 변경 관련 `operations.spec.ts`의 modal hotkeys / traps keyboard 시나리오: **2개 통과**. 편집과 포커스 유지 및 송출 단축키 차단을 확인했다.
- `npm run build:app`: 타입 검사와 프로덕션 빌드 통과.
- `npm run lint`, 수정 TSX/TS/CSS와 검사 파일의 Prettier, `git diff --check`: 통과.
- `npm run check:bundle`: 예산 통과. core 682,620 bytes, optional worship details 77,088 bytes, optional PDF parser/worker 1,397,111 bytes(검사 시점 빌드).
- 초기 화면, 오류의 밝은·어두운 테마와 좁은 화면, 긴 제목과 입력 오류를 포함한 좁은 검토 화면을 캡처해 확인했다.

추가한 검사 중 가로 넘침 검사가 실제 문제를 발견해 fieldset 최소 너비를 수정했다. 비동기 저장 검사의 읽기 시점과 지연 응답을 주입하는 검사 장치도 보정한 뒤 최종 실행을 완료했다.

## 증거의 한계

로컬 소스·합성 응답·실제 Electron UI 검증이다. 실제 Gemini/OpenAI/Claude 계정의 권한·결제·네트워크와 한국어 악보 인식 정확성, 실제 프로젝터·외부 모니터, 설치/서명/배포 수용은 이번 검사로 확정하지 않는다. 소스 개선과 빌드까지 반영했으며 사용 중인 설치 앱을 교체하지 않았다.
