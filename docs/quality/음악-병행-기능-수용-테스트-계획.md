## 기록 방법과 증거 경계

실행 기록은 날짜, 기준 커밋과 dirty tree, 앱/OS/Chrome/확장 버전, 격리 경로 확인, 명령, 기대/실제 결과, 실패/미실행과 근거를 남긴다. 로그/스크린샷에 계정명·인증 정보·개인 재생목록 URL·실제 파일 절대 경로가 포함되지 않도록 한다. 합성 제목과 사용 허가된 짧은 시험 음원을 사용한다.

로컬 단위·가짜 브라우저 adapter·Electron 성공을 실제 유튜브 뮤직 성공으로 보고하지 않는다. 관측된 playing도 스피커 소리의 증거는 아니다. 실제 서비스 성공, 패키지/확장 설치 성공, 물리 음향, 운영자 수용을 각각 기록한다. 전체 앱/임의 외부 앱 소리를 F2로 제어한다는 주장은 하지 않는다.
