# AI 연결 입력 닫기 검증

2026-10-16 · 범위: AI 찬양 준비의 연결 입력 닫기와 기존 작업 보존

연결 영역 안에 닫는 조작이 없고 같은 추가 버튼을 다시 눌러야 접히던 흐름을 수정했다. 영역에 닫기·취소를 추가하고 버튼의 펼침 상태를 제공한다. Escape는 연결 영역만 닫고 열었던 버튼으로 포커스를 돌린다. 상단 전체 닫기는 준비 창 전체를 닫으며 스크롤 중에도 유지된다. 저장하지 않은 연결 입력은 폐기하고 기존 준비 지시·저장된 연결은 보존한다.

- `npm run build:app`: 타입 검사·생산 빌드 통과.
- 변경한 두 컴포넌트 ESLint 및 세 소스/테스트 Prettier 검사 통과.
- `npm run check:bundle`: 공통 673,510바이트, 선택 예배 77,055바이트, 선택 PDF 1,397,111바이트로 통과.
- `npx playwright test tests/electron/song-preparation.spec.ts`: 6개 통과. 신규 검사는 1024×768에서 취소·영역 닫기·Escape·포커스 복귀·다시 열 때 미저장 키 제거·준비 지시/저장된 연결 유지·스크롤 후 전체 닫기를 확인한다. 기존 PDF 검토·적용/되돌리기·재시작·OpenAI/Claude 모의 제공자·이미지 편집 복구도 통과했다.

각 테스트는 폐기 가능한 임시 사용자 경로를 만들고 실제 `app.getPath('userData')` 일치를 먼저 확인한다. 실제 API 키·사용자 자료는 사용하지 않았으며 제공자 응답은 모의다. 실제 API 호출·설치용 패키징·커밋·푸시·배포는 수행하지 않았다. 기존 작업 트리 변경을 보존한 상태에서 수정했다.
