# 콘티 보관함 개선 검증

2026-10-12 · 로컬 소스 기준

## 변경과 사용 흐름

보관함을 목록과 곡 순서 미리보기로 나누고, 콘티 이름·예배 날짜·포함된 곡 이름 검색과 최근 수정순/예배 날짜순/이름순 정렬을 추가했다. 현재 콘티와 선택한 콘티를 구분한다. 선택은 미리보기만 바꾸며 **콘티 열기**에서 현재 순서를 바꾼다.

새 콘티·복제·이름 변경은 별도 입력 화면으로 전환하고 이름 변경 후 결과를 보관함에서 바로 확인한다. 휴지통 이동 전 선택한 콘티와 복원 가능 여부를 표시하며, 현재 콘티의 순서가 비워지는 경우 안내한다. 복원한 콘티는 보관 목록으로 돌아가 선택된다. 입력 화면의 Esc 취소와 포커스 복귀를 제공한다.

| 변경 소스/문서 공백 검사               | 통과       | 이번 보관함 변경 파일 범위                                                                                                   |

첫 실행에서는 예배 날짜 입력의 접근성 이름에 보조 안내가 섞여 기존 검사 두 개가 실패했다. 입력 이름과 안내를 `aria-label`/`aria-describedby`로 구분한 뒤 5개 검사가 통과했다. 이후 작은 창에서 미리보기 영역을 넓히고 입력 중에는 목록을 숨기는 배치로 개선한 후 해당 탐색 검사를 다시 통과했다. 검색된 콘티의 이름을 바꿔도 새 이름의 상세 화면을 유지하도록 보완하고 편집·탐색 검사 2개를 최종 재통과했다.

기존 콘티 검사에서 저장 스타일 73을 기대하던 두 항목은 앞선 사용자 요청의 기본 프리셋 자동 적용에 맞춰 110으로 갱신했다. 원곡과 다른 콘티의 독립성 검사는 유지한다.

## 격리와 화면

소스·설정·검사 파일을 임시 프로젝트에 복사하고 의존성만 연결하여 빌드했다. 각 Electron 실행에서 `app.getPath('userData')`가 검사별 `propre-setlists-native-*` 임시 디렉터리와 같은지 확인한 다음 합성 자료로 기능을 검사했다. 실제 사용자 자료를 검사 입력으로 사용하지 않았다. 빌드는 임시 프로젝트의 `dist`/`dist-electron`에 생성했다. 검증 도중 원래 체크아웃에서 별도 작업의 설정·오디오·문서와 Electron 번들 변경을 감지했다. 해당 변경은 되돌리지 않았으며, 위 실행 결과는 보관함 변경을 포함한 임시 소스 스냅샷 기준이다.

스크린샷은 합성 검사 자료이며 `test-results/setlist-manager-2026-10-12/`에 저장했다.

- `setlist-library-modern.png`: 보관 목록과 곡 순서 미리보기
- `setlist-library-compact.png`: 820px 창
- `setlist-library-narrow.png`: 700px 창의 목록/미리보기
- `setlist-library-editor.png`: 700px 창의 새 콘티 입력 화면

이 기록은 로컬 소스와 격리 Electron 실행에 대한 증거다. 설치된 배포 앱 업데이트, 서명·공증 및 실제 예배 송출 수용 검사는 포함하지 않는다.
