# 무료 다운로드 업데이트 검증

2026-10-16 · REQ-040 / TASK-040 / TC-040 / ADR-019. 사용자 요청으로 Apple 유료 멤버십 없이 확인·브라우저 다운로드·수동 앱 교체로 전환했다. [설계](../engineering/프로프리-앱-업데이트-설계.md), [배포 절차](../operations/앱-설치와-업데이트-배포.md).

## 변경과 보존 범위

- 현재 작업 트리의 예배 운영·큐시트·AI·한글 문서 정리를 보존했다. 작업 전 tracked diff와 주요 파일을 임시 baseline으로 보관했다.
- electron-updater/native adapter와 설치/재시작 IPC, 설치 전용 송출 잠금을 제거했다. 기존 정상 종료의 저장·예배 체크포인트와 사용자 자료 디렉터리, workspace-v4/portable3는 유지한다.
- 새 JSON 확인은 15초·64KiB·HTTPS redirect 최대5회·정식 버전 숫자·CPU별 같은 origin DMG 주소를 검증한다. Main 소유 URL만 브라우저로 열고 Renderer는 URL/명령을 제공하지 않는다.
- 무료 빌드는 현재 공개 GitHub Releases 주소를 package metadata에 포함하고 unsigned DMG/ZIP·JSON을 생성한다. 외부 게시를 수행하지 않는다. Apple 인증 요구만 제거하고 기존 코드·성경 권리/플랫폼 증거 gate는 유지한다.

첫 native 실행 30개 중 28개가 통과했고, 숨겨진 테스트 송출 창을 visible로 가정한 검사와 이전 `재시작하여 업데이트`를 기대한 검사 두 개를 현재 수동 교체 정책에 맞게 수정했다. 수정 후 업데이트/예배 10개를 재실행해 통과했다. 실제 브라우저/네트워크 호출은 unit transport 또는 Main handler를 합성하며 공개 서버에서 설치 파일을 내려받는 실수용과 구분한다. 모든 앱 검사는 폐기 가능한 PROPRE_TEST_USER_DATA와 실제 app.getPath('userData') 일치를 먼저 확인했다.

전체 `format:check`는 이번 변경과 별개의 기존 `tests/electron/sections.spec.ts` 형식 문제를 보고했다. 해당 파일은 수정하지 않으며 이번 변경 파일의 scoped 형식 검사를 별도로 확인한다. 전체 native suite의 새 실행 결과로 위 부분 회귀를 표현하지 않는다.

## 무료 패키지 증거

`npm run package:free` 통과. 공개 GitHub 상태는 read-only 조회로 확인했으며 release/asset 게시를 실행하지 않았다.

- macOS arm64 DMG: `release/0.1.0/ProPre-0.1.0-arm64.dmg` / 167,062,809 bytes. `hdiutil verify` CRC 검사 통과.
- DMG SHA-256: `9b082a738e118d41256a6e06ccf18067f7f263b7c87ec531e770c05f9e13b481`.
- 버전 정보: `release/0.1.0/propre-update.json`, 버전 0.1.0과 mac-arm64 DMG 파일명/주소 일치 및 실제 파일 존재 확인.
- JSON SHA-256: `20eff3ade499f8f127466fe3eb77b94af1eb86660f722db79ed7c7289b25086e`.
- app.asar의 package metadata에 `https://github.com/Cat613/Propre/releases/latest/download/propre-update.json` 포함 확인. 패키지 dependencies에서 electron-updater 제거, Main에서 install-app-update/quitAndInstall 코드 제거 확인.
- `scripts/check-ai-package.mjs`의 패키지 stdio/MCP 합성 호출 통과. packaged GUI는 실제 사용자 자료를 열지 않았다.
- 임시 userData의 1024×768 Electron에서 교체 안내 모달의 실제 screenshot을 확인하고 화면 내부 경계·읽기·닫기/다운로드 버튼을 확인했다.
- scoped Prettier와 소스/문서 whitespace 검사 통과. 전체 형식 검사의 별도 기존 파일 문제는 위에 남겼다.

## 남은 실수용

GitHub 실제 게시, 인터넷에서 받은 unsigned 앱의 macOS 실행 허용과 CPU별 동작, 이전 무료 버전→새 버전의 정상 종료·수동 교체 후 자료/예배/설정 보존, 실제 프로젝터/음향·운영자 수용은 수행하지 않았다. 로컬 DMG와 합성 검사는 Gatekeeper 통과나 공개 다운로드 검증을 뜻하지 않는다. 현재 버전과 동일한 버전 번호를 게시하면 업데이트를 제안하지 않는다.
