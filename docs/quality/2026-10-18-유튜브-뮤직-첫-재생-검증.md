# 유튜브 뮤직 앨범·재생목록 첫 재생 검증

- 연결된 대상 페이지에서 ProPre의 명시적 재생 요청이 첫 곡을 로드하고 재생하도록 구현했다. 링크 저장·음악 준비·확장 연결만으로는 재생하지 않는다.
- 실제 Chrome: 설치된 확장의 소스가 이 저장소의 `browser-extension/youtube-music`임을 UI에서 확인하고 확장을 갱신했다. 기존 INSERT COIN 앨범 탭도 새로고침하고 다시 연결했다.
- 시작 전 관측: video currentSrc 없음, paused=true, currentTime=0, 하단 플레이어 없음. Chrome의 앨범 재생 버튼을 누르지 않았다.
- ProPre에서 준비한 음악 재생을 누른 결과: 앱에 재생 확인 중 → 재생 중, 곡명 아니 근데 진짜 표시. 실제 Chrome video는 readyState=4, paused=false, currentTime 0.188 → 11.132초로 진행했다.
- 앱 일시정지 후 Chrome paused=true, currentTime=16.572초. 앱 이어 재생 후 paused=false, currentTime=17.372초로 진행했다. 검증 후 앱에서 다시 일시정지했다.
- 관련 단위 테스트 21개 통과: 초기 재생, 제목이 일반 텍스트인 플레이어, 대상 불일치, 로딩 중 중지, 만료 후 늦은 재생 차단, 기존 재생 세대 보호, 실제 소켓 브리지, 음악 상태·파일·Chrome 열기.
- Electron 음악 워크스페이스 테스트 5개 통과. 각 테스트는 임시 userData 경로를 생성하고 실제 app 경로가 일치하는지 먼저 확인한다.
- 타입 검사, 린트, 앱 빌드 통과.

## 확인 범위

실제 사이트 검증은 현재 Mac/Chrome 계정의 INSERT COIN 앨범 1건이다. 일반 재생목록의 초기 로드는 동일한 목록 ID 및 헤더 버튼 경로를 사용하며 합성 어댑터 테스트를 통과했으나 모든 유튜브 뮤직 화면, 계정, 로그인·자동 재생 제한에서의 동작을 보증하지 않는다. 페이지를 열고 확장에서 해당 탭을 연결하는 단계는 필요하다. 공개 릴리스·설치 패키지 갱신은 이 검증에 포함하지 않는다.

## 추가 검증: Chrome에서 준비 → 탭 자동 연결

- 앱에서 등록한 INSERT COIN 음악의 `Chrome에서 준비`를 눌렀다. 확장 팝업은 사용하지 않았다. Chrome 새 탭이 열리고 앱에 `Chrome 탭 연결됨 · 앱에서 재생을 누르면 음악이 시작됩니다.`가 표시됐다.
- 연결 직후 실제 Chrome video는 currentSrc 없음, paused=true, currentTime=0이었다. 앱 재생 요청 후 첫 곡이 시작됐고 paused=false, currentTime=6.534초를 관측했다.
- 음악이 재생 중인 상태에서 다시 `Chrome에서 준비`를 눌렀다. 이전 탭은 paused=true, currentTime=11.336초로 멈췄고 새 탭은 자동 연결됐다. 마지막 최종 빌드·확장 갱신 후에도 앱 버튼만으로 자동 연결되는 것을 다시 확인했다. 최종 상태는 음악 미재생, 준비한 음악 재생 버튼 활성화다.
- 단위 테스트 30개 통과. sender 탭 선택, 출처/표시값/상위 프레임 검증, Native 승인, 기존 탭 pause/release 순서, 중단 실패 시 교체 거절, 일회성 요청·대상 불일치 거절, 명시적 중지 시 준비 취소, 준비 페이지 자체 autoplay 차단을 포함한다.
- Electron 음악 워크스페이스 테스트 5개 통과. 타입 검사·린트·앱 빌드 통과. 검증 데이터는 임시 userData를 사용하며 실제 경로를 검사한다.
- 실제 Chrome 확인은 현재 Mac과 계정의 앨범 사례다. 확장 설치와 Native host의 최초 설정이 필요한 점, 앱·확장 코드 갱신 후 재시작·새로고침이 필요한 점은 유지된다. 공개 배포 패키지 갱신이나 모든 로그인·브라우저 환경의 수용 완료를 뜻하지 않는다.


## 추가 검증: 음악 카드에서 한 번에 재생

- 사용자 캡처 및 실행 앱에서 선택한 루시 앨범과 실제 연결된 F.I.A 찬양이 달라 재생 버튼이 비활성화된 것을 확인했다.
- 기본 동작을 카드 재생 한 번으로 통합했다. 연결 없음·다른 곡 연결 상태는 자동으로 올바른 링크에 연결한 뒤 재생하며, 연결과 로딩을 따로 조작하도록 요구하지 않는다. 무음 연결과 관리 동작은 더 보기로 이동했다.
- 실제 앱을 업데이트해 음악 2개가 등록된 상태에서 별도 선택이나 준비 없이 루시-insert coin 재생을 한 번 눌렀다. 자동 Chrome 연결 이후 첫 곡 아니 근데 진짜의 재생 중 표시를 확인했다. 앱 일시정지 후 실제 Chrome 플레이어가 0:20 / 3:58에서 멈춘 것을 확인했다.
- 준비 완료 응답은 document_start 보고가 아닌 재생 가능 대상 관측을 기다리도록 보완했다. 작업 중 재생 취소/음악 중지와 늦은 연결 응답의 재생 방지를 유지했다. 성공 후 로딩 안내도 지운다.
- 관련 단위 테스트 32개 및 Electron 테스트 6개 통과. 카드 재생 한 번, 더 보기 접근, 대상 자동 복구, 자동 연결 중 중지, 준비 가능 관측 대기를 포함한다. 타입 검사·린트·앱 빌드 통과.
