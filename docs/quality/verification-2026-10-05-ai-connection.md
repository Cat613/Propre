# AI 로컬 연결·자료 준비 구현과 검증

검증일: 2026-10-05 (Asia/Seoul) · 제품 0.1.0 · REQ-034 / TASK-029 / TC-034 / ADR-011 / FLOW-009

## 결과와 기준

로컬 MCP 9개 도구, 연결 설정 UI, 패키지 stdio 프로그램, 컨트롤 준비 명령/Repository 저장, 격리된 PNG 미리보기를 구현했다. 자료 검색/조회·성경 위치·생성/일괄 수정·진행 순서·미리보기까지 실제 SDK 클라이언트와 Electron에서 확인했다. 현재 선택·송출 유지와 버전/중복 요청/편집 중/저장 실패/Undo/재시작 경계를 확인했다.

[설계와 계약](../engineering/ai-connection.md), [사용·실패 복구](../operations/ai-connection.md), [소스와 패키지 SHA-256 기록](source-manifest-2026-10-05-ai-connection.json)을 기준으로 읽는다. 작업 시작 시 이미 큰 범위의 수정/미추적 파일과 동시 성경 삽입 작업이 있었으며 이를 유지했다. 이번 작업은 해당 전체 코드가 이번에 처음 작성되었다고 주장하지 않는다.

호스트: macOS arm64 / Node 25.2.1. 실제 앱: Electron 44.5.1 / 내장 Node 24.21.0 / Chromium 152.0.7977.130. 프로젝트 기준 Node 24/최소 22.12는 유지했다. 공식 MCP TypeScript SDK 1.32.0을 명시 버전으로 추가했다.

## 신규 검증의 구체적 근거

### 로컬 MCP와 저장 계약 — 11개

`tests/automation.test.ts`는 실제 SDK 클라이언트로 초기화·9개 도구 발견/annotations·인자 검증을 수행한다. 조회 권한의 변경 거절, 동일 requestId 동시 재시도/결과 재사용, 다른 입력 재사용 거절, 결과 불명 뒤 재실행 방지, 잘못된 인증·Host·Origin·큰 본문·잘못된 JSON, 권한 교체 후 이전 자격 해제, 0600 파일/시작·해제 정리, 실제 stdio 프로그램의 호출/해제를 확인한다. 인증값을 검사 출력이나 산출물에 저장하지 않는다.

`tests/prepared-repository.test.ts`는 현재 작업본 ID를 유지한 새 자료 준비와 재열기, 동시 compare-and-save에서 하나만 성공하는 결과, 저장 실패의 이전 상태 보존, 순서 원본 비교·중복 자료·없는 자료 보호를 확인한다.

### 실제 Electron의 AI 준비 — 7개

1. 설정의 기본 꺼짐/조회 권한/허용/연결됨/해제와 복사 설정을 확인한다. 복사된 설정으로 실제 Electron Node 모드 stdio를 실행한다. 설정에 인증 토큰이 없음을 확인하고 조회 권한으로 생성을 거절한다.
2. 기존 합성 본문을 메인·모니터에 송출한 채 새 찬양/내장 성경 위치/새 성경 자료/반복 순서를 준비하고 PNG를 얻는다. 현재 선택·송출 본문·작업본 ID를 보존한다. 정상 종료/재시작 후 자료·순서 복원과 연결 꺼짐·마지막 본문 자동 재송출 없음까지 확인한다.
3. 선택 자료의 제목·본문·슬라이드 추가를 한 명령으로 저장하고 동일 요청 결과 재사용과 stale revision 거절을 확인한다. 한 번 Undo로 원래 자료로 돌아오고 활성 자료의 수정은 거절한다.
4. 다른 자료 수정은 현재 선택/Undo 경계를 유지한다. 순서 변경 뒤 이전 revision의 교체가 새 순서를 덮지 못하게 한다.
5. 열려 있는 편집 모달의 변경 요청 거절과 새 자료 저장 실패를 확인한다. 실패한 자료는 라이브러리에 추가하지 않으며 같은 requestId 재시도로 다시 실행하지 않는다. 저장소 복구 후 새 요청은 성공한다.
6. 선택 자료 수정의 디스크 쓰기 실패는 `SAVE_FAILED/applied: true`로 반환한다. 편집본/journal과 앱의 저장 실패 표시를 유지하며 운영자가 재시도하면 저장된다.
7. 저장 스타일과 기본 프리셋이 다른 자료의 미리보기에서 실제 선택/첫 송출에 적용할 기본 프리셋을 사용하고 `effectiveGlobalSlideStyle/styleSource`를 반환한다. 실제 자료 열기 후 저장 스타일과 일치한다.

### 패키지 연결 프로그램

`scripts/check-ai-package.mjs`가 생성된 `.app/Contents/MacOS/ProPre`를 `ELECTRON_RUN_AS_NODE=1`로 실행하고 `app.asar/scripts/propre-mcp.mjs`를 통해 SDK 초기화와 합성 `get_app_state` 호출을 완료한다. 별도 시스템 Node를 연결 프로그램으로 사용하지 않는다.

이 검사는 임시 인증 파일과 합성 로컬 서버만 사용하고 패키지 GUI나 실제 사용자 작업공간을 열지 않는다. 패키지 GUI의 사용자 자료 전환/실제 계정 연결까지 확인한 것으로 표현하지 않는다.

## 남은 범위와 전달

- 구현과 자동 검사: 완료. 신규 기능은 같은 컴퓨터의 MCP 클라이언트에서 자료 준비까지 제공한다.
- 실제 사용자 Codex/다른 클라이언트의 계정·설정 등록·모델 도구 선택: 이번에 수행하지 않았다. [사용 안내](../operations/ai-connection.md)에 등록/재연결 흐름을 기록했다.
- 웹 원격 연결·공개 플러그인·OAuth 서버·실시간 송출 도구: 후속 범위, 이번 구현에 없다.
- 물리 프로젝터/스피커·운영자 리허설·다른 OS·장시간 운영·배포 서명/공증: 기존 릴리즈 확인 경계를 유지한다. 패키징 과정에서 Developer ID 서명은 생략되었다.
- 미디어 실패를 미리보기 오류로 전환하는 경로는 코드에서 확인했다. 실제 모든 이미지/영상 형식·장비 조합이 검증되었다고 주장하지 않는다.
- requestId의 중복 방지는 같은 허용 세션의 500개 변경 요청 범위다. 세션 변경 후에는 재조회한다. 결과 불명을 성공이나 새로운 실행 허용으로 처리하지 않는다.
- 실제 사용자 자료·보호 키·AI 클라이언트 설정을 읽거나 변경하지 않았다. 기존/동시 수정은 유지했으며 커밋·푸시·공개 배포는 수행하지 않았다.
