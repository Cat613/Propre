## 성능 측정의 한계

자동 실행 과정에서 시작부터 초기 자료·저장 상태 준비까지의 시간과 Electron 프로세스의 working-set 합계를 숫자로 수집한다. 위치는 `test-results/operational-metrics.json`이며 원문·URL·키·개인 경로는 기록하지 않는다. 앱 실행 시험의 합성 규모와 숨긴 창 조건에서 측정한 값으로, 실제 설치 앱의 시작 시간이나 장시간 메모리 누수를 보증하지 않는다. working-set 합산은 프로세스 간 공유 메모리를 중복 집계할 수 있다.

최종 원래 프로젝트 표본 16회 시작의 중앙값 291ms(280~2912ms), 각 사례 종료 시 working-set 합계 약 447~704MiB를 확인했다. 첫 실행의 Electron 다운로드가 포함되어 시작 시간 상한에 영향을 준다. 창 수·편집 화면에 따라 부하가 달라지며 현장 장시간 기준은 별도 지정해야 한다.

## 미실행·제약

실물 다중 모니터/프로젝터와 케이블 변경, 실제 음향, 모든 해상도·폰트·키보드/IME·VoiceOver 수용, 서명·공증·깨끗한 장비 설치·실제 사용 자료 업그레이드/롤백, 실제 Gemini 계정 호출·오류, 사용자 운영 과제와 장시간 부하, 원격 CI 실행은 미실행이다. 코드/성경 자료 권리는 출처·허락 증거가 없으므로 완료로 표시하지 않는다.

테스트 중 발견한 locator 대상과 파일 기록 완료 대기를 수정하고 전체 검사를 다시 실행했다. 실패 시 정상 종료를 막는 앱 정책 때문에 테스트 정리는 합성 데이터 앱만 종료한다. 실제 운영 앱의 저장 실패 보호를 해제한 것은 아니다.
