## 표시 상태

| 대상 | 상태 | 사용자가 볼 정보와 다음 행동 |

색·점멸만으로 상태를 전달하지 않는다. 현재 `isOutputEnabled`는 창 존재 여부이고 `PreviewPanel`의 Active는 내용 여부여서 서로 같은 상태를 뜻하지 않는다. 목표에서는 창 준비, 콘텐츠 송출, 장비 연결을 구분한다.

## 편집·모달 정책

- 편집 모달의 `적용`은 편집 초안 반영이다. 영구 저장을 함께 수행하지 않는다면 `저장` 문구를 사용하지 않는다.
- 저장/폐기/취소는 발표를 바꾸거나 종료할 때 제공한다. `취소`는 원래 발표와 위치로 돌아간다.
- 설정 모달은 변경을 초안에 모았다가 저장하거나, 즉시 반영 항목임을 명확히 표시한다. 현행 라우팅·Stage 크기 변경은 즉시 반영되므로 `취소`가 되돌림을 뜻한다고 안내하면 안 된다.
- 최상위 모달이 Escape와 진행 키를 처리한다. 입력 중 숫자·방향키·IME 조합 입력은 라이브 송출에 사용하지 않는다.
- 실행 취소는 발표 편집 범위로 한정하고 라이브 중단과 자료 삭제를 구분한다.

## 접근성·문구 기준

버튼은 이름을 가지고 키보드 포커스가 보이게 한다. 모달은 제목·초점 이동·닫은 후 복귀 대상을 제공한다. 상태 알림은 보조 기술에 전달하고 복구가 필요한 오류는 짧은 토스트만으로 끝내지 않는다. 대비와 최소 읽기 크기는 실제 제어 장비에서 점검한다.

`Songs`, `Bible`, `Go`, `Active` 등 혼합 용어를 발표/성경/검색/송출 상태와 일관되게 정리한다. 전체 국제화 프레임워크 도입은 이번 범위의 선행 조건이 아니다.

## 화면 수용 검사

첫 실행, 빈 라이브러리, 미저장 자료, 성경 검색 실패, 누락 미디어, 저장 실패, Output 꺼짐·재연결, Stage 마지막 슬라이드, 모달 중 진행 키를 각각 검사한다. 세부 절차는 TC-001~029를 따른다.

## 플레이리스트 파일 동작 (2026-10-05 적용)

기존 플레이리스트 제목 아래에 `파일 저장`, `파일 불러오기` 버튼을 배치한다. 빈 순서에서는 저장을 비활성화한다. 파일 작업 중 두 버튼을 비활성화하고 상태 문구를 표시하며 진행 단축키와 AI 준비 변경을 막는다. 시스템 파일 선택창을 사용하고 불러오기는 총 순서 수·곡 순서·찬양 목록 등록/현재 순서 교체/같은 곡 재사용/현재 작업 및 송출 유지 설명을 확인창에 표시한다. 취소를 기본값으로 두며 결과 알림에서 새 곡과 재사용 곡 개수를 안내한다. 50개 초과는 앞 50개와 전체 개수를 표시한다. REQ-036/TC-036/ADR-013 참조.

## 콘티 보관함 (2026-10-06 적용)

플레이리스트 제목을 현재 콘티 이름/선택 날짜·자동 저장 안내와 연결한다. 콘티 보관함 모달은 새 이름/날짜/현재 순서 복사, 보관/휴지통 전환, 이름·날짜 검색, 최근 수정 순서와 최근 열기 날짜, 열기/복제/이름·날짜/휴지통/복원을 제공한다. 작은 화면은 모달 본문을 스크롤한다. 작업 중 버튼/입력을 잠그고 오류는 모달 안에 유지해 재시도할 수 있다. 플레이리스트에는 현재 편집이 원곡인지 콘티 사본인지와 소속을 표시하고 사본일 때 별도 원곡 반영 버튼을 제공한다. 원곡이 없으면 새 곡 저장으로 표시한다. native 확인창에서 본문 일부/슬라이드 수와 원곡 변경 여부를 안내한다. TC-038/ADR-015 참조.
