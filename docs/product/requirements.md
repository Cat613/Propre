작성일: 2026-10-04 · 상태: 구현 기준 갱신 / 운영·배포 검증 분리

사용자의 전체 개선·자동 저장·창 구분 요청에 따라 REQ-002/006/020을 실제 구현 정책으로 갱신하고 REQ-031을 추가했다. [구현 현황](../review/feature-inventory.md), [후속 검증](../quality/verification-2026-10-04-implementation.md), [백로그](../delivery/backlog.md)에서 코드·자동/네이티브·물리 장비·배포 증거를 구분한다.

## 범위 변경 규칙

기존 발표의 식별·저장·라이브 재개·지우기 범위를 바꾸는 결정은 [ADR](../governance/decisions.md)에 기록한다. 확정 전에는 작업에 `정책 확정 필요`를 표시한다. 기능 확대는 첫 안정화 수용 기준을 바꾸지 않고 별도 REQ를 추가한다.

## 기능과 검증의 연결

REQ → TASK → TC는 위 표를 기준으로 관리한다. 문제의 재현 근거는 백로그에 연결된 REV에서 확인한다. 하나의 요구사항이 여러 작업에 걸쳐 있으면 모든 필수 작업과 테스트를 통과하기 전까지 충족으로 표시하지 않는다.
