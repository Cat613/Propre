## 세 패널 편집 화면 (2026-10-12 적용)

별도 상단 앱 바 없이 세 패널을 배치한다. 현재 콘티 이름은 좌측, 자동 저장 상태는 중앙 하단에 표시한다. 좌측 콘티/찬양·성경, 중앙 편집, 우측 송출 미리보기/설정에 공통 배경·테두리·버튼·입력 스타일을 적용한다. 좌우 패널 너비를 조절할 수 있고 조절한 비율을 기억한다.

- **좌측:** 현재 콘티의 곡 수·날짜와 보관함, 파일 저장·새 콘티로 불러오기·현재 콘티에 추가를 제공한다. 곡 순서는 번호와 슬라이드 수로 읽고 드래그 핸들로 조절한다. 찬양 검색에는 검색 지우기와 결과 없음 안내를 제공한다.
- **중앙:** 현재 자료가 콘티 곡인지 찬양 자료인지 표시하고 제목 수정 버튼을 제공한다. 텍스트·성경·미디어 슬라이드 추가, 가사 편집, AI 찬양 준비를 제목 아래에 배치한다. 슬라이드 카드의 순서·파트·송출 상태를 구분하고 빈 자료에는 첫 슬라이드 추가를 안내한다.
- **우측:** 미리보기 옆에 송출 창 닫힘/연결 중/화면 적용됨/오류를 표시한다. 배경·텍스트 지우기와 전체 중지는 미리보기 바로 아래에 둔다. 미디어·스타일·레이어·설정은 아이콘과 이름을 함께 표시하는 탭으로 전환한다. 스타일 정렬 버튼은 키보드와 보조 기술이 읽을 수 있는 이름을 제공한다.

1100×800과 1440×960 창의 합성 자료 화면을 확인했다. 작은 창에서 파일·중지 버튼은 한 줄로 표시하며 스타일 프리셋 선택과 관리 버튼을 두 줄로 나눈다. 기존 편집·자동 저장·원곡 반영·송출 동작의 실행 기록은 [세 패널 검증](../quality/2026-10-12-세-패널-작업-화면-개선-검증.md)에 기록한다.

## 화면 테마와 곡 목록 밀도 (2026-10-12 적용)

우측 설정의 **화면 테마**에서 다크·라이트를 전환한다. 기존 설정에 테마가 없으면 다크를 기본값으로 사용하고, 선택한 값은 기존 설정 자동 저장 경로로 유지한다. 편집 화면의 목록·카드·입력·탭·보관함·모달에 적용하며 송출 미리보기와 실제 송출 콘텐츠는 자료에 지정한 색상을 사용한다.

콘티·찬양 목록은 행의 위아래 여백과 글자 크기를 줄이고 번호를 작게 표시한다. 제목과 슬라이드 수는 구분한다. 드래그/제거/추가 버튼은 마우스 오버·키보드 포커스에서 표시하며 제목 폭을 미리 차지하지 않도록 배치한다.

## 표시 상태

| 대상 | 상태 | 사용자가 볼 정보와 다음 행동 |
| --- | --- | --- |
| 발표 | 새 자료 / 미저장 / 저장 중 / 저장됨 / 저장 실패 / 복구 초안 | 상태 문구 + 저장·재시도·복구 선택 |
| 출력 | 꺼짐 / 준비 중 / 준비됨 / 송출 중 / 중단 / 장비 없음 / 오류 | 장비 이름·현재 콘텐츠 + 켜기·점검·재연결 |
| 검색 | 입력 대기 / 검색 중 / 유효 결과 / 형식 오류 / 범위 오류 / 결과 없음 | 입력 유지 + 수정 안내·적용 방식 선택 |
| 미디어 | 등록 중 / 사용 가능 / 복사 실패 / 파일 누락 / 재생 실패 | 해당 파일별 상태 + 다시 선택·재연결 |
| AI | 미설정 / 실행 대기 / 진행 / 취소 / 실패 / 검토 필요 | 키 설정 진입·취소·재시도·수동 편집 |

색·점멸만으로 상태를 전달하지 않는다. 현재 `isOutputEnabled`는 창 존재 여부이고 `PreviewPanel`의 Active는 내용 여부여서 서로 같은 상태를 뜻하지 않는다. 목표에서는 창 준비, 콘텐츠 송출, 장비 연결을 구분한다.

## 편집·모달 정책

- 편집 모달의 `적용`은 편집 초안 반영이다. 영구 저장을 함께 수행하지 않는다면 `저장` 문구를 사용하지 않는다.
- 일반 자료는 자동 저장과 실패 시 재시도·내보내기를 사용한다. 예배 순서 상세는 `변경 저장`으로 확정하며 취소하면 해당 입력 초안을 버린다. 일반 전환마다 저장/폐기/취소를 묻는 정책은 아니다.
- 설정 모달은 변경을 초안에 모았다가 저장하거나, 즉시 반영 항목임을 명확히 표시한다. 현행 라우팅·Stage 크기 변경은 즉시 반영되므로 `취소`가 되돌림을 뜻한다고 안내하면 안 된다.
- 최상위 모달이 Escape와 진행 키를 처리한다. 입력 중 숫자·방향키·IME 조합 입력은 라이브 송출에 사용하지 않는다.
- 실행 취소는 발표 편집 범위로 한정하고 라이브 중단과 자료 삭제를 구분한다.

## 접근성·문구 기준

버튼은 이름을 가지고 키보드 포커스가 보이게 한다. 모달은 제목·초점 이동·닫은 후 복귀 대상을 제공한다. 상태 알림은 보조 기술에 전달하고 복구가 필요한 오류는 짧은 토스트만으로 끝내지 않는다. 대비와 최소 읽기 크기는 실제 제어 장비에서 점검한다.

`Songs`, `Bible`, `Go`, `Active` 등 혼합 용어를 발표/성경/검색/송출 상태와 일관되게 정리한다. 전체 국제화 프레임워크 도입은 이번 범위의 선행 조건이 아니다.

## 화면 수용 검사

첫 실행, 빈 라이브러리, 미저장 자료, 성경 검색 실패, 누락 미디어, 저장 실패, Output 꺼짐·재연결, Stage 마지막 슬라이드, 모달 중 진행 키를 각각 검사한다. 세부 절차는 TC-001~029를 따른다.

## 플레이리스트 파일 동작 (2026-10-05 적용)

기존 플레이리스트 제목 아래에 `파일 저장`, `파일 불러오기` 버튼을 배치한다. 빈 순서에서는 저장을 비활성화한다. 파일 작업 중 두 버튼을 비활성화하고 상태 문구를 표시하며 진행 단축키와 AI 준비 변경을 막는다. 시스템 파일 선택창을 사용하고 불러오기는 총 순서 수·곡 순서·찬양 목록 등록/현재 순서 교체/같은 곡 재사용/현재 작업 및 송출 유지 설명을 확인창에 표시한다. 취소를 기본값으로 두며 결과 알림에서 새 곡과 재사용 곡 개수를 안내한다. 50개 초과는 앞 50개와 전체 개수를 표시한다. REQ-036/TC-036/ADR-013 참조.

## 콘티 보관함 (2026-10-06 적용)

플레이리스트 제목을 현재 콘티 이름/선택 날짜·자동 저장 안내와 연결한다. 콘티 보관함 모달은 새 이름/날짜/현재 순서 복사, 보관/휴지통 전환, 이름·날짜 검색, 최근 수정 순서와 최근 열기 날짜, 열기/복제/이름·날짜/휴지통/복원을 제공한다. 작은 화면은 모달 본문을 스크롤한다. 작업 중 버튼/입력을 잠그고 오류는 모달 안에 유지해 재시도할 수 있다. 플레이리스트에는 현재 편집이 원곡인지 콘티 사본인지와 소속을 표시하고 사본일 때 별도 원곡 반영 버튼을 제공한다. 원곡이 없으면 새 곡 저장으로 표시한다. native 확인창에서 본문 일부/슬라이드 수와 원곡 변경 여부를 안내한다. TC-038/ADR-015 참조.

## 현재 콘티와 확장 화면 (2026-10-16)

콘티 제목/날짜 클릭으로 정보를 수정하며 `새 콘티`는 빈 콘티·현재 순서 복사를 명시 선택한다. 파일·원곡 반영·템플릿·인쇄는 더 보기 메뉴에 모은다. 곡/전체 순서를 전환하고, 편집 자료가 현재 콘티 소속일 때 중복 안내를 생략한다. 세부 동선은 [콘티 사용 안내](../operations/예배별-콘티-보관-편집.md)를 따른다.
