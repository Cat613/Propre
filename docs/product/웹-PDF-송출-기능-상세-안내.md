## 1. 무엇을 송출할 수 있는가

기존 슬라이드, 이미지, 영상, 오디오에 웹 주소와 PDF 페이지를 추가했다. 오른쪽 `미디어` 탭의 `송출 자료`에서 사용한다.

| 자료 | 용도 | 실행 방식 |
| --- | --- | --- |
| 기존 슬라이드 | 찬양 가사·성경·직접 만든 화면 | 기존 슬라이드 실행 |
| 이미지·영상 | 기존 배경 미디어 | 기존 미디어 실행 |
| 오디오 | 화면과 별도의 음악 재생 | 기존 오디오 실행 |
| 웹 | 입력한 HTTP(S) 주소의 실제 웹 화면 | 주소 등록 → 화면 준비 → 준비 화면 송출 |
| PDF | 안내문·악보·발표 자료의 특정 페이지 | 원본 등록 → 페이지 준비 → 준비 화면 송출 |

PPT·Word·Excel·한글은 PDF로 내보내 등록한다. 해당 파일의 직접 편집·변환, 다른 앱의 창이나 데스크톱 공유는 현재 지원하지 않는다.

## 2. 자료 등록·검색·삭제

### URL 등록

`URL 추가`에서 웹 주소와 선택적 이름을 입력하고 `주소 저장`을 누른다. 이름이 없으면 호스트명을 사용한다. `example.com`처럼 스킴을 생략하면 HTTPS로 보완하며, HTTP 사이트는 `http://`를 직접 입력한다.

등록은 주소를 목록에 저장하는 기능이다. 등록하거나 목록에서 선택하는 것만으로 사이트에 접속하거나 현재 송출을 바꾸지 않는다. `주소 수정`은 해당 자료의 이름과 저장 주소를 변경한다. 준비 창에서 다른 페이지로 이동해도 등록 주소는 자동으로 바뀌지 않는다.

### PDF 등록

`PDF 추가`로 하나 이상의 파일을 선택한다. 첫 페이지를 실제로 읽고 렌더한 후 앱 관리 폴더에 원본을 복사한다. 원래 위치의 파일을 옮기거나 삭제해도 앱의 복사본을 사용할 수 있다.

암호가 없는 100MiB 이하, 1~1,000페이지 PDF를 지원한다. 지원하지 않는 파일은 이름과 등록 실패 안내를 표시하고 다시 선택할 수 있다. 여러 파일 중 일부가 실패해도 정상 파일의 등록 결과는 유지한다.

### 검색·삭제

`웹·PDF 자료 검색`은 등록 자료의 이름을 검색한다. 자료 버튼에는 종류·이름과 현재 송출 여부를 표시한다. 선택한 자료의 `자료 삭제`는 활성 목록에서 숨기고 복원 가능한 상태로 저장한다. 현재 송출 중인 자료는 삭제할 수 없다. `삭제 되돌리기`는 가장 최근 삭제 자료부터 복원하며 재시작 후에도 사용할 수 있다. 삭제 뒤에는 이 버튼으로 초점을 옮겨 웹·PDF 영역의 Ctrl/Cmd+Z로도 복원할 수 있다. 슬라이드 편집 영역의 Undo와는 별도의 기능이다. 삭제한 PDF의 원본은 복원을 위해 보관하고 미디어 정리에서 제외한다.

이전 구현에서 완전히 삭제한 자료는 복원 가능한 삭제 항목이 없을 때 `삭제 되돌리기`로 최근 저장 복사본 5개를 조회한다. 현재 목록에 없는 자료만 복원하고 곡·콘티·설정은 되돌리지 않는다. PDF 원본이 남아 있고 저장된 파일 hash가 일치해야 한다. 복사본에도 남아 있지 않으면 전체 백업이나 원본 파일로 복구해야 한다.

## 3. 선택·준비·송출은 서로 다른 동작이다

컨트롤의 `준비 패널 닫기` 또는 선택한 자료를 다시 누르면 준비 패널을 접는다. 등록 자료·별도 브라우저·현재 송출을 종료하지 않는다. 같은 자료를 다시 선택하면 패널을 열 수 있으며 다시 송출하려면 준비를 확인한다. 현재 송출의 복귀·전체 중지 도구는 패널을 접어도 남는다.

| 동작 | 화면에서 하는 일 | 현재 송출 |
| --- | --- | --- |
| 자료 선택 | 준비 패널을 열고 사용할 자료를 고름 | 유지 |
| 화면 준비 | 웹을 로딩하거나 PDF 페이지를 렌더 | 유지 |
| 준비 확인 | 현재 웹 상태를 다시 확인해 송출 가능 상태로 만듦 | 유지 |
| 준비 화면 송출 | 준비한 웹 또는 PDF로 실제 화면을 전환 | 변경 |
| 슬라이드로 복귀 | 현재 슬라이드·배경·레이어를 다시 표시 | 슬라이드 모드 |
| 전체 중지 / F2 | 화면·음성·대기 작업을 중지 | 검은 화면 |

자료를 준비해도 현재 곡·콘티·편집 중인 문서·Undo 기록을 바꾸지 않는다. 준비 중 다른 슬라이드를 실행하거나 전체 중지를 누르면 이전 준비 확인은 무효가 된다. 다시 준비하거나 확인한 뒤 송출해야 한다.

## 4. 웹 준비 창과 창 전환

웹 자료에서 `화면 준비`를 누르면 별도의 웹 준비 창이 열린다. 그 창에서 로그인·스크롤·입력·버튼 조작으로 필요한 화면을 만든다. 준비와 송출은 같은 브라우저 화면을 사용하므로 송출할 때 로그인이나 입력 상태를 따로 복사하지 않는다.

준비 창의 가장자리로 크기를 자유롭게 조절할 수 있고 웹 내용이 창 크기에 맞춰진다. 최초 크기는 현재 화면의 작업 영역 안에 맞추며 최소 크기는 480×320이다. 크기 변경은 준비 확인을 무효화하므로 다시 확인한 뒤 송출한다. `준비 확인`이나 `브라우저 조작`은 사용자가 조절한 크기를 유지한다. 실제 송출에서는 메인 출력 크기에 맞춰 웹 배치가 달라질 수 있다.

컨트롤로 돌아와 슬라이드를 누르는 동안 이미 준비 중인 웹 창을 자동으로 앞으로 가져오지 않는다. 웹 송출에서 슬라이드로 복귀할 때는 웹을 준비 창으로 돌려놓고 창을 숨긴다. 다시 조작하려면 `브라우저 조작`을 누른다. 준비 창의 닫기 버튼은 웹을 종료하지 않고 숨기며 같은 버튼으로 다시 열 수 있다.

| 준비 도구 | 동작 |
| --- | --- |
| 뒤로 / 앞으로 | 해당 브라우저의 탐색 이력 이동 |
| 새로고침 | 현재 페이지를 다시 읽음 |
| 브라우저 조작 | 준비 창을 열어 직접 조작 |
| 웹 확대 | 50%, 75%, 100%, 125%, 150%, 200% |
| 준비 확인 | 준비 창의 현재 페이지로 송출 확인을 갱신 |

페이지 이동·새로고침·확대와 출력 크기 변경은 이전 준비 확인을 무효화한다. 웹의 움직이는 콘텐츠를 정지 사진으로 고정하는 기능은 아니므로 동영상·시계·SPA 내용은 준비 확인 후에도 계속 움직일 수 있다.

## 5. 웹 송출·미리보기·실시간 조작

`준비 화면 송출`은 같은 웹 화면을 메인 송출 창으로 옮긴다. 컨트롤 미리보기는 캡처 화면이며 최대 5fps로 갱신되어 실제 송출보다 늦을 수 있다. 송출 화면 자체를 5fps로 제한하지는 않는다.

송출 중에는 뒤로·앞으로·새로고침·확대·준비 창 열기를 잠근다. 페이지 이동이 필요하면 슬라이드로 복귀한 뒤 준비 창에서 처리한다. 페이지 자체의 자동 갱신·SPA 내부 변화는 계속될 수 있다.

`실시간 조작 (실제 송출에 적용)`을 선택하면 조작 미리보기의 클릭·휠·일반 키가 실제 웹 화면에 전달된다. 미리보기 지연 때문에 정확한 위치를 확인한 뒤 사용한다. 한글 IME 입력과 본격적인 페이지 이동은 준비 창에서 처리한다. 복귀·중지·새 송출 때 조작은 다시 잠긴다. 웹 화면이 중단됐을 때도 조작할 수 없도록 잠근다.

## 6. 웹 소리와 기존 오디오

웹은 준비와 기본 송출에서 음소거한다. 기존 오디오는 웹·PDF 화면을 준비하거나 송출하는 것만으로 중단하지 않는다.

`웹 소리 켜기`가 성공하면 기존 오디오를 일시정지하고 웹 소리를 켠다. 명령이 거절되면 기존 오디오 재생 상태를 바꾸지 않는다. `웹 소리 끄기`, 슬라이드 복귀, 전체 중지에서는 웹을 음소거한다. 웹 소리를 끄거나 슬라이드로 복귀해도 앞서 일시정지한 오디오를 자동 재생하지 않으므로 필요한 경우 직접 재생한다.

## 7. PDF 페이지·회전·송출 중 페이지 이동

PDF를 선택하면 현재 준비 번호 주변을 6페이지 단위의 썸네일로 보여준다. 썸네일을 누르거나 `준비 이전`·`준비 다음`으로 페이지를 렌더한다. 번호를 직접 입력한 경우 `화면 준비`로 확인한다. `회전`은 90도씩 바꾸며 준비 미리보기와 썸네일에 적용한다.

페이지 전체가 보이도록 비율을 유지해 맞추고 남는 영역은 검은 여백으로 표시한다. 기존 가사·공지·로고 등이 PDF를 덮지 않는다. 준비만 한 다른 페이지나 회전값은 현재 송출을 바꾸지 않는다.

`송출 이전`·`송출 다음`은 현재 송출 중인 PDF의 페이지를 즉시 준비하고 전환한다. 이때 송출에 확정된 회전값을 유지한다. 별도로 선택해 둔 준비 페이지나 회전을 다른 값으로 바꾸지 않는다. 송출 페이지 이동으로 이전 준비 확인이 무효가 되면 `준비 화면 송출`은 비활성화되며, 준비 화면을 새로 확인해야 한다.

예: 1페이지를 0도로 송출 중에 다음 자료를 위해 1페이지를 90도로 준비하더라도, `송출 다음`은 2페이지를 0도로 송출한다. 준비 패널에는 선택한 1페이지·90도 미리보기가 남는다.

## 8. 모니터 화면

모니터는 PDF의 현재·다음 페이지를 보여주고 마지막 페이지에는 문서 끝을 표시한다. 웹에서는 자료 이름·현재 웹 호스트·송출 상태를 요약한다. 기존 슬라이드 모드의 현재·다음 가사와 모니터 시계는 기존 흐름을 따른다.

웹 모니터는 웹 페이지를 별도로 실행하지 않는다. 실제 페이지 조작은 컨트롤의 조작 미리보기 또는 준비 창을 사용한다.

## 9. 슬라이드 복귀·전체 중지·기존 기능

`슬라이드로 복귀`와 기존 슬라이드·이미지·영상 실행은 외부 자료를 끝내고 최신 슬라이드 레이어로 돌아간다. 외부 자료가 표시되는 동안 기존 레이어 값은 유지하므로 복귀 후 사용할 수 있다. 오디오만 실행하는 경우 화면 소스는 유지한다.

`전체 중지` 또는 F2는 웹을 종료하고 PDF 대기 작업을 취소하며 오디오·배경·가사·공지·props·메시지를 모두 지운다. 웹 준비 창에 입력 초점이 있어도 F2는 전체 중지로 작동한다. 늦게 끝난 웹 전환이나 PDF 준비가 중지된 화면을 다시 송출하지 않는다.

F1 텍스트 지우기와 F4 배경 지우기는 기존 슬라이드 레이어를 대상으로 한다. 웹·PDF는 독립 화면이므로 외부 자료 위에 가사·공지 등을 합성하지 않고, 크로마키 설정으로 외부 자료의 색을 바꾸지 않는다.

## 10. 저장·재시작·백업·재연결

등록 URL, PDF 복사본, 마지막 PDF 준비 페이지·회전은 저장한다. 새 작업 공간은 v3이며 이전 v1·v2 원본은 보존한다. 재시작하면 등록 자료를 다시 보여주되 웹에 자동 접속하거나 외부 자료를 자동 송출하지 않는다.

전체 `.ppros` 백업은 PDF 원본과 등록 URL을 포함한다. 단일 곡·콘티 파일에는 외부 자료를 넣지 않는다. 쿠키·로그인 세션·탐색 이력·캡처·준비 확인은 백업하지 않는다. 전체 파일은 JSON·base64를 포함해 200MiB 한도를 적용한다.

앱 내부 PDF 복사본이 누락됐다면 설정의 `누락 미디어 다시 연결`에서 같은 형식의 파일을 선택한다. 새 원본의 페이지 수를 확인하고 준비 번호를 범위 안으로 보정한다. 이전 PDF 렌더 캐시와 섞이지 않도록 새 파일로 다시 준비한다. 송출 중인 PDF는 먼저 송출을 끝내야 다시 연결할 수 있다.

| 준비 후 페이지 이동 또는 출력 크기 변경 | 준비 확인 무효 | 로딩 완료 후 준비 확인 |
| PDF 페이지 렌더 실패 | 기존 송출 유지 | 다른 페이지 또는 원본 확인 |
| 웹 화면 중단 | 마지막 캡처가 있으면 정지 화면, 컨트롤 경고 | 슬라이드 복귀 후 다시 준비 |
| 이미 송출 중인 자료 수정·삭제 | 변경 거절 | 먼저 슬라이드 복귀 |
| 앱 종료·전체 중지 | 브라우저/대기 작업 정리 | 자료 목록에서 다시 준비 |

웹·PDF 준비를 위해 실제 화면을 바꾸거나 파일을 수정하지 않는다. 실패한 전환은 가능한 경우 이전 송출로 복구한다. 실제 사이트 로그인·DRM 및 실물 장비 표시 결과는 사이트·장비별로 별도 확인해야 한다.

## 12. 웹의 지원 범위

HTTP(S)만 등록하며 로컬 파일·앱 내부 주소·주소에 포함한 ID/비밀번호와 알려진 인증 query는 거절한다. 카메라·마이크·화면 공유·위치·클립보드 권한, 팝업 새 창, 파일 업로드와 다운로드는 지원하지 않는다. 팝업을 사용하는 인증이나 내장 브라우저를 거절하는 사이트는 이용이 제한될 수 있다.

웹 로그인은 같은 앱 실행 중에 유지할 수 있으나 종료하면 버린다. 개인 인증 링크는 등록하지 않고 일반 사이트 주소를 등록한 뒤 준비 창에서 로그인한다. 실제 대상 사이트·DRM, Windows, 프로젝터·스피커 및 저사양 장비 성능은 자동 개발 검사와 별도의 수용 범위다.
