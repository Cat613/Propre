# MUS-01 음악 준비와 공통 패널

작성: 2026-10-17 · 상태: 설계 제안 / 미구현

## 사용 흐름

1. 운영자가 예배의 `음악` 영역에서 `음악 추가`를 누른다.
2. `로컬 파일` 또는 `유튜브 뮤직 링크`를 선택한다. 이름은 예: 예배 전 음악, 기도 반주, 예배 후 음악이다.
3. 로컬은 파일 검사 후 구간·반복·음량을 정한다. 유튜브 뮤직은 링크를 저장하고 브라우저에서 재생목록을 확인한다. 링크 확인은 브라우저 페이지 이동이므로 이미 재생 중인 연결 탭을 재사용하지 않는다.
4. 필요하면 같은 항목에 로컬 대체 음원을 연결한다. 대체는 곡의 자동 일치나 스트리밍 다운로드가 아니다.
5. `준비`로 다음 대상만 지정한다. 재생 중인 음악은 유지한다.
6. 운영자가 `재생`을 눌렀을 때만 소스 중단 확인과 재생 절차를 수행한다.

초기 빈 상태에는 `음악을 준비해두면 진행 중에 바로 재생할 수 있습니다`와 두 추가 버튼을 둔다. 파일 선택 취소는 변경 없이 돌아온다. 링크 오류·구간 오류는 입력 아래에 표시하고 초안을 유지한다. 준비 검사 실패도 현재 음악을 중단하지 않는다.

## 화면 구성

음악 패널은 기존 오디오 바를 확장한다. 상단 고정 영역은 실제 재생 상태, 하단 펼침 영역은 예배 음악 목록·다음 준비·설정이다. 메인/Stage에는 음악 이름·개인 링크·계정 정보를 보내지 않는다.

```text
음악   [로컬 · 재생 중] 기도 반주  00:42 / 03:20
[일시정지] [처음부터] [3초간 줄여 멈춤] [즉시 중지]  음량 40%
다음 준비: 예배 후 음악 · 유튜브 뮤직   [전환해 재생]
[목록 펼치기] [브라우저 열기] [대체 음원으로 전환]
```

이 그림은 로컬 재생 예시다. 유튜브 뮤직에서는 검증된 capability에 해당하는 조작만 표시하며 페이드·탐색·반복을 기본 약속하지 않는다. 연결되지 않았으면 `브라우저에서 준비`와 `연결 확인`을 제공하고 `재생`을 비활성화한다. 연결 자체가 없으면 `외부 재생 상태 확인 필요`로 표시한다.

| 버튼 | 의미 |
| --- | --- |
| 준비 | 다음 대상으로 선택·파일 검사. 소리는 유지 |
| 재생 / 이어 재생 | 새 항목은 지정 구간 시작, 일시정지는 해당 위치에서 재개 |
| 일시정지 | 현재 위치 유지. 이름과 준비 항목 유지 |
| 처음부터 | 로컬은 지정 구간 시작으로 이동. 재생 중이면 계속, 일시정지 중이면 멈춘 채 이동 |
| 줄여 멈춤 | 로컬만 기본 3초 동안 볼륨을 줄여 일시정지. 설정 음량은 유지 |
| 즉시 중지 | 즉시 멈춤. 로컬 위치는 구간 시작으로 초기화, 준비는 유지 |
| 음악 전체 중지 | 관리 중인 모든 음악과 송출 웹 소리를 중단 시도. 외부 실패를 별도 표시 |

외부 서비스의 기본 조작명은 `일시정지`로 표시한다. `음악 전체 중지`의 상세 결과에는 `유튜브 뮤직 일시정지됨 · 재개 위치 유지`를 표시한다. 처음부터 재생을 지원하지 않으면 해당 버튼을 숨긴다. 재생/정지 요청을 보냈다는 이유만으로 성공 표시하지 않는다.

## 예배별 목록과 작업 보존

음악 목록은 예배별 사본이다. 예배 전·기도·헌금·예배 후 등의 이름을 자유롭게 지정한다. 목록 재정렬·제목/음량 편집·다른 예배 선택이 현재 음악에 영향을 주지 않는다. 활성 재생은 실행 당시 사본을 사용하고 편집본은 `다음 재생부터 적용`을 표시한다. 재생 중 항목 삭제는 논리 삭제로 처리하고 현재 재생과 중지 도구를 유지한다. Undo는 목록/설정만 복원하며 소리를 재개하지 않는다.

새 예배로 바꾸면 준비 선택을 비우되 기존 재생 카드에 `다른 예배의 음악 재생 중`을 표시한다. 교체/백업 복원은 기존 전체 복원 절차에 음악 중단 확인을 포함한다.

## 접근성과 좁은 화면

- 1024×768 창에서는 두 줄 조작부와 접히는 목록을 사용한다. 1280×800·1440×900에서도 예배 진행 버튼이 가려지지 않아야 한다. 모바일 화면은 이번 범위가 아니다.
- 긴 한글 제목은 말줄임과 전체 이름 접근성을 제공한다. 상태를 색만으로 구분하지 않는다.
- Tab 순서: 재생 → 처음부터 → 페이드 → 중지 → 음량 → 목록. 비활성 이유를 텍스트로 연결한다.
- Space는 포커스된 버튼만 조작한다. 전역 Space 음악 토글은 추가하지 않는다. F2는 기존 전체 중단을 유지한다.
- 모달을 닫으면 호출 버튼으로 포커스를 돌린다. 연결 끊김은 지속 상태로 알리되 반복 토스트는 만들지 않는다.
- `오디오 플레이어 표시`가 꺼져도 재생 중·외부 상태 미확인 시 상단 소리 상태와 음악 전체 중지는 유지한다. 패널을 숨겨도 로컬 오디오 엔진을 언마운트하지 않는다.

## v1.1 UI 보완 기준

화면 대안과 추천 배치는 [UI·UX 대안과 추천안](04-UI-UX-대안과-추천안.md)을 따른다. 기존 도식은 로컬 확장 상태의 기능 예시이며 모든 버튼을 고정 바에 동시에 노출하는 최종안이 아니다. 기본 바에는 현재 상태·재생/일시정지·음악 중지·목록 열기만 두고, 다음 준비는 공간이 허용될 때 두 번째 줄에 표시한다. 구간/반복/연결 설치는 준비 화면으로 이동한다.

준비 상태를 `파일 확인됨`, `브라우저 준비 필요`, `연결됨 · 대상 확인됨`으로 구분한다. 링크 저장만으로 `재생 준비 완료`를 표시하지 않는다. 현재 음량은 실시간 적용, 항목 기본 음량은 다음 재생에 적용하며 라벨을 구분한다. 외부 볼륨 미지원이면 로컬 슬라이더 자리에 `음량은 브라우저에서 조절`을 표시한다.

외부 재생목록은 등록 라벨과 실제 곡 제목을 두 줄로 구분한다. 외부 현재 위치를 읽지 못하면 가짜 00:00/진행 막대를 그리지 않는다. 다음 준비만 있을 때는 활성 카드와 구분해 `준비됨 · 아직 재생하지 않음`을 표시한다. 일반 목록 클릭은 선택/준비만 수행하며 더블클릭으로 재생하지 않는다.
