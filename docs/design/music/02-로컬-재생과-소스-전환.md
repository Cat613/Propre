# MUS-02 로컬 재생과 소스 전환

작성: 2026-10-17 · 상태: 설계 제안 / 미구현

## 로컬 재생

현재 Control 루트의 단일 HTMLAudioElement를 유지한다. 새 창·Main·Stage에 재생 요소를 만들지 않는다. 등록 파일은 기존 관리 에셋으로 가져오고 읽기·디코딩 가능성과 길이를 검사한다. 확장자만 보고 준비 완료로 판정하지 않는다.

설정 기본값: 구간 시작 0초, 끝은 곡 끝, 반복 꺼짐, 신규 항목 음량 50%, 페이드 3초. 기존 등록 음원의 음량은 유지한다. 시작/끝은 0.1초 단위, 0 ≤ 시작 < 끝 ≤ 실제 길이, 페이드는 0~10초다. 길이 미확정이면 구간을 확정하지 않고 재검사를 제공한다. 정확도 목표는 로컬 일반 조작의 반응 300ms 이내, 구간 끝/페이드 종료 오차 250ms 이내이며 프레임 단위 정밀도는 보장하지 않는다. 부하·절전·장치 변경 조건에서 별도로 측정한다.

재생 전에 지정 시작으로 seek하고 완료 후 재생한다. 구간 끝은 ended만 기다리지 않고 재생 시계로 판정한다. 반복은 지정 구간 내에서만 수행한다. 시간값/볼륨은 범위 검증하고 0초도 유효값으로 취급한다. 페이드는 현재 설정 음량에 gain을 곱해 적용하고 종료 후 일시정지한다. 재개는 설정 음량으로 복귀한다. 페이드 중 중지·소스 전환·F2가 오면 이전 타이머와 요청을 폐기한다. 음량 0은 재생 중·무음으로 표시한다.

## 전환 조정자

Main의 MusicCoordinator가 모든 관리 소스의 전환 권한과 generation을 소유한다. Control 로컬 엔진은 실제 적용 결과를 보고한다. 기존 mediaSlice의 playAudio, 웹 소리 켜기, 순서 진입 audio:stop, clearLayer(audio), clearAll, F2가 같은 조정자를 통과하도록 바꾼다. 기존 경로를 남겨 우회 재생시키지 않는다.

전환은 다음 순서로 직렬 실행한다.

1. 대상 등록 revision·파일·연결·capability를 사전 검사한다. 실패하면 기존 재생 유지.
2. 재생 전환용 playbackGeneration을 발급하고 이전 활성 페이드/재생 요청을 무효화한다. 준비 요청은 별도 수명이며 평소 준비만으로 재생 세대를 바꾸지 않는다.
3. 현재 로컬 재생 pause 적용, 송출 웹 muted 적용, 연결된 외부 탭 pause 상태를 확인한다. 외부 미연결 상태도 미확인 재생 가능성이 있으면 처리한다.
4. 기존 소리 중단을 확인한 후 대상 start를 실행한다. 명령 ACK 외 실제 재생 상태를 확인해 표시한다.
5. 기존 소리 중단 후 대상 시작이 실패하면 조용한 실패 상태로 유지한다. 이전 음악 자동 재개나 대체 음원 자동 시작은 하지 않는다.

준비/전환 검사 취소는 원래 재생 유지가 기본이지만, 이미 중단을 적용했다면 자동 복구하지 않는다. `현재 음악이 멈췄습니다 · 다시 재생`을 제공한다. 목표는 관리 소스 하나이며 임의 다른 브라우저/앱에서 나는 소리까지 시스템 전체 독점으로 차단하지 못한다.

## 외부 상태를 모를 때

연결이 끊겨도 외부 브라우저 음악은 계속 나올 수 있다. 따라서 `대체 음원으로 전환`은 먼저 외부 정지를 시도한다. 확인되지 않으면 로컬 재생을 보류하고 `브라우저에서 정지`를 제공한다. 운영자가 직접 정지 후 `외부 음악을 멈췄습니다`를 누른 경우에만 해당 전환을 재개한다. 이 확인은 그 시점의 수동 확인이며 자동 측정으로 기록하지 않고 이후 전환의 영구 허용으로 재사용하지 않는다.

외부 수동 재생이나 송출 웹의 예기치 않은 오디오가 감지되면 현행 소스 외의 관리 소스를 중단 시도한다. 실패하면 `소리 중복 가능 · 확인 필요`를 유지한다. 연결 탭의 수동 재생을 막을 수 있다는 보장은 하지 않는다.

## 중단·종료·복구

F2는 화면 전체 중단과 함께 로컬 즉시 정지·웹 음소거·연결 탭 pause를 병렬 요청하고 generation을 올린다. 로컬 중단이 외부 응답을 기다리지 않아야 한다. 2초 이내 결과가 없으면 외부 중단 미확인 상태와 브라우저 열기를 표시한다. F2는 토글이 아니며 반복해도 재개되지 않는다.

음악 전용 전체 중지는 화면을 유지하고 같은 오디오 중단을 실행한다. 검은 화면 전환은 음악을 자동 중단하지 않는다. 현재 AudioPlayer는 Look audio 비표시 시 pause하지만 playing 의도를 남겨 다시 표시하면 재개할 수 있다. 새 설계는 이 동작을 명시적으로 변경한다. Look audio 비표시 시 모든 관리 소리를 pause하고 자동 재개 의도를 지운다. 다시 표시할 때는 `이어 재생`을 눌러야 한다. 신규 안내와 MUS-T25 회귀 검사를 함께 적용한다.

정상 종료는 저장 flush와 음악 정지를 요청한다. 외부 정지 미확인 시 한 번만 `브라우저 확인` 또는 `외부 음악이 계속될 수 있음을 확인하고 종료`를 제공한다. 취소하면 창을 유지한다. 강제 종료·충돌에서는 외부 중단을 보장하지 않는다. 업데이트/수동 앱 교체 안내는 외부 정지 미확인 상태도 반영하며 재시작 후 자동 재생하지 않는다.

파일 누락·깨짐은 해당 항목 재연결로 복구한다. 재연결은 새 에셋 검증·참조 교체를 원자 저장하며 재생 중 사본은 보존한다. 자동 음량 정규화, 장치별 라우팅, crossfade는 후속 범위다.

## v1.1 보완: 일시정지·소리 끄기·소스 인수

유튜브 뮤직이 활성 상태일 때 정상 제어명은 `일시정지`다. 로컬의 위치 초기화를 포함한 `중지`와 동일한 기능으로 표시하지 않는다. 음악 전체 중지는 소리 중단 의도이며 상세 결과에 외부 위치 유지 여부를 표시한다. 준비 없음 상태에서 play는 거절한다. 재생 중 같은 activePlaybackId에 play는 no-op이며 등록 항목 revision이 바뀌어도 중지/일시정지는 가능하다.

외부 음악이 수동 재생되는 것을 관측했어도 자동으로 현 활성 음악을 교체하거나 외부 음악을 임의 인수하지 않는다. 연결된 비활성 관리 탭이면 pause 시도 후 중복 가능 상태를 표시한다. 운영자가 `현재 브라우저 음악을 사용`을 명시한 경우에만 기존 소스 중단 확인 후 인수한다.

화면 소스가 바뀌어도 음악 소유권은 유지한다. 웹 송출의 소리 켜기는 조정자의 소스 전환이며 로컬/유튜브 뮤직 중단 확인이 필요하다. 검은 화면, 메인 창 닫기, 슬라이드 복귀는 음악 중단 명령이 아니고 F2/전체 중단과 구분한다.

성능 수치는 합격 증거가 없는 목표다. 재생 요소 재사용 시 seek/pause/play의 물리 적용 경합까지 검증한다. 구간/페이드 오차는 엔진 시계와 녹음/측정 근거를 구분하며, 목표 미달이면 정밀도 표현과 구현 방식을 재검토한다.
