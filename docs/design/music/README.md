# 로컬 음원·유튜브 뮤직 병행 설계

작성: 2026-10-17 Asia/Seoul · 상태: 상세 설계 v1.2 / 로컬 구현·검증 완료 / 실제 서비스·음향 미검증

사용자가 선택한 5번, **로컬 음원과 유튜브 뮤직 병행**을 구현하기 위한 설계다. 예배 전·후에는 기존 유튜브 뮤직 재생목록을 사용하고, 정확한 시작·종료와 오프라인 대비가 필요한 순서에는 로컬 음원을 준비한다. 두 소스를 한 음악 패널에서 구분하며, 준비한 다음 음악이 현재 재생을 바꾸지 않도록 한다.

사용자가 승인한 것은 병행 방향과 설계 진행이다. 브라우저 확장 프로그램 방식·수치·세부 동작은 아래의 설계 제안이며 실제 제어 검증을 통과해야 확정한다. 이번 작업은 문서 작성이며 앱 개발·배포 완료를 뜻하지 않는다.

현재 배치·구현 기준은 [미디어 통합과 중앙 송출 미리보기](05-미디어-통합과-송출-미리보기-구현-설계.md)다. 앞선 별도 고정 음악 바 추천을 대체한다.

## 제공 범위와 완료 기준

목표 제공 범위는 로컬 음원 준비·반복·구간·페이드, 유튜브 뮤직 링크 준비·검증된 직접 재생/일시정지, 실제 상태 표시, 대체 음원 수동 전환, 예배별 저장·복제·내보내기다. 로컬 파일은 사용 권한이 확보된 파일을 사용하며 유튜브 음원을 추출·다운로드해서 만들지 않는다.

직접 제어가 성립하지 않으면 로컬 기능과 외부 링크 열기를 제공할 수 있지만, 이는 **축소 제공**이며 사용자 원래 목표인 ProPre 내 유튜브 뮤직 재생·일시정지 완료로 처리하지 않는다. MUS-P0에서 미해결 이유와 가능한 대안을 기록하고 범위를 재검토한다. OS 공용 미디어 키는 대상 앱을 보장하지 못하므로 기본 제어 경로로 사용하지 않는다.

내장 Google 로그인, 숨긴 YouTube 공식 플레이어의 오디오 전용 재생, 비공식 스트림 추출, 자동 광고 건너뛰기, 클라우드 계정 동기화, 휴대폰 원격 제어, 전용 음향 출력 장치 선택·헤드폰 큐 모니터링은 이번 범위 밖이다. 음악은 현재 macOS 기본 오디오 장치로 나간다. 준비에는 소리가 없으며 시험 재생은 실제 출력으로 들린다는 점을 표시한다.

현행 코드 조사, 문서 링크·추적 검사는 설계 근거다. 실제 브라우저 로그인·자동재생·서비스 정책 적합성, 물리 믹서/스피커, 장시간 리허설은 별도 수용이다.

## v1.1 검토 반영 (2026-10-17)

준비/재생 세대, 활성 사본 중단, 명령 만료·정지 장벽, 탭 교체/해제, Look 재개 정책 변경, 실시간 음량, 비출력 준비/에셋 pin, 실제 외부 대상 검증, host 설치·worker 복구를 보완했다. 상세 내용은 검토 기록이 기준이다. UI는 고정 바+펼침 준비 목록+순서 배지를 추천하며 대안은 제안 상태다. 수용 계획은 MUS-T01~30이다. 앱 구현·실제 서비스·음향 검증 상태는 미완료로 유지한다.

## v1.2 사용자 배치 제안과 구현 (2026-10-17)

음악 관리를 우측 미디어로 통합하고 중앙 상단에 실제 송출 미리보기를 배치한다. 기능/UI·UX 재검토 후 로컬 음악·관리·저장·구간·페이드, 브라우저 연결 소스를 구현하며 [현재 설계](05-미디어-통합과-송출-미리보기-구현-설계.md)와 실행 기록을 기준으로 한다. 외부 실제 서비스·설치·음향 수용은 별도이며 이전의 미구현/제안 표현은 당시 상태다.

[현재 구현·검증 기록](../../quality/2026-10-17-미디어-음악-통합-구현과-검증.md): 단위/계약305개·Electron117개와 관련 UI/패키지 helper 검사를 완료했다. 실제 Chrome 서비스·실음향은 별도 수용이다.

- [음악 워크스페이스 UI/UX 개편](07-음악-워크스페이스-UI-개편.md): 현재 음악 플레이어, 간결한 목록, 추가·관리 메뉴와 반응형 검증.
