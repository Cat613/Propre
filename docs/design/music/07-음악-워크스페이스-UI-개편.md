# 음악 워크스페이스 UI/UX 개편

## 문제

음악 패널이 현재 음악·연결 안내·음량 안내·추가·목록을 같은 밀도로 나열하여 운영 중 필요한 행동을 찾기 어려웠다. 긴 YouTube 곡 제목이 패널 높이를 차지하고, 큰 항목 카드 안의 반복 버튼은 목록 탐색을 방해했다. 선택된 항목과 실제 소리가 나는 항목도 시각적으로 구분이 약했다.

## 정보 구조와 시각 계층

- 미디어 헤더: 송출 자료 제목과 파일 수, 휴지통 아이콘, 가져오기. 다섯 미디어 필터는 균등 폭의 한 행으로 정리한다.
- 음악 헤더: 음악 제목과 연결 상태. 상태 버튼이 연결 설정을 열며 설정 안내를 평상시 펼치지 않는다.
- 현재 음악: 상태 배지 → 곡 정보 → 주요 재생 제어 → 소스별 보조 기능. 목록과 구분되는 하나의 플레이어 영역으로 묶는다.
- 음악 목록: 현재 예배 이름·항목 수와 추가 버튼, 간결한 행 목록. 한 행에 소스 아이콘, 제목·종류·현재 상태, 재생/일시정지, 더 보기만 둔다.
- 추가 메뉴: 음악 파일과 YouTube Music 링크를 한곳에서 제공한다. 기존 파일 설정·링크 설정·대체 음원 입력은 기존 검증과 저장 계약을 유지한다.

## 플레이어 상태

대기 상태는 음악 선택 안내를 보여준다. 재생 중·일시정지·중지·준비 중·연결 확인 필요·재생 오류는 텍스트 배지로 구분한다. 색이나 선택 테두리만으로 상태를 전달하지 않는다. 현재 음악은 실제 소스 소유권과 플레이어 관측으로 판단하며, 다음 음악 선택만으로 현재 곡 제목이나 재생 표시를 바꾸지 않는다.

YouTube Music은 실제 관측 곡 제목을 주 정보로, 등록한 재생목록 이름을 보조 정보로 보여준다. 긴 제목은 두 줄로 제한하고 title 및 펼칠 수 있는 재생 정보에서 전체 제목을 확인한다. 음량 안내는 재생 정보 안에 둔다. 브라우저 음량을 제어할 수 없는 상태에서 가짜 음량 슬라이더를 제공하지 않는다.

로컬 음악은 실제 진행 시간·읽기 전용 진행률·음량 조절을 제공한다. 처음부터와 줄여 멈춤은 재생 설정에 모은다. 준비 중에는 취소 또는 중지를 계속 제공하고, 연결 미확인 시 이어 재생을 막으며 기존 브라우저 확인·외부 중단 확인·대체 음원 복구 경로를 유지한다.

## 목록과 작업

목록의 제목 선택은 무음 준비다. 재생 버튼은 기존 한 번에 연결·첫 재생을 사용한다. 현재 소스의 버튼은 일시정지/이어 재생을 사용하여 재생 위치를 보존한다. 선택 항목은 테두리·체크로, 실제 활성 항목은 배경·상태 텍스트로 구분한다. 선택만 된 다음 음악에 재생 중 표시를 하지 않는다.

더 보기에는 설정·재생 없이 연결·위로 이동·삭제를 둔다. 삭제 후 실행 사본 유지와 되돌리기를 보존한다. 메뉴는 기존 행 안에서 열어 문맥을 유지하며, 추가 동작을 선택하면 추가 메뉴는 닫힌다. 음악이 없으면 빈 상태와 추가 방법을 안내한다.

## 반응형·접근성·테마

패널 너비에 맞는 그리드와 텍스트 최소 폭을 사용하고 280px 이하에서 간격을 줄인다. 목록은 행당 84px 이내로 유지하며 음악 영역 자체가 세로 스크롤된다. 메뉴는 오른쪽 정렬로 패널 밖으로 벗어나지 않게 한다. 모든 아이콘 조작에 접근성 이름·툴팁을 제공하고 키보드 포커스를 표시한다. 기본 details/summary로 메뉴와 보조 정보를 키보드로 열 수 있다. 애니메이션 축소 설정을 존중한다.

기존 workbench 테마 토큰으로 밝고 어두운 테마 모두 구성한다. 제목·보조 설명·상태·주요 조작의 대비를 유지한다. 재생 중 상태는 색상과 텍스트를 함께 사용한다.

## 검증 범위

기존 음악 재생·일시정지·탭 이동·F2·페이드·범위 반복·삭제/되돌리기를 유지하는 Electron 테스트를 수행한다. 현재 음악과 다음 선택의 분리, 추가 메뉴, 긴 한국어 제목, 1280/1920 창 크기와 밝은/어두운 테마를 추가 검사하고 스크린샷을 검토한다. UI 변경은 음악 데이터·저장 스키마·확장 권한·브리지 프로토콜을 변경하지 않는다.
