# WSP-06 예배 템플릿

2026-10-16 · 설계 v1 · 로컬 구현·수용 반영 · [공통 계약](예배-운영-기능-공통-계약.md) · 수용: WSP-T06

## 목적·템플릿과 복제의 차이

주일예배·청년예배·기도회에서 반복되는 순서와 화면 정책을 재사용한다. 복제는 이전 예배 내용을 그대로 복사하는 기존 기능이고, 템플릿은 매번 바꿀 슬롯과 고정 자료를 구분한다. 템플릿은 실제 예배·실행 기록과 다른 저장 객체이며 수정해도 이미 만든 예배가 바뀌지 않는다.

## 진입과 화면

기존 새 콘티 생성 화면에 `빈 예배 / 템플릿 / 현재 콘티 복사` 세 선택지를 명확히 둔다. 템플릿 선택 화면에는 이름·설명·순서 개수·예상 시간을 표시한다. 과도한 카드 대신 검색 가능한 간단한 목록을 쓰고 최근 사용을 먼저 보여준다. 첫 실행에는 앱이 자동 예배를 만들지 않으며 합성 기본 템플릿 2개를 '예시'로 제공할 수 있다.

현재 예배 더 보기의 `템플릿으로 저장`은 이름과 항목별 포함 선택을 받는다. 기본은 제목·종류·시간·화면 정책만 포함하고 실제 담당자·운영 메모·무대 메모·날짜는 제외한다. 각 항목을 `매번 채우기` 또는 `고정 자료 포함`으로 선택한다. 포함될 개인정보와 자료 개수를 저장 전 요약한다.

## 생성 흐름

1. 템플릿 선택 → 새 예배 이름·날짜·시작 시간 입력. 날짜는 필수 여부를 기존 콘티 정책에 맞추고, 시작 시간은 선택이다.
2. 채워야 할 슬롯 목록에서 곡·말씀·설교 자료를 연결한다. `나중에 채우기`로 미완성 초안을 만들 수 있다.
3. 생성 요약에 완성/미완성 순서와 고정 자료를 표시한다. 원자 생성 성공 후 새 콘티를 열되 현재 편집/라이브는 유지한다.
4. 미완성 슬롯은 해당 행에 `자료 선택 필요`로 남긴다. bound 정책인데 자료가 없으면 진행을 막고 자료 연결 또는 keep 변경을 제공한다.
5. 완성 후 사전 점검을 안내한다. 예배 날짜가 같고 이름이 같아도 덮어쓰지 않고 새 ID로 생성한다.

생성 버튼을 두 번 눌러도 requestId로 한 예배만 만든다. 실패하면 빈 예배·절반 사본을 남기지 않는다. 취소하면 입력 화면에서 원래 예배로 돌아가며 라이브는 유지한다.

## 데이터·독립성

`ServiceTemplate { id, revision, name, description?, createdAt, updatedAt, deletedAt?, timezone, items[] }`를 workspace에 저장한다. 각 항목은 CueItem의 계획 필드와 `materialMode: slot | fixed`, 선택적 슬롯 이름·필수 여부를 가진다. 날짜·실제 진행·preflight 결과·활성 안내·타이머 runtime은 저장하지 않는다.

fixed 자료는 template 소유 presentation/resource 사본에 연결하고 assets만 공유한다. 템플릿 저장 당시 내용을 보존한다. 예배 생성 시 다시 독립 사본으로 복사하며 모든 item/presentation/resource ID를 재매핑한다. 템플릿 갱신은 expectedRevision 비교 후 적용하고 기존 예배에 전파하지 않는다. 슬롯은 미연결 상태를 명시적으로 허용하되 실제 실행에서는 WSP-01의 유효성 검사를 따른다.

템플릿의 기본 화면 정책은 생성된 예배에 복사한다. stageNote를 포함하더라도 자동 전송하지 않는다. 자료 source가 사라져도 고정 사본은 유지한다. asset이 누락되면 생성은 미완성 초안으로 허용하되 경고하고 사전 점검에서 차단한다. 이름 최대 100자, 설명 500자, 항목 최대 1,000개, 템플릿 총 200개와 공통 상태 크기 상한을 적용한다.

## 수정·삭제·백업

템플릿 관리에서 이름 변경·복제·내용 편집·휴지통/복원을 제공한다. 편집은 실제 예배 진행 화면과 구별해 `템플릿 편집 중`을 표시하며 송출 버튼을 두지 않는다. 삭제는 soft delete로 자료·assets를 보존한다. 전체 백업에 휴지통까지 포함한다. 동일 파일 재가져오기는 새 템플릿을 만들며 이름 충돌은 '복사본' 표시로 구분한다.

템플릿 단독 이동은 신규 portable schema의 `kind: service-template`으로 제공한다. 예배 service 파일과 구분하며 미지원 형식은 명확히 거절한다. 공유용 PDF와 달리 수정 가능한 구조·포함 메모·자료가 전달됨을 내보내기 전에 보여준다. 외부 전송 기능은 추가하지 않는다.

## UI 예외·수용

슬롯이 없으면 입력 단계를 건너뛰고 생성 요약으로 간다. 템플릿이 없으면 `현재 예배를 템플릿으로 저장`과 예시 보기를 제공한다. 검색 결과 없음은 전체 목록 복귀를 제공한다. 1024×768에서 슬롯 입력은 순차 세로 목록, 요약·생성 버튼은 고정한다. 키보드로 슬롯 선택·자료 연결·취소가 가능하고 실패 시 입력을 보존한다.

템플릿 수정→기존 예배 불변, 새 예배 수정→템플릿 불변, 원곡 삭제→고정 사본 유지, 모든 내부 참조 재매핑, 반복 항목·서로 다른 예배 사본 분리, 중복 클릭·용량 초과의 원자 거절을 검사한다. 첫 기능 묶음에서는 생성·저장만 먼저 구현하고 관리·휴대 파일은 후속 단계로 나누되 최종 수용에서 누락하지 않는다.

## 2026-10-16 구현 확정

이번 미배포 workspace4/portable3 예배 묶음에서 템플릿 계약을 완성했다. 단독 service-template 파일과 전체 백업, 관리·휴지통·복원·고정 자료 교체까지 포함한다. 필수 슬롯은 materialPending과 빈 찬양 사본으로 표현하며 prepare/preflight가 차단한다. 비곡은 자료 없이 진행할 것을 명시할 수 있다. 새 콘티→템플릿 전환 시 제목/날짜를 보존한다. [최종 계약·검증](../../quality/2026-10-16-예배-템플릿-검증.md).
