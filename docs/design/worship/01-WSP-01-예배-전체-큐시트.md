# WSP-01 예배 전체 큐시트

2026-10-16 · 설계 v1 · 로컬 구현·수용 반영 · [공통 계약](예배-운영-기능-공통-계약.md) · 수용: WSP-T01

## 목적과 범위

기존 곡 중심 콘티를 예배 전체 순서로 확장한다. 준비 담당자는 기도·봉독·설교·광고도 같은 흐름에 넣고, 운영자는 현재 진행과 다음 순서를 확인한다. 순서별 자동 화면 전환이나 시간에 따른 자동 진행은 초기 범위에서 제외한다.

한 예배는 기존 콘티 하나이며 이름·날짜·보관함·복제·휴지통을 재사용한다. 별도의 '예배 목록' 화면을 만들지 않는다. 현재 콘티 영역에 `곡 / 전체 순서` 전환을 두고 선택을 기억한다. 기존 사용자의 첫 진입은 곡 보기로 유지하고 새 예배는 전체 순서로 시작한다.

## 화면과 주요 흐름

전체 순서 상단은 예배 제목, 날짜, `순서 추가`, 더 보기만 표시한다. 합계 시간은 시간이 입력된 경우에만 보인다. 행은 순서 번호·종류·제목과 선택적 담당자/시간으로 한 줄을 우선한다. 현재 진행 행에는 `진행 중`, 선택 행에는 테두리를 표시해 색상만으로 구분하지 않는다. 메모와 화면 정책은 행 펼침 또는 오른쪽 상세 영역에서 편집한다.

```text
주일 오전예배                         순서 추가  ⋯
곡 | 전체 순서                       예상 62분

 1  찬양      찬양 A                  5분
▶2  대표기도  대표기도       김○○      3분   진행 중
 3  봉독      요한복음 15:1–5           2분

선택: 대표기도
화면  배경만 유지 · 소리 유지
메모  기도 후 봉독자 등단
                                  준비 확인  이 순서 진행
```

1. 빈 예배에서는 `첫 순서 추가`와 `템플릿으로 만들기`를 제공한다. 종류 선택 후 제목만으로 생성할 수 있다. 담당자·시간·메모는 선택이다.
2. `찬양 추가`는 기존 원곡 선택을 재사용하고 독립 사본을 만든다. 여러 곡은 사용자가 선택한 순서로 추가한다.
3. 비곡 순서는 자료 없이도 만들 수 있다. `자료 연결`에서 성경 자료/일반 발표/웹/PDF를 선택하면 예배 소유 사본을 만든다. 연결 자료·첫 슬라이드/PDF 페이지를 미리 확인한다.
4. 행 클릭·Enter는 준비 대상만 바꾼다. 선택한 자료와 현재 라이브가 다르면 기존 송출 미리보기 옆에 준비 대상을 구분한다.
5. `준비 확인`으로 연결 유효성·페이지·세대·정책을 점검한다. `이 순서 진행`이 유효한 준비 토큰으로 실행한다. keep/black/background-only도 계획 revision을 검사한다.
6. 실행 성공 후 이전 진행은 완료, 선택 cue는 진행 중이다. 실패하면 이전 진행·화면을 유지하고 실패 이유·재준비 버튼을 보여준다. 한 예배에서 진행 중은 최대 하나다.
7. `다음 순서 준비`는 다음 대기 cue를 선택만 한다. 다음 진행은 다시 명시 실행한다. 마지막에는 `예배 마치기`로 실행 요약을 저장한다. 화면·소리 종료는 별도 선택으로 명확히 표시한다.

## 순서 정책

| 종류 | 기본 화면 | 기본 오디오 | 자료 없는 진행 |
| --- | --- | --- | --- |
| 찬양 | 연결 곡 첫 슬라이드 | 유지 | 불가, 가사 없는 곡은 명시한 빈 슬라이드 사용 |
| 기도·헌금·custom | 현재 화면 유지 | 유지 | 가능 |
| 봉독·설교·광고 | 현재 화면 유지, 자료 연결 시 사용자가 bound 선택 | 유지 | 가능 |

자료를 연결했다고 기본 정책을 조용히 bound로 바꾸지 않는다. 연결 직후 `이 자료로 화면 전환`을 제안하고 결과를 표시한다. 배경만 유지는 현행 배경 레이어를 유지하며 본문·광고·청중 자막·prop을 지운다. 웹/PDF 위에서 실행할 때는 기존 슬라이드 배경의 미리보기를 보여주고 웹을 음소거한 후 전환한다. black은 검정 화면으로 시각 레이어를 가리되 소리 정책은 별도다. 다시 가사를 띄우면 black 가림을 해제한다.

기본 오디오 유지는 새 오디오를 재생하지 않는다는 뜻이다. stop은 로컬·웹 오디오를 모두 멈춘다. 새 영상 자동 재생·오디오 큐는 후속 범위다. 기존 수동 슬라이드 송출은 큐 진행 상태를 자동 변경하지 않고 `수동 송출 중`을 표시한다. cue 진행과 현재 시각 source는 각각 표시한다.

## 편집·저장·정렬

servicePlan.items와 곡 투영의 불변식은 공통 계약을 따른다. 순서 입력 창은 제목·시간·메모·화면 정책을 함께 명시 저장하며 입력 초안을 로컬 복구 기록에 보존한다. 기존 곡 편집 자동 저장과 충돌하지 않도록 flush 후 revision을 검사하고, 구조 변경은 추가/이동/제거 단위 Undo로 제공한다. 큐시트 Undo는 편집 히스토리이며 실제 진행·소리 정지를 되돌리지 않는다. 곡 편집 Undo와 별도 맥락을 화면에서 표시한다.

드래그 손잡이 외에 행 더 보기의 `위로/아래로`와 키보드 정렬을 제공한다. 제목 편집 중 방향키는 입력에 맡긴다. 기존 전역 Space 송출과 충돌하지 않도록 큐시트 영역은 Enter 선택, 명시 버튼 진행을 사용한다. 활성 진행 cue 제거는 종료/전환 전까지 막고, 다른 cue 삭제는 되돌리기를 제공한다. 현재 순서를 건너뛰면 완료와 구분한 skipped 상태로 기록한다. 과거 항목 재진행은 새 실행 구간을 기록하며 기존 소요 시간을 덮지 않는다.

## 예외·복구·화면 크기

누락 자료는 행에 `자료 확인 필요`로 표시하고 파일 재연결/자료 교체로 이동한다. 해당 순서 진행만 차단하며 keep으로 명시 수정하면 자료 없이 진행할 수 있다. 연결 교체는 원자 저장하고 실패 시 이전 연결을 남긴다. 창 재연결·출력 적용 시간초과는 상태를 '확인 필요'로 표시하며 성공을 추정하지 않는다.

콘티를 바꾸어도 진행 중 예배는 유지하고 상단에 소속 예배를 고정 표시한다. 다른 예배를 시작할 때 현재 예배 종료/일시중단을 선택한다. 삭제·휴지통 이동도 진행 중 예배는 종료 후 허용한다.

1024×768에서는 목록과 상세를 겹쳐 두지 않고 상세를 하단 펼침으로 전환한다. 진행 버튼은 스크롤 밖에서도 접근할 수 있게 고정한다. 더 좁은 창에서는 담당자·시간을 두 번째 줄로 옮긴다. 모바일 원격 조작은 범위 밖이다. 포커스는 추가 후 새 행, 삭제 후 다음 행, 상세 닫기 후 원래 행으로 복귀한다.

## 구현·수용 기준

Repository 이전/저장·곱절 순서 투영 → 편집 UI → 준비·실행 coordinator → 세션 복구 순으로 구현한다. 데이터 이전 실패·슬라이드/웹/PDF 전환·Undo·곡 보기 정렬을 함께 검사한다.

완료 기준은 기존 콘티의 곡/사본/스타일 보존, 선택만으로 무송출, 실행 실패 시 이전 상태 보존, 동일 명령 중복 방지, 키보드 전 과정, 좁은 화면의 조작 접근성이다. 실제 프로젝터·음향 리허설 결과는 자동 검사와 별도 기록한다.

## 2026-10-16 로컬 구현 확정

명시 저장·로컬 초안 복구를 사용하고 구조 Undo와 진행 기록을 분리했다. `예배 전체로 저장/예배 파일 불러오기`가 portable schema3 service 형식을 사용하며 메모 포함을 표시한다. 행 정렬은 버튼과 Alt+방향키로 제공한다. 전용 드래그 손잡이는 현재 추가하지 않았다. 좁은 콘티 패널에서 선택·준비와 오조작을 줄이고 기존 곡 보기의 드래그와 구분하기 위한 조정이다. 키보드/버튼 정렬과 포커스·충돌을 격리 앱에서 검증했다.
