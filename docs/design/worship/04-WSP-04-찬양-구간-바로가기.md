# WSP-04 찬양 구간 바로가기

2026-10-16 · 설계 v1 · 로컬 구현·수용 반영 · [공통 계약](예배-운영-기능-공통-계약.md) · 수용: WSP-T04

## 목적·범위

인도자의 즉흥 반복이나 순서 변경에 대응해 절·후렴·브릿지의 첫 슬라이드로 이동한다. 기존 songForm과 songPosition이 있으면 이를 사용하고, 없으면 명시 라벨을 이용한다. 가사 문자열로 '후렴'을 추정하거나 AI를 호출하지 않는다. 슬라이드 순서를 다시 생성하지 않으므로 기존 편집과 송폼 이력을 보존한다.

## 화면과 조작

현재 곡 슬라이드 목록 위에 `구간` 버튼을 둔다. 열면 가로 칩 또는 줄바꿈 목록에 `1절 · 후렴 · 2절 · 브릿지`를 표시한다. 라벨이 많으면 스크롤보다 펼침 목록을 우선하고 자주 쓰는 6개까지만 첫 줄에 둔다. 현재 라이브 구간과 준비 구간은 '송출 중'/'선택' 표식으로 구분한다.

기본은 칩 선택 → 해당 첫 슬라이드로 목록 스크롤·준비 선택 → `이 구간 송출`이다. 숙련자용 `구간 클릭 즉시 송출`은 명시적으로 켠 뒤에만 작동하고 곡 영역에 `즉시 송출` 표시를 유지한다. 이 옵션은 Control 실행 중 설정으로 두어 앱 재시작 시 기본 준비 모드로 돌아간다. 글로벌 기본값으로 조용히 확산하지 않는다.

반복된 파트는 `후렴 · 1번째`, `후렴 · 2번째`의 발생 위치를 펼쳐 선택한다. 기본 대상은 현재 라이브 뒤의 가장 가까운 같은 파트이며 없으면 첫 발생이다. 준비만 하는 모드에서는 실제 대상 발생 위치를 칩 옆에 보여준다. 라이브가 다른 곡이면 첫 발생을 사용한다. 송출 성공 후 다음 슬라이드는 원래 배열에서 선택한 발생의 다음 슬라이드다. '마지막 후렴'은 마지막 발생을 선택하며 배열을 변경하지 않는다.

## 인덱스·정합성

`SectionOccurrence { key, label, firstSlideId, slideIds, partId?, stepIndex?, repeatIndex? }`를 presentation revision별로 계산한다. songPosition의 partId/stepIndex/repeatIndex로 발생을 묶고 page 순서 및 실제 슬라이드 배열 순서를 대조한다. 각 occurrence의 실제 ID가 유효하고 연속될 때만 송폼 기반 바로가기를 만든다.

수동 수정으로 송폼 위치가 불완전하면 해당 구간에 `구간 정보 확인 필요`를 표시하고 실제 라벨 기반으로 안전하게 재계산한다. 같은 라벨이라도 비연속이면 별도 발생이다. 연속된 같은 라벨은 하나의 구간으로 묶는다. 라벨 없는 슬라이드는 앞 구간에 자동 편입하지 않고 별도 미지정 구간으로 표시한다. 구간 이름 변경은 라벨/송폼의 원래 편집 기능에서 수행하며 파생 인덱스 자체를 저장하지 않는다.

송출 명령은 presentationId, presentationRevision, firstSlideId, expectedOutputGeneration을 포함한다. 버튼을 누른 뒤 슬라이드가 삭제·분할되면 거절하고 인덱스를 새로 만든다. 삭제된 인덱스 번호를 다음 슬라이드로 대체하지 않는다. 현재 라이브가 다른 자료면 버튼에 곡 제목을 포함한다.

## 웹·PDF·콘티와의 연결

웹/PDF 송출 중에는 칩을 골라도 현재 화면을 유지한다. `이 구간 송출`을 실행하면 기존 source coordinator로 슬라이드로 전환하고 웹 소리 정책을 적용한다. 큐시트 진행 중인 곡과 다른 곡을 수동 송출하면 진행 cue를 자동 이동시키지 않고 `수동 송출 중`으로 표시한다. PDF 페이지 바로가기는 기존 PDF UI를 유지한다.

가사 없는 간주도 명시 구간으로 선택 가능하다. 성경·일반 발표에는 라벨 기반 `구간`을 선택 기능으로 쓸 수 있지만 '찬양 파트'라고 표시하지 않는다. 송폼과 라벨이 모두 없으면 `슬라이드에 구간 이름을 지정하면 바로갈 수 있습니다`와 편집 이동을 제공한다.

## 키보드·오류·수용

칩은 Tab으로 진입하고 방향키로 탐색, Enter로 준비 선택한다. 즉시 송출 모드일 때도 입력·IME·모달 안 키는 가로채지 않는다. 숫자키·전역 단축키는 초기 범위에 추가하지 않는다. 좁은 화면의 펼침 목록은 제목·발생 순서·슬라이드 수를 읽을 수 있게 하고 닫을 때 원래 칩으로 복귀한다.

파트 반복·여러 페이지·중간 구절 삽입·수동 정렬·삭제·라이브 다른 곡·웹 복귀를 단위 및 격리 Electron에서 검증한다. 기본 클릭 무송출, 즉시 모드의 명확한 표시, stale revision 거절, 송출 후 다음 슬라이드 정합성이 완료 조건이다. 실제 운영자에게 갑작스러운 후렴 재진입 과제를 주고 오조작/소요 조작 수를 기록한다.

## 2026-10-16 구현 확정

준비 구간 표식은 편집 다중 선택과 분리한다. 편집 도구가 실행 위치를 가리는 것을 막고 준비와 편집을 구분하기 위한 조정이다. 구간 제어는 카드 스크롤 위에 고정하며 반복 발생은 명시 선택 목록으로 제공한다. [구현 계약·로컬 검증](../../quality/2026-10-16-구간-바로가기-검증.md).
