# WSP-07 인쇄·공유용 큐시트

2026-10-16 · 설계 v1 · 로컬 구현·수용 반영 · [공통 계약](예배-운영-기능-공통-계약.md) · 수용: WSP-T07

## 목적과 출력 범위

방송실·찬양팀·인도자가 같은 예배 순서를 확인할 수 있도록 로컬 PDF와 인쇄용 문서를 만든다. 클라우드 게시·메일·메신저 전송은 제공하지 않는다. 내보내기는 현재 예배의 저장된 고정 revision을 기준으로 하고 현재 라이브·메모 초안을 임의 변경하지 않는다.

| 기본 프리셋 | 포함 | 기본 제외 |
| --- | --- | --- |
| 공용 | 예배 제목·날짜·순서·제목·예상 시간 | 담당자·모든 메모·주소 |
| 찬양팀 | 공용 + 곡 구간 순서 | 운영 메모·무대 메모·웹 주소 |
| 운영자용 | 공용 + 담당자·화면 정책·자료 이름·운영 메모 | 무대 안내 초안·웹 주소 |

프리셋 변경 후 포함 체크를 개별 조절할 수 있다. 담당자·운영 메모·무대 메모를 포함하면 상단에 포함 사실을 표시한다. 일시 StageMessage와 실제 실행 토큰은 어떤 프리셋에서도 내보내지 않는다. 전체 가사·악보·PDF 원문 삽입은 초기 범위가 아니다.

## 화면과 흐름

예배 더 보기의 `큐시트 인쇄·PDF`로 연다. 왼쪽 또는 상단에는 프리셋과 최소 옵션, 나머지는 실제 페이지 미리보기를 둔다. 기본은 A4 세로·보통 글자·메모 제외다. 상세에서 가로, 글자 크기(보통/크게), 열 포함 여부, 계획 시각 표기를 바꾼다.

1. 실행 전 편집 flush를 요청한다. 저장 실패면 재시도/취소를 제공하고 오래된 저장본을 조용히 내보내지 않는다.
2. Repository에서 setlist revision과 필요한 파생 정보를 동결한다. 문서 상단에 예배명·날짜, 하단에 생성 시각·짧은 revision 표기를 넣는다.
3. 옵션 변경 시 미리보기를 새 job으로 생성한다. 이전 job의 늦은 결과는 버린다.
4. `PDF 저장`은 native 경로 선택 후 원자 기록, `인쇄`는 OS 인쇄 대화상자로 연결한다. 취소는 실패로 표시하지 않는다.
5. 계획이 바뀌면 `예배 내용이 바뀌었습니다 · 최신 내용으로 다시 만들기`를 표시한다. 기존 미리보기 저장 시에는 '이전 내용 기준'임을 명확히 알린다.

저장 완료는 실제 파일 기록을 확인한 뒤 표시하고 `파일 위치 보기`를 제공한다. 인쇄 대화상자 전송 완료는 실제 용지 출력 완료로 표현하지 않는다.

## 레이아웃 명세

A4 세로 여백 12mm, 본문 11pt/큰 글자 13pt, 기본 열은 번호·순서·제목·예상 시간이다. 담당자 선택 시 열을 추가한다. 메모는 좁은 열에 압축하지 않고 해당 행 아래 전체 너비의 보조 행으로 표시한다. 머리글은 모든 페이지에 반복하고 페이지 번호를 넣는다. 메모가 긴 행은 다음 페이지로 나누되 제목과 메모 첫 줄은 함께 유지한다. 반복 제목에 '(계속)'을 붙여 연결을 알린다.

한글·영문·숫자·긴 제목·특수문자·빈 시간·1,000행·최대 메모를 지원한다. 넘치는 텍스트를 말줄임으로 숨기지 않고 줄바꿈한다. IANA 시간대와 예배 날짜를 사용하며 자정을 넘는 계획 시각에는 '+1일'을 표시한다. 시작 시간 또는 앞 duration이 미정이면 해당 시각은 '미정'으로 출력한다. 미완성 자료 슬롯은 '자료 미정' 표시를 유지한다.

곡 구간 순서는 songForm에서 계산하며 불완전하면 '구간 확인 필요'라고 표시한다. URL은 원칙적으로 출력하지 않는다. 운영자가 명시 선택한 경우에도 hostname만 허용하고 query·fragment·로그인 정보는 포함하지 않는다. 실제 자료 경로·인증 상태는 출력하지 않는다.

## 렌더·보안·수명

Main 소유 격리된 로컬 인쇄 renderer에 정제된 DocumentDTO만 전달한다. HTML escape/plain text와 고정 CSS로 구성하고 네트워크·임의 링크 탐색·Node 접근을 막는다. 사용자가 입력한 HTML이 실행되지 않아야 한다. font ready를 확인한 뒤 Electron의 PDF/print 경로를 감싸는 export 서비스를 사용한다. 지원 API 조합은 구현 시 설치된 Electron에서 검증한다.

시스템 한글 폰트 의존 여부를 명시하고, 포함 가능한 배포 폰트는 라이선스 확인 후 선택한다. 폰트 미로드는 출력 성공으로 처리하지 않는다. 미리보기 임시 파일은 앱 임시 디렉터리의 job별 위치에 만들고 닫기/실패/다음 시작 때 정리한다. 사용자가 저장한 최종 파일은 정리 대상에서 제외한다. 파일명은 제목·날짜에서 안전한 문자로 만들고 충돌은 OS 저장 대화상자에서 처리한다.

최대 1,000 cue·2,000자 메모의 실제 크기를 검사하고 렌더 시간·메모리 상한을 구현 단계에서 측정한다. 30초 초과 시 작업 취소와 재시도를 제안하되 UI 스레드를 막지 않는다. 완료 전 작업 취소는 출력 대상 파일을 남기지 않거나 검증 가능한 임시 파일만 남겨 정리한다.

## 검증·완료 기준

DTO의 정보 선택·시간 계산·escaping·revision 고정은 단위/계약 검사한다. 격리 Electron에서 프리셋 변경·옵션 유지·취소·저장 실패·동시 편집·이전 job 폐기를 검사한다. 생성 PDF는 텍스트 추출뿐 아니라 페이지 렌더 이미지로 첫/중간/마지막·긴 메모·페이지 경계를 검토한다. 한글 폰트·표 머리글·행 분할·누락 여부를 육안 확인한다.

실제 프린터는 A4 세로/가로 각각 출력해 잘림·여백·한글을 확인한다. 그 전에는 '로컬 PDF 검증 완료 / 실제 인쇄 미확인'으로 보고한다. 기본 공용 PDF에 메모·담당자·URL이 없는 것을 필수 수용 조건으로 둔다.

## 2026-10-16 구현 계약과 조정

Main의 CuesheetExport가 저장 완료 후 Repository의 고정 revision을 allowlist DTO로 만든다. 공용 기본은 담당자·메모·URL/호스트를 제외하며 자료 미정은 유지한다. 상세 선택은 옵션별로 허용하고 개인정보 포함 사실을 문서 상단과 UI에 표시한다. 실행 토큰·StageMessage·타이머 runtime·전체 가사·원문 자료·실제 파일 경로는 투영하지 않는다. 호스트 선택도 hostname만 전달한다.

인쇄 renderer는 preload/Node 없는 sandbox·별도 비영속 session이며, 자신의 단일 preview.html 이외 요청·권한·탐색·새 창을 거절한다. 입력은 HTML escape한다. 시스템 한글 폰트 준비 후 실제 높이로 페이지를 나누고 긴 메모는 보조 행을 나누며 제목/표 머리글/쪽 번호를 반복한다. 제목은 한국어 단어 단위 줄바꿈을 우선한다. macOS Apple SD Gothic Neo의 실제 생성/추출/렌더를 검사했다. 다른 OS의 시스템 폰트/물리 인쇄는 별도 수용이다.

최대 메모 1,000개를 한 번에 Chromium PDF로 만들 때 메모리가 크게 증가했다. pageRanges만으로는 전체 DOM의 인쇄 배치를 줄이지 못해, 최종 페이지 DOM을 50쪽씩만 붙여 출력한 뒤 pdf-lib로 원래 순서 그대로 합친다. 반복 헤더/전체 쪽 번호는 분할 전에 고정한다. 실제 PDF 페이지 수와 배치 페이지 수가 다르면 성공 처리하지 않는다. 30초·최종 PDF200MiB·4,000쪽 제한과 생성 renderer working set2GiB(250ms 표본) 초과 취소를 적용한다. 표본 사이의 순간 peak까지 제한한다고 주장하지 않는다. [부하·시각 검증](../../quality/2026-10-16-큐시트-PDF-인쇄와-최종-회귀.md)에 실측과 메모리 한계를 남긴다.

Control은 같은 최종 PDF 바이트를 PDF.js canvas로 미리 본다. 저장과 인쇄는 렌더 준비 뒤만 활성화하고 옵션 변경/닫기/취소의 늦은 job을 버린다. 계획 변경 시 기존 고정본임을 표시하고 이전 내용 저장/인쇄는 기본 취소인 native 재확인을 요구한다. UUID job은 하나만 유지하며 임시 파일은0700 폴더/0600 파일이다. 닫기·실패·정상 종료·다음 시작에서 정리하고, 임시 저장 경로 오류는 앱 전체 시작을 차단하지 않는다. 사용자가 저장한 PDF는 삭제하지 않는다. 인쇄 성공 표시는 OS 전달이며 실제 용지 완료가 아니다.
