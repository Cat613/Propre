TASK-009/017/018/021 후속 보완: 개발 실행의 CSP 차단·시작 실패 종료를 수정하고 실제 프로젝트 Vite 설정을 사용하는 시작·자동 저장·모니터·종료 회귀 검사를 추가했다. [개발 시작 복구 검증](../quality/verification-2026-10-04-startup-recovery.md) 참조.

## 초기 M0 재현과 수용 기준의 보존

### TASK-001

- 기존 발표 A를 열고 B 파일 또는 성경을 적용한 뒤 저장한다. A의 ID·제목·내용이 그대로 보존되는지 확인한다.
- 저장 실패, 가져오기 취소, 검색 결과 없음, 미저장 발표 전환과 앱 종료를 검사한다. 새 발표 ID는 저장 성공·초안 식별 정책에 따라 일관되게 관리한다.
- 대상: librarySlice·editorSlice·LibraryPanel·BiblePanel·종료 IPC. 기능 기획과 동작 변경안을 기록한 뒤 수용 기준에 맞춰 구현한다.

### TASK-002

- 재현 목록: setActiveSlide, updateSlide, deleteSlide, batchDeleteSlides, reorderSlides, reorderMultiSlides, setSlides, 요소 변경, undo/redo.
- 각 명령이 준비 자료만 바꾸는지 라이브에 적용되는지 명시한다. 적용된 결과는 Output·Stage·미리보기에서 같은 버전으로 확인한다.
- 동일 상태를 보내는 횟수보다 최종 상태 수렴과 다음 슬라이드의 정확성을 우선 검사한다.

### TASK-003

- Background·Slide·Announcement·Props·Message·Audio를 모두 활성화한 합성 상태에서 각 지우기 명령의 결과를 비교한다.
- UI audio와 Store audio의 제어를 합치고 미디어 탭 전환·Output 창 닫기·다시 열기에도 재생 정책이 유지되는지 검사한다.
- 전체 중단의 검사는 실제 스피커/헤드폰·화면 확인까지 포함한다. 메모리에서 null이 된 결과만으로 소리 중단 완료로 표시하지 않는다.

### TASK-004

- 상태 먼저 발행→늦은 Renderer 준비, Output 재생성, Stage 숨김/표시, display 재선택, 빠른 연속 변경을 검사한다.
- 최신 전체 snapshot을 준비 후 전달하고 오래된 version이 새 version을 덮지 않는지 확인한다.

### TASK-009

- Control·Output·Stage·알 수 없는 frame의 동일 요청을 비교한다. 자료 저장·키 조회·임의 채널·다른 화면 변경은 역할에 따라 거절한다.
- 등록 미디어, URL 인코딩 이름, 심볼릭 링크, 루트 밖 경로, 미지원 파일을 검사한다. webSecurity를 켠 상태에서 실제 이미지·영상 로드를 확인한다.
- CSP·탐색·새 창 제한과 허용 AI 요청을 함께 검사하고 키·원문·개인 경로가 로그에 남지 않게 한다.

## 공통 완료 조건

1. 범위와 관련 REQ·REV·TC가 연결되고 제품 정책의 결정 상태가 명확하다.
2. 필요한 데이터 호환·원본 보존·실패 복귀가 구현되어 있다.
3. 해당 검사를 실제 실행했고 실패·미실행 항목과 검사 환경을 기록했다.
4. 구현 현황·계약·운영 안내를 최종 동작에 맞게 갱신했다.
5. 코드 확인·자동 검사·네이티브·실장비·사용자 확인·배포를 서로 다른 증거로 표시했다.

## TASK-032 파일에서 AI 찬양과 플레이리스트 준비

2026-10-07 · 상태: 구현·격리 검증 완료 / 실제 API 품질 평가 대기 · REQ-037 / TC-037 / ADR-014 / FLOW-011

사용자가 요청한 PDF/이미지 → 선택 AI → 송폼 슬라이드 → 플레이리스트 새 구성 또는 추가를 구현한다. 여러 AI를 등록하고 작업마다 선택하는 방향을 반영한다. [상세 설계](../engineering/ai-song-preparation.md)의 순서대로 송폼 모델·컴파일러 → 원자 적용·durable receipt → 내부 MCP 작업 세션 → 파일/제공자 어댑터 → 준비·검토 UI → 격리 앱/실제 API 평가를 진행한다.

완료 조건: Gemini/OpenAI/Claude 어댑터별 파일·도구 계약과 연결/모델 지원 확인, 교체/추가 결과·기존 항목 ID 보존, 곡/순서/영수증 전체 저장, 초안 복구·재시작 중복 방지, 현재 선택/작업본/Undo/송출 유지, 메타데이터 파일 왕복, TC-037 및 관련 회귀 증거다. 실제 모델의 가사·송폼 대조 결과를 모의 응답 검사와 구분한다. [실행 검증](../quality/verification-2026-10-07-ai-song-preparation.md)과 [운영 안내](../operations/ai-song-preparation.md)를 추가했다. 새 곡은 찬양 목록에도 등록하며 기존 곡에 대해서만 원곡 갱신을 별도 선택으로 처리한다. 실제 계정의 한국어 악보 평가와 실제 장비 수용 확인은 미실행이다.

TASK-033은 [콘티 보관함 설계](../engineering/setlist-library.md), [검증](../quality/verification-2026-10-06-setlist-library.md)을 따른다. TASK-032의 AI 파일 준비 설계와 별도 범위이며 사본을 쓰는 데이터 경로는 이후 AI 준비에도 적용해야 한다.
