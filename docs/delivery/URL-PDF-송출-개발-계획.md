단계마다 실행 결과를 기록하고 선행 검증을 통과한 뒤 다음 단계로 진행한다. 기존 dirty 파일은 보존한다. 실장비·실사이트 인증·DRM·서명/배포는 자동 개발 검사와 구분한다. 커밋·푸시·배포는 이 계획에 포함하지 않는다.

개발 단계는 로컬 구현과 자동 검사까지 완료했다. 실제 사이트 인증·DRM, Windows 및 실장비 수용은 [검증 기록](../quality/2026-10-12-URL-PDF-송출-검증-기록.md)의 후속 항목으로 남긴다. Office/한글 직접 변환·화면 공유는 후속 개발 범위다.
