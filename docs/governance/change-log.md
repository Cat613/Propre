# 문서·계획 변경 이력

## 2026-10-12 — AI 찬양 준비 프롬프트 개선

- 고정 분석 규칙과 사용자 요청을 분리하고 Gemini/OpenAI/Claude의 시스템 지시로 연결했다. 각 첨부 앞에 파일 ID·이름을 제공한다.
- 가사 판독·반복기호·기본 두 줄 슬라이드 분할·원문 대조 지시와 송폼 예시를 추가하고 MCP 도구·필드 설명 및 오류 경로를 보강했다.
- 일부 파일 재분석에서 이번 파일 밖의 기존 곡·파트·순서·반복을 변경하거나 삭제하는 초안을 거부한다. 다음 페이지는 기존 부분을 보존한 추가만 허용한다.
- 기존 저장 형식을 유지하며 실제 제공자 호출·한국어 악보 인식 비교는 수행하지 않았다.

## 2026-10-12 — 라이트 모드와 곡 목록 공간 개선

- 설정에 다크·라이트 화면 테마 선택을 추가하고 선택값을 기존 설정 저장 경로로 유지한다. 설정이 없는 기존 자료는 다크로 시작한다.
- 편집 화면의 공통 색상과 기존 중립 색상 유틸리티를 라이트 팔레트에 연결하고, 송출 렌더링은 테마 적용 범위에서 분리한다.
- 콘티·찬양 목록 행을 압축하고 드래그·추가·삭제 버튼이 제목 폭을 상시 차지하지 않도록 정리했다.

## 2026-10-12 — 상단 앱 바 제거

- 사용자 피드백에 따라 ProPre·현재 콘티·저장 시각의 별도 상단 바를 제거했다. 현재 콘티 이름은 좌측에서 확인하며 자동 저장 상태와 실패 시 재시도는 중앙 하단에 배치했다.

## 2026-10-12 — 세 패널 작업 화면 개선

- 콘티/자료 목록, 슬라이드 편집, 송출 미리보기/설정의 배경·테두리·입력·버튼 스타일을 통일하고 패널 너비 조절 비율을 기억한다.
- 편집 도구는 중앙 제목 아래로, 배경·텍스트 지우기와 전체 중지는 우측 미리보기 아래로 이동한다. 검색·빈 자료·미디어 안내와 키보드 포커스 표시를 개선한다.
- 작은 창의 버튼 줄바꿈과 스타일 프리셋 선택 폭을 보완했다. 변경 범위와 격리 실행 결과는 [검증 기록](../quality/verification-2026-10-12-workbench.md)에 기록한다.

## 2026-10-12 — 콘티 보관함 사용 흐름 개선

- 보관함을 검색·정렬 목록과 선택한 콘티의 곡 순서 미리보기로 구성했다. 곡 이름 검색, 현재 콘티 표시, 곡·슬라이드 수와 예배 날짜를 제공한다.
- 새 콘티·복제·이름 변경은 별도 입력 화면에서 처리하며 이름 변경 후에는 보관함에서 결과를 확인한다. 휴지통 이동은 선택 콘티 확인과 현재 순서 비움 안내를 제공하고, 복원 후 복원한 콘티를 바로 표시한다.
- 앞선 요청의 콘티 곡 기본 프리셋 자동 적용과 콘티 파일의 현재 콘티 끝에 추가하기를 운영 안내에 반영했다.
- 보관함 검사 결과와 화면은 [검증 기록](../quality/verification-2026-10-12-setlist-manager.md)에 기록한다.

- 루트 README를 현행 진입점으로 갱신하고 이전 기술 명세·차세대 로드맵·개선 보고서의 기록 시점을 표시했다.
- 내부 문서 링크·소스 경로·추적 ID·표 구조·상태·기존 변경 보존을 확인했다.
- 작업 도중 추가된 별도 운영 검토를 보존·연결하고 Undo 발표 경계·선택 이력 두 사례를 직접 추가 검사했다. 최종 표본은 25개이며 기대 일치 10개, 차이 15개다.

실행 코드·패키지·실제 사용자 데이터·키·배포 상태를 수정하지 않았다. 작업 전부터 존재한 dist-electron 변경은 보존했다. 커밋·푸시·설치 패키지·실장비·실 API·사용자 수용은 이번 작업 범위에 포함하지 않았다.

제품 동작 변경안은 제안 상태다. 후속 확정·구현·검증은 해당 ADR·REQ·TASK와 새 실행 기록을 갱신한다.
