작성일: 2026-10-04 · 상태: 코드 대응 반영 / 운영·외부 증거 대기 · 관련: [검토](../review/프로프리-전체-검토-보고서.md), [결정 기록](결정-기록.md)

## 가정 관리

- 시장·가격·업무 절감·개발 기간을 조사하지 않았다. 수익화나 구매 결정의 확정 근거로 쓰지 않는다.
- 기존 자료를 계속 읽는 것이 중요하다고 가정한다. 실제 파일 분포·미디어 크기·편집 방식은 추가 확인해야 한다.
- `.ppros` 샘플 파일의 실제 내용을 문서에 복제하지 않았다. 검증은 합성 자료를 중심으로 수행했다.
- 현재 번들 결과와 감사 DB는 검토 시점 스냅샷이다. 다음 구현·릴리즈에서 다시 확인한다.

## 해소 판정

위험을 닫을 때 관련 작업과 실제 TC 실행 기록, 잔여 제약, 담당자·날짜를 남긴다. 문서나 설계를 작성한 것만으로 자료 손실·장비·설치 위험을 닫지 않는다. 제품 선택이 미정이면 Q를 유지하고 관련 ADR의 상태를 제안으로 둔다.

## 구현 후 질문·잔여 위험

Q-003~007은 [ADR-008](결정-기록.md)의 전체 중단·시작/재개·클릭 송출/편집 반영·미디어 포함 JSON·선택 AI 정책으로 이번 버전에 적용했다. 초기 비교안은 기록으로 보존한다. Q-001의 전체 지원 장비/규모, Q-002 자료 출처/권리, Q-008 실제 운영자 수용은 미확인이다.

코드 대응의 근거는 [후속 검증](../quality/2026-10-04-운영-개선-후속-검증.md), 운영/외부 대기는 [릴리즈 기준](../operations/릴리즈-운영-투입-기준.md)에 연결한다. 번들·창의 적용 응답을 실제 장비·서명·권리 승인으로 사용하지 않는다.

## 확장 후 남은 확인 (2026-10-16)

예배 기능 7개·웹/PDF·업데이트의 로컬 구현은 [현재 현황](../review/구현-자산-문서-현황.md)에 반영했다. 실제 사이트 로그인/소리, 물리 메인·무대·음향, 60분 타이머·절전, 물리 인쇄, 서명된 A→B 업그레이드와 실제 사용자 자료 이전은 [릴리즈 기준](../operations/릴리즈-운영-투입-기준.md)의 열린 수용 항목이다. 큐시트·예배/템플릿 파일은 선택한 담당자·메모를 포함할 수 있으므로 공유 전 포함 정보를 확인한다. 과거 `audit` 결과는 현재 의존성 상태의 증거로 재사용하지 않는다.
