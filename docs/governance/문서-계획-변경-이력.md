# 문서·계획 변경 이력

## 2026-10-16 — 무료 다운로드 업데이트로 전환

사용자 요청으로 Apple 유료 가입/서명/공증을 요구하는 자동 설치를 무료 버전 확인·브라우저 DMG 다운로드·수동 앱 교체 안내로 변경했다. 설치 IPC/native adapter와 의존성을 제거하고 unsigned 파일·JSON 생성 명령을 준비했다. 실제 외부 게시와 다운로드한 앱 교체 수용은 별도다. [현재 설계](../engineering/프로프리-앱-업데이트-설계.md), [검증](../quality/2026-10-16-무료-다운로드-업데이트-검증.md).

## 2026-10-16 — 선택한 AI로 기존 파일 분석 연결

기존 작업이 생성 당시 AI로 요청하던 기본 분석 버튼을 통합했다. 현재 선택한 연결/제공자/모델로 전환 후 분석하며 재전송과 이전 오류의 제공자를 구분한다. Electron 8개·타입·빌드·lint·번들 검사가 통과했다. [검증 기록](../quality/2026-10-16-AI-선택과-실제-요청-연결-검증.md).

## 2026-10-16 — 제공자별 AI 할당량 오류 구분

429의 상세 구조를 안전하게 읽어 Gemini 할당량 0/일일/분당 제한과 OpenAI 크레딧·사용/지출 한도를 구분했다. 원격 오류 메시지는 표시하지 않는다. 단위 15개·Electron 7개·타입·빌드·번들 검사가 통과했다. 실제 계정 제한 원인은 미확인이다. [검증 기록](../quality/2026-10-16-AI-할당량-오류-안내-검증.md).

## 2026-10-16 — AI 연결 입력 닫기 복구

AI 찬양 준비 안의 연결 입력에 닫기·취소를 추가하고 Escape는 연결 입력부터 닫도록 했다. 기존 준비 지시와 저장된 연결을 유지하며 상단 전체 닫기는 스크롤 중에도 표시한다. 관련 Electron 6개, 타입·생산 빌드·변경 컴포넌트 lint·번들 검사 통과. [검증 기록](../quality/2026-10-16-AI-연결-입력-닫기-검증.md).

- 편집 소속과 원곡 반영은 한 줄로 줄이고 자세한 원곡 보호 설명은 tooltip에 남겼다.

- 내부 문서 링크·소스 경로·추적 ID·표 구조·상태·기존 변경 보존을 확인했다.
- 작업 도중 추가된 별도 운영 검토를 보존·연결하고 Undo 발표 경계·선택 이력 두 사례를 직접 추가 검사했다. 최종 표본은 25개이며 기대 일치 10개, 차이 15개다.

실행 코드·패키지·실제 사용자 데이터·키·배포 상태를 수정하지 않았다. 작업 전부터 존재한 dist-electron 변경은 보존했다. 커밋·푸시·설치 패키지·실장비·실 API·사용자 수용은 이번 작업 범위에 포함하지 않았다.

제품 동작 변경안은 제안 상태다. 후속 확정·구현·검증은 해당 ADR·REQ·TASK와 새 실행 기록을 갱신한다.
