# ProPre

ProPre는 가사·성경·미디어 자료를 준비하고 청중 화면과 무대 모니터로 송출하는 Electron·React 데스크톱 앱입니다. 현재 버전은 **0.1.0**이며 자료 자동 저장, 저장 오류 복구, 역할별 창과 최신 송출 상태의 재전달을 제공합니다.

2026-10-04 운영 검토의 24개 항목과 추가 요청인 창 구분·자동 저장을 구현했습니다. 로컬 단위/계약 검사, 실제 Electron 창 실행, macOS arm64 앱 생성 결과는 [후속 검증](docs/quality/verification-2026-10-04-implementation.md)에 기록했습니다. 물리 송출 장비·서명·공증·실제 사용자 자료 업그레이드·배포 권리는 별도 확인 단계입니다.

이후 개발 실행의 검은 화면 오류를 수정하고 Vite 개발 실행·자동 저장·종료 검사를 추가했습니다. 원인과 실제 실행 복구는 [개발 시작 복구 검증](docs/quality/verification-2026-10-04-startup-recovery.md)을 확인합니다.

## AI에서 자료 준비

같은 컴퓨터의 MCP 지원 AI에서 자료 검색·조회, 가사/성경 자료 생성·본문/스타일 수정, 진행 순서 구성, PNG 미리보기를 사용할 수 있습니다. **설정 → 시스템 환경 설정 열기 → AI 연결**에서 조회 또는 자료 준비 권한을 선택하고 연결을 허용한 뒤, AI 클라이언트용 연결 설정을 복사합니다. 연결한 뒤 설정창을 닫고 AI에서 “ProPre 상태와 자료 목록을 보여줘”로 확인합니다.

새 자료는 현재 선택과 송출을 유지하며, 송출에 사용 중인 현재 자료의 수정은 거절합니다. 수정 버전 충돌·중복 요청·모달/입력 중 작업·저장 실패를 처리하고 현재 자료의 일괄 수정은 한 번의 Undo로 되돌립니다. 연결은 앱 세션에만 유지되고 인증 토큰은 AI 클라이언트 설정에 포함하지 않습니다. 앱에 포함된 연결 프로그램을 사용하므로 별도 Node 설치가 필요하지 않습니다.

[연결·사용·복구 안내](docs/operations/ai-connection.md), [설계와 계약](docs/engineering/ai-connection.md), [104개 단위/계약·29개 실제 앱 검사와 패키지 연결 검증](docs/quality/verification-2026-10-05-ai-connection.md)을 참고합니다. 실시간 송출 제어와 웹의 원격 AI 연결은 후속 범위입니다.

## 창과 자동 저장

| 창 | 제목과 용도 |
| --- | --- |
| 컨트롤 | `ProPre · 컨트롤` — 준비·편집·순서·송출 제어 |
| 메인 | `ProPre · 메인 송출` — 청중 화면 |
| 모니터 | `ProPre · 모니터` — 현재/다음 본문과 시계 |

Dock 아이콘 메뉴와 앱의 창 메뉴에서 이름으로 창을 선택하거나 다시 엽니다. 앱의 페이지 제목이 네이티브 창 이름을 덮지 못하게 했습니다.

모니터는 현재·다음 본문과 시계를 유지하면서 찬양·성경의 글꼴·색상·정렬·줄 간격을 메인 화면의 자료 스타일과 연동합니다. 성경은 현재·다음 구절을 각각 표시합니다. 모니터 본문 크기는 시스템 환경 설정의 무대 모니터에서 별도로 조절하며, 긴 본문은 영역에 맞춰 줄입니다. [구현·검증 기록](docs/quality/verification-2026-10-05-stage-style.md)을 참고합니다.

설정에서 지정한 찬양/성경 기본 프리셋은 자료 선택·첫 송출·종류 전환에 자동 적용합니다. 같은 종류를 진행하는 동안 직접 조정한 스타일은 유지합니다. 선택 안함은 자료의 저장 스타일을 사용하며 개별 텍스트 사용자 스타일은 우선합니다. [기본 프리셋 검증](docs/quality/verification-2026-10-05-default-presets.md)에 적용 규칙을 기록했습니다.

제목·텍스트·추가/삭제/정렬·캔버스 요소·자료 스타일은 별도 저장 버튼 없이 라이브러리에 저장됩니다. 마지막 변경 뒤 기본 400ms에 기록하며, 일괄 편집과 캔버스 편집은 각각 350ms·250ms의 자동 적용 대기가 추가됩니다. 열려 있는 편집창에서도 변경을 반영하고 닫기·정상 종료 때 남은 대기를 정리합니다. 상단에서 저장 대기/저장 중/저장됨/실패를 확인하고 실패하면 재시도할 수 있습니다.

프리셋·라우팅·모니터 글자 크기·크로마키·미디어 목록도 저장합니다. API 키는 명시적으로 등록하며 OS 보호 저장만 사용합니다. 키 원문은 출력 창·백업에 전달하지 않습니다.

## 주요 동작

- 찬양 편집 화면의 `성경 구절 추가`에서 개역개정 구절·절 범위·장을 검색하고 필요한 항목을 선택해 현재 자료의 맨 앞·중간·맨 뒤에 삽입합니다. 본문과 구절이 있는 말씀 슬라이드가 추가되며 자동 저장·Undo/Redo를 지원합니다. 추가 중 현재 송출은 유지하고, 슬라이드 클릭으로 송출합니다. [사용·검증 기록](docs/quality/verification-2026-10-05-bible-insert.md)을 참고합니다.
- 새 자료·성경·파일 가져오기는 새 ID로 생성하고 이전 자료를 보존합니다. 자료별 Undo 경계를 유지하고 선택만 바꾸는 작업은 편집 이력을 소비하지 않습니다.
- 기존 슬라이드 클릭 송출을 유지합니다. 활성 자료의 편집·삭제·정렬·Undo/Redo는 메인과 모니터에 함께 반영합니다. 자료 전환은 활성 슬라이드 송출을 해제합니다.
- 메인·모니터 창을 다시 열거나 로드하면 최신 전체 상태를 전달합니다. 제어창에는 창 준비·적용 상태와 오류를 표시합니다.
- 컨트롤만 닫으면 화면은 유지하고 오디오는 멈춥니다. Dock에서 컨트롤을 재개할 수 있습니다. 앱 전체 재시작은 자료를 복원하고 마지막 본문·소리를 자동 재송출하지 않습니다.
- 모두 지우기는 배경·본문·광고·고정 안내·자막·오디오를 중단합니다. 오디오는 컨트롤 한 곳에서 재생하므로 탭 전환이나 출력 창 수에 따라 중복 재생하지 않습니다.
- 설정 → 화면 구성 → `오디오 플레이어 표시`를 끄면 상단 오디오 제어 영역을 숨깁니다. 기본값은 표시이며 선택은 앱 재시작 후에도 유지됩니다. 숨겨도 재생 중인 소리는 유지되며 `모두 지우기` 또는 F2로 중단할 수 있습니다.
- 이미지·영상·오디오를 등록 미디어로 관리합니다. 특수문자 파일명, 누락 재연결, 참조를 보호한 미디어 정리, 실제 video 요소를 지원합니다.
- 같은 합성 렌더러가 미리보기와 메인에서 Look·크로마키·광고·고정 안내·자막을 처리합니다. 캔버스 크기·단위와 텍스트 맞춤을 공유합니다.
- 성경은 큰 장 번호와 숫자 권명을 구분하고 잘못된/빈 결과로 자료를 지우지 않습니다. 데이터 출처·권리와 원문 품질은 별도 확인 대상입니다.
- AI 추출은 선택 이미지의 Google 전송 안내, 설정 진입, 취소·시간 제한·자료 변경 보호를 제공합니다. 실제 계정 API 호출은 이번 검사에 포함하지 않았습니다.

## 실행과 검사

개발/CI 기준은 Node 24 (`.nvmrc`), 최소 22.12입니다. Electron 44.5.1의 내장 Node 24.21.0과 호스트 Node를 구분합니다. Vite 8·Tailwind 4·React 18·Zustand·Zundo·Zod를 사용합니다. 저장은 Main의 파일 서비스, AI는 Main의 요청 서비스에서 처리합니다.

```bash
npm ci
npm run dev
```

개발 명령으로 Electron 앱을 실행합니다. 일반 브라우저만으로 여는 경우 파일·창·저장 브릿지는 제공되지 않습니다.

```bash
npm run verify
npm run format:check
npm audit
npm run package:check
```

`verify`는 lint·타입·단위/계약·앱 번들·JS 예산·실제 Electron 검사를 순서대로 실행합니다. `build:app`은 실행 번들만, `package:check`는 로컬 `.app` 디렉터리를 만듭니다. 산출물은 `dist`, `dist-electron`, `release/0.1.0/mac-arm64/ProPre.app`입니다. 공개 릴리즈는 권리·실장비·서명 증거를 확인하는 `npm run release`를 사용합니다.

## 콘티 보관함

플레이리스트의 **콘티 보관함**에서 예배별 이름·날짜로 여러 콘티를 만들고 열기·복제·검색·이름 변경·휴지통/복원을 사용합니다. 곡의 가사·반복·색상·스타일은 각 콘티에 독립된 사본으로 저장합니다. 원곡 수정/삭제는 과거 콘티에 전파하지 않습니다. 콘티 수정본은 별도의 **찬양 목록 원곡에 반영**으로만 원곡에 적용합니다. [사용 안내](docs/operations/setlist-library.md), [검증](docs/quality/verification-2026-10-06-setlist-library.md)을 참고합니다.

## 저장·백업

플레이리스트의 **파일 저장 / 파일 불러오기**로 콘티를 `.ppros` 파일에 보관·이동합니다. 곡 순서와 반복, 각 곡의 가사·슬라이드·파트 색상·자료 스타일·참조 미디어를 함께 담습니다. 불러오기는 순서 확인 후 각 곡을 찬양 목록에도 저장합니다. 동일 내용은 재사용하고 다른 내용은 새 자료로 보관하며 현재 작업·송출을 유지합니다. [사용 안내](docs/operations/playlist-files.md), [검증 기록](docs/quality/verification-2026-10-05-playlist-files.md)을 참고합니다.

기존 앱 데이터 디렉터리를 유지하며 `workspace-v2.json`에 원곡·콘티·곡 사본을 저장합니다. 이전 `workspace-v1.json`과 백업은 보존하고 현재 순서는 독립 사본을 가진 콘티로 이전합니다. 5개 직전 기록과 손상 원본을 보관합니다. 저장 실패 후 현재 편집본은 `파일 → 파일로 내보내기`로 다른 위치에 보존할 수 있습니다. 전체 백업 내보내기·복원과 직전 저장본 복구도 파일 메뉴에 있습니다.

새 `.ppros`는 버전 있는 JSON이며 자료 스타일과 등록 미디어를 포함합니다. 전체 백업은 자료·작업본·순서·설정·미디어를 포함하고 키·절대 개인 파일 경로를 제외합니다. 기존 JSON 형식도 읽습니다. 기존 외부 미디어 경로는 임의로 읽지 않고 누락 등록으로 보관하여 운영자가 다시 연결할 수 있게 합니다. 이전 origin의 localStorage 프리셋이 모두 자동 이전된다고 보장하지 않으며 이전 기록은 지우지 않습니다.

운영 저장/IPC 24MiB, 미디어 파일 100MiB, 휴대용 프로젝트/백업 200MiB 제한을 적용합니다. 백업·변환·장애 대응의 자세한 절차는 [운영 가이드](docs/operations/runbook.md)에 있습니다.

## 단축키

| 키 | 동작 |
| --- | --- |
| 방향키, Space, 숫자 1~9 | 슬라이드 송출/진행 |
| Ctrl/Cmd+S | 대기 중 자동 저장 확인 |
| Ctrl/Cmd+Z, Shift+Ctrl/Cmd+Z 또는 Ctrl/Cmd+Y | 현재 자료 Undo/Redo |
| Ctrl/Cmd+C, Ctrl/Cmd+V | 선택 슬라이드 복사/붙여넣기 |
| Delete/Backspace | 선택 슬라이드 삭제 |
| F1 | 본문 송출 해제 |
| F2, 모달 밖 Escape | 모든 시각 레이어·오디오 중단 |
| F4 | 배경 송출 해제 |
| 모달 안 Escape, Tab/Shift+Tab | 변경 적용 후 모달 닫기, 모달 포커스 이동 |

입력창·select·IME·모달은 송출 단축키에서 보호합니다.
